# 衣序 HangFlow · V2 交互原型

> 单文件、无 CDN、无联网，双击即开；浅色家电/家居五金风（白底、哑光外壳、阳极氧化铝管、灰接缝，无金色/深色科技底）。
> 结构：**墙/边缘 — 圆柱 — 10mm 接缝 — 圆柱 — … — 圆柱 — 墙/边缘**。
> K 件衣服 = **K+1 个抱箍式伸缩圆柱**；衣架挂在 K 个接缝处；**不画衣服、不换序、无换向、无卷簧**。
> 两端 01/0(K+1) 是固定端（锁死、不可拖）；内部圆柱可拖；夹头只保留小按钮 + 🔒/🔓。

## 怎么打开

- 双击 `app-v2/index.html`（Chrome / Edge / Safari 新版，`file://` 可用）。
- 手机扫码：项目根目录 `python -m http.server 8000`，访问 `http://<电脑局域网IP>:8000/app-v2/`。
- 页面无外部请求；RDK 现场可由 FastAPI 托管 `app-v2/`。

## 结构（v2 锁定）

```
墙/边缘 ─ C0 ─ S1 ─ C1 ─ S2 ─ C2 ─ … ─ SK ─ CK ─ 墙/边缘
          圆柱   接缝  圆柱   接缝  圆柱        接缝  圆柱
```

- **C**：抱箍式伸缩圆柱，长度 = 该段净风道；两端 01/0(K+1) 是**固定端**（默认夹头锁死、锚在墙/杆，不可拖）。
- **S**：两个圆柱端头之间的 **10mm 接缝**，衣架钩挂在这里（自由转动、不承重）。
- K = 衣架数（2–8）；圆柱数 = K+1；接缝数 = K。
- 加一件衣服 = 新增一个接缝 + 一个内部圆柱；两端固定端圆柱始终保留。
- **只拖内部圆柱 02–0K**；点固定端会提示“端部固定，先解锁再调”。
- **不换序**：衣架不能穿过圆柱，v2 不提供 P2/抬升换序。

## 默认数据（K=4）

| 项 | 值 |
|---|---|
| 总链长 ΣL + K×10 | **460 mm** = 端部 2×60 + 内部 3×100 + 接缝 4×10 |
| 可用长度 | **1100 mm**（杆 1200 − 两端各 50） |
| 剩余空杆 | **640 mm**（1100 − 460） |
| 圆柱 / 接缝 | 5 个 / 4 个 |
| 端部夹头 | 左右 01 / 05 固定端，默认 60mm，夹头锁死、不可拖动 |
| 内部圆柱 | 3 个，默认各 100mm（净风道 10cm），可拖动/滑杆调 |
| 端部圆柱范围 | 60mm 固定；面板标注固定端，不随杆长/总链长自动缩 |

顶部统计显示 **总链长 / 可用长度 / 剩余空杆 / 视觉识别**，不显示卷簧余量。

## 参数口径

| 项 | 值 |
|---|---|
| 杆长 | 800–2400 mm 滑杆（默认 1200 mm） |
| 端部余量 | 两端各 50 mm（墙/法兰），页面画出余量区 |
| 衣架数 K | 2–8（默认 4） |
| 圆柱数 | K+1（默认 5） |
| 圆柱长度 | 内部 40–220 mm；两端固定端 60mm |
| 接缝 | 10 mm / 个（衣架挂点） |
| 总链长 | `ΣL(K+1 段) + K×10mm` |
| 可用长度 | 杆长 − 2×50 mm |
| 剩余空杆 | 可用长度 − 总链长（不小于 0） |
| 目标净风道 | 3–20 cm；等距/加权时内部圆柱的目标 |
| 杆离墙 `d_wall` | 50–300 mm（默认 150）；<120 mm 显示衣摆蹭墙提示 |
| 视觉识别 | 模拟识别全部 K+1 个圆柱编码（01、02…） |

## 交互/演示

1. **默认**：4 衣架 / 5 圆柱 / 4 接缝，总链长 460mm，右侧剩 640mm 空杆；两端 01/05 固定端，内部 02/03/04 可拖。
2. **一键等距**：内部圆柱 = 目标净风道（3–20cm），两端固定端长度不变；总链长、剩余空杆实时更新。
3. **按湿度加权**：按相邻衣架的湿度权重分配内部圆柱（湿的段更长）；固定端不变。
4. **收衣**：内部圆柱缩到最短 4cm；固定端保持 60mm，不自动缩短。
5. **手动逐段**：按住内部圆柱左右拖（鼠标/触摸），按当前 scale 换算 mm；也可用滑杆。拖动时自动模式暂停；两端都锁的内部段拒绝并提示“先松一端”；固定端点按提示“端部固定，先解锁再调”。
6. **改杆长**：只改可用长度/剩余空杆，不自动改任何段长；杆 2.4m 时视图自动缩放为“链条 + 200mm 空杆”，右侧虚线标真实剩余空杆。
7. **加减衣服**：K 的 +/−；加一件 = 插入一个接缝 + 一个内部圆柱，固定端仍各一个；编号连续，已有湿度和夹持状态保留。
8. **夹头**（每个圆柱两端各一个小按钮）：
   - 图标：🔒 锁定 / 🔓 松开；点击内部圆柱夹头切换。
   - 固定端 01/05 两个夹头默认 🔒，点固定端提示“端部固定，先解锁再调”；固定端不参与拖动。
   - 伸缩动画时用 `←/→` 箭头表示固定端/移动端：锁左端 → 右端动；锁右端 → 左端动；两端都锁 → 定点、无箭头。
   - 内部圆柱两端都锁时保持长度、滑杆禁用。
9. **告警**：`ΣL+K×10 > 可用长度` 红色「总链长超限」；`d_wall < 120mm` 黄色衣摆蹭墙提醒。

## 算法（前端模拟）

- 内部圆柱：等距 = 目标值；加权 = `w=1+2h`，按相邻衣架平均权重分配；收衣 = 4cm（锁定圆柱除外）。
- 端部固定端默认 60mm、锁死；内部圆柱独立可拖动，不自动顶墙。
- 总链长 = 所有 K+1 个圆柱长度 + K×10；可用 = 杆长 − 100mm；剩余空杆 = 可用 − 总链长。
- 请求总链长超过可用长度时**不自动压缩**，保留端部 60mm/内部目标值，红色显示请求总链长并提示加长杆或减少衣架。
- 视图缩放：链条 + 200mm 空杆；圆柱 ID 居中，长度标签奇偶错行，宽度 <42px 时隐藏（面板保留）；空杆虚线标注真实剩余值。
- 总链长、可用长度、剩余空杆、视觉识别数实时显示。

## 接真设备（替换点）

| 位置 | 现在 | 接真机时 |
|---|---|---|
| `state.lengths` | K+1 个圆柱目标长度 | 由 planner 下发；MQTT `flow/cyl-0i/cmd {target_mm}` |
| `state.clamps` | 本地锁/开演示状态 | 下发夹头电磁/机构指令；锁/开位置反馈 |
| 端部夹头 | 页面锁位/顶墙文案 | 锁杆位置、顶墙力/电流反馈 |
| 视觉识别 | 模拟 `01–0(K+1)` | RDK ArUco 识别编码与位置 |
| 衣架湿度 | 面板滑杆 | 传感器/手动输入；加权模式输入 |
| 杆长 / 端部余量 / d_wall | 页面配置 | 现场标定；d_wall 由安装位置或测距得到 |
| 告警 | 前端计算 | 超限在 planner 侧拦截；页面只显示回执 |

## 已知不足（诚实版）

- 俯视示意图不是 CAD；圆柱、夹头按钮和接缝是 CSS/图标示意，不是可装配结构细节。
- 长杆视图是缩放示意（链条 + 200mm），不是整杆等比例；右侧虚线旁标注真实剩余空杆。
- 两端固定端默认锁死，点按只给“端部固定，先解锁再调”提示；没有实现解锁后拖动端部的机构流程。
- 夹头状态与箭头是交互演示；不模拟夹头打滑/刚度、顶墙预紧力。
- 未接 MQTT/WebSocket；数据、电量、视觉识别均为前端模拟，刷新重置；日志只保留 8 条。
- 只做单杆；不画衣服；不做换序/P2；不做语音、升降、多杆。
- 390 竖屏验证 `scrollWidth = 390`；桌面 1400 宽已检查，无横向滚动。

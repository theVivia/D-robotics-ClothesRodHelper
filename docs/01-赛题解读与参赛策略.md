# 赛题解读与参赛策略

> **这份文档回答：DDC2026 到底在比什么，我们怎么用 48 小时最大化获奖概率。**
> 事实来源：官方赛事页 <https://hackathon.d-robotics.cc/>（2026-11-23 抓取）。评分细则未公开，文中"评审偏好"均为**推断**，已标注。

---

## 1. 赛事事实（原文提炼）

| 项 | 内容 |
|---|---|
| 名称 | DDC2026 · 地瓜机器人黑客松，"48H 和真实世界碰一碰" |
| 时间地点 | 2026.12.05 13:00 开赛 — 12.07 18:30 颁奖；上海张江科学会堂 |
| 赛题 | **开放主题，不分赛道**；从零做新作品 / 改造已有项目 / 继续未完成项目都可以 |
| 硬性要求 | ①以地瓜 RDK 为核心计算平台；②可配合 MCU、传感器、执行器；③**运用 AI 辅助开发并展示 AI 使用过程**；④现场演示**可运行的实物** |
| 提交 | 12.07 **12:00 截止**提交作品与开发过程；14:00 评审；18:30 决赛路演 |
| 队伍 | 2—4 人，可跨校跨公司；个人报名后线上组队 |
| 报名节点 | 10.01—11.30 报名；**11.30 前完成参赛确认**（今天 11.23，只剩 7 天） |
| 现场资源 | RDK X5 / S100 / S600；奥比中光深度相机；飞特舵机/电机；3D 打印与 PCB 打样；焊接测量工具；麦克风/扬声器/屏幕；百度智能云；Qoder / WorkBuddy |
| 奖金 | 总池 30 万：MVP 12 万×1、一等 5 万×1、二等 3 万×2、三等 1 万×5、人气 2 万×1 |
| 食宿 | 免费餐饮、会期住宿、国内往返交通支持 |

**关键含义**

1. **开放主题 = 选题本身就是评分项**。没有赛道兜底，作品要在几十上百个项目里被记住，必须"一句话说得清 + 一眼看得懂"。
2. **"真实世界"是主题词**。评委（投资人和机器人公司 CEO 居多）看重的是"这东西真的有人要吗"，而不是"技术多炫"。
3. **允许带已有项目**，但必须说明赛前基础和现场增量 → 赛前准备是合法且被鼓励的，但**现场必须有肉眼可见的进展**（否则会被认为"拿旧项目来蹭"）。
4. **AI 使用过程是显式要求**，不是加分项 → 需要留下可展示的证据链（见 [docs/16](16-AI辅助开发与过程证据.md)）。

## 2. 评审在比什么（推断，按权重排序）

| 维度 | 推断权重 | 评委视角 | 我们的对策 |
|---|---|---|---|
| **需求真实性** | 高 | "这东西解决谁的什么问题？" | 开场 10 秒讲梅雨季衣服不干的场景，带一件"闷出味"的 T 恤当道具 |
| **完成度/可运行** | 高 | "能不能现场跑一遍给我看？" | P0 功能 12.06 中午必须全通；准备"软演示"备份 |
| **技术含量** | 中高 | "是不是只是拼装？" | 视觉闭环定位 + 加权间距规划 + 一维顺序约束分析，讲清"为什么难" |
| **设计与形态** | 中高 | 洛可可创始人、科沃斯 CEO 在场 | 深色科技感外观、手机端好看、桌面布置干净（见 [docs/08](08-交互与App设计.md)） |
| **商业潜力** | 中 | 投资人："能不能卖？成本多少？" | 成本表 + 定价 + 渠道 + 延展故事（见 [docs/15](15-产品化与商业化.md)） |
| **展示/答辩** | 中 | 路演 3 分钟定生死 | 固定脚本 + 排练 5 次 + 20 个 Q&A 预案（见 [docs/12](12-演示脚本与答辩.md)） |
| **AI 使用** | 中（硬性） | 是否真的用 AI 提效，而不是嘴上说 | 提交 AI 使用日志、代码标注、截图（见 [docs/16](16-AI辅助开发与过程证据.md)） |

> 一句话策略：**用"真实痛点 + 能跑 + 一个记得住的画面"拿基础分，用"视觉闭环 + 算法"拿技术分，用"成本与延展"拿商业分。**

## 3. 选题判断：为什么"衣序"适合这个比赛

### 优势

1. **人人有体感**：评委也晾衣服。不需要解释场景，30 秒能共情。
2. **物理动作可视化**：衣服自己排开，是天然的演示画面，比"屏幕上的数据"强十倍。
3. **RDK 用得上且不硬凑**：视觉定位、规划、网页服务一颗板全包；不是"为了用 RDK 而用"。
4. **成本可控**：模块便宜，能现场做 4 个；不需要昂贵机械臂/人形。
5. **有延展**：模块化 + 视觉 = 可迁移的"可移动挂点"平台，商业故事不封顶。
6. **安全边界清晰**：低速、轻载，现场演示风险低（对比机械臂/无人机）。

### 劣势与对策

| 劣势 | 对策 |
|---|---|
| 看起来"不够硬核机器人" | 强调"分布式多智能体协同 + 视觉闭环 + 1D 调度算法"；现场展示视觉标定与误差数据 |
| 容易被当成"电动晾衣架" | 开场就切割："我们不换杆，我们让杆变聪明"；道具对比：传统杆 vs 套挂模块 |
| 单件成本里 RDK 占比高 | 现场讲"一拖 N"：一台 RDK 带 8 个单元，摊薄后每单元中枢成本 ¥70 |
| 演示受场地/杆限制 | 自带 1.2m 便携演示架（可折叠），30 秒布场 |

## 4. 参赛口径：已有项目怎么报

官方允许"改造已有项目/继续未完成项目"，但要求说明**赛前基础**与**活动期间新增**。我们的诚实口径：

- **赛前基础（11.23—12.04）**：方案文档、机械 CAD、固件骨架、算法仿真、网页原型、采购与打样。
- **现场增量（12.05—12.07）**：整机装配与标定、视觉闭环上线、多单元协同调试、外观收尾、演示排练、现场数据。
- **提交物**：GitHub 仓库（含 commit 时间线）+ 现场照片/视频 + AI 使用记录 + 一页纸说明"赛前 vs 现场"。

> 不要试图隐藏赛前工作：commit 记录、文档时间戳都在。**主动声明反而显得专业**。

## 5. 团队配置

### 理想 4 人

| 角色 | 能力要求 | 现场职责 |
|---|---|---|
| A 队长/系统 | 能做技术决策、能讲 | 架构、视觉、控场、答辩主答 |
| B 机械 | 3D 打印/装配/结构 | 单元装配、现场修件、演示架 |
| C 电控 | 焊接/固件/调试 | 接线、烧录、电源、故障排查 |
| D 产品/交互 | 前端/设计/文案 | 网页、演示脚本、拍摄记录、Q&A 辅助 |

### 3 人：D 的活由 A 兼，网页用现成原型。
### 2 人：砍到 2 个单元 + 单向等距（见 [docs/13](13-风险与PlanB.md) 瘦身版）。
### 1 人：只报"方案 + 软演示"，现场主攻视觉与网页，硬件用 1 个单元做概念验证。

> 组队建议：优先找**会焊接 + 会 3D 打印**的人，这两件事现场最耗时；算法和前端可以 AI 辅助加速。

## 6. 现场资源利用

| 资源 | 怎么用 |
|---|---|
| RDK X5 | 主力中枢；S100/S600 不碰（资料少、48h 风险高） |
| 奥比中光深度相机 | P1：衣物体积/拥塞检测；P0 不依赖（驱动风险） |
| 飞特舵机 | 备选驱动方案（若 N20 打滑严重，现场可换总线舵机做夹爪/推杆） |
| 3D 打印 | 现场补件/改件（提前带好 STL，现场只打小件） |
| PCB 打样 | 来不及，用洞洞板/杜邦线；PCB 只做展示图 |
| 麦克风/屏幕 | P2 语音；屏幕做"展台看板"循环播放演示视频 |
| 百度智能云/Qoder | AI 辅助开发，留证据 |

**自带清单**（详见 [docs/10](10-赛前12天准备计划.md)）：烙铁、热熔胶、螺丝刀套装、扎带、魔术贴、备用 N20/ESP32、充电宝、插排、相机三脚架、卷尺、记号笔、标签纸。

## 7. AI 辅助开发策略（硬性要求）

1. **工具链**：DSH（本会话）+ Qoder/WorkBuddy（现场提供）+ 本地大模型（可选）。
2. **留痕方式**：
   - 每个功能模块在 commit message 里标注 `[AI-assisted]`；
   - 保存关键 prompt → 生成 → 人工修改的对比截图（10—20 组）；
   - `docs/16` 维护 AI 使用日志表（时间、工具、任务、产出、人工修改点）；
   - 现场展示"AI 生成 → 我们 review → 改错"的真实片段（比展示"AI 写了 1 万行"可信）。
3. **诚信边界**：AI 生成的代码必须自己跑通、能解释；不把 AI 产出说成纯手写。

## 9. 提高获奖概率的四个"记忆点"

1. **一句话**："不换晾衣杆，让衣服自己让出风道。"
2. **一个画面**：4 件挤在一起的衣服，一键之后"唰"地排开，间距数字从 2cm 跳到 12cm。
3. **一个数字**：整机成本 ¥400（不含 RDK），比换一台电动晾衣架便宜 80%。
4. **一个延展**："同一套模块，明天可以挂到衣柜里、阳台上——我们卖的是可移动的挂点。"

## 10. 合规与礼仪

- 不抄袭他人项目；开源库/模型遵守许可证（YOLO/OpenCV/ROS2 均为宽松许可，需在仓库注明）。
- 现场用电遵守场馆规定，充电宝不上飞机托运（如返程）。
- 演示时不给评委"惊喜动作"（突然快速移动），避免夹手/掉落。
- 拍摄队友与评委需征得同意；不泄露他人项目。

# 04 · 机械结构设计（套挂单元 ClipUnit）

> **这份文档回答什么问题**：套挂单元凭什么能夹在 Ø20–35 的既有晾衣杆上、挂住 2kg 湿衣服不打滑不掉、用 N20 30rpm 在 20cm 内走完、并且用一台普通 3D 打印机在 48 小时内做出来。

> 口径：所有数字都是**设计值 / 估算**，不是实测。凡"实测"二字出现在别处文档里，以本文的"设计值 + 待验证项"为准。

## 0. 一页结论（先看这个）

| 项 | 设计值 | 结论 |
|---|---|---|
| 适配杆径 | Ø20–Ø35（圆杆，钢/铝/不锈钢） | 上壳按杆径一版一打（改 `ROD_D` 重生成）；下爪滑槽 20mm 行程吸收公差/杆不直，弹簧自动补偿 |
| 单元质量 | 250 g（含 18650） | 单模块承重校核到 5kg（表 4-8） |
| 驱动轮 | Ø28 硅胶（Shore A 50–60），轮距 0 | 摩擦轮在杆正上方 |
| 惰轮 | Ø20×2，轴距 60mm，杆正下方 ±30 | 既承重又抗俯仰 |
| 夹持预载 | F_s = 25 N（可调 15–30N） | 由 2 根 Ø5×0.6×15 弹簧压缩 8mm 实现 |
| 顶轮正压力 | N_f = 47.1 N（挂 2kg） | 自增力：衣物越重压得越紧 |
| 行进速度 | 44.0 mm/s @30rpm | 20cm 用时 4.6s，设计值 5.0s |
| 所需牵引力 | 4.0 N | 可提供 16.5N（湿态），余量 4.1× |
| 挂点位置 | (0, 0, −48)，**杆轴心竖直正下方** | 挂衣重力对杆轴力矩 = 0 |
| 打印预算 | 单件 ≤55g / ≤2.9h，四件合计 100g / 5.7h | 满足"48h 内单机打完" |
| 机械件成本 | ≈¥65/单元（**不含 N20 与硅胶轮**——这两项计入电控口径 `docs/09`） | 与 Lead 锁定口径一致：单单元 ¥150 = 电控+电池 ¥86.5 + 机械 ¥65 |

**三条硬约束（写进设计冻结）**：
1. **挂点必须在杆轴线正下方**（Y 向偏移 ≤ ±5mm）。圆柱杆 + 轮式接触的径向法向力对杆轴的力矩恒为零，绕杆轴的滚转只能靠摩擦抗——一旦偏心，2kg×25mm = 0.49 N·m 就能让 0.32 N·m 的摩擦容量失效，模块会绕杆"转圈"。详见 §4.2。
2. **夹持是弹性的**，不能做成刚性夹死。杆径公差、杆不直（1.2m 杆中间下垂 1–2mm）、热胀都需要弹簧吸收，否则要么夹不住、要么把杆压出痕。
3. **钩销不用打印件**，用 Ø6 不锈钢圆销。打印件沿层方向抗弯只有 XY 向的 30–50%，挂 2kg 的销子必须是金属。

## 1. 设计目标与约束

### 1.1 功能目标（来自 `docs/_shared-context.md` §4）

1. 夹住 Ø20–35mm 圆杆，**不换杆、不改造**——这是产品"零安装"卖点的物理基础。
2. 沿杆自走，单次行程 ≥300mm，定位精度目标 ±5mm（机械端给到 ±1mm，视觉端做绝对校准）。
3. 单模块承重 5kg（设计工况 2kg 湿衣 + 单元自重）。
4. 侧面挂衣钩，衣架能单手挂取，衣服不蹭单元壳体。
5. 断电后不溜车（水平杆上无外力即静止；斜杆靠电机保持力矩 + 编码器闭环）。

### 1.2 硬约束

| 约束 | 来源 | 对结构的影响 |
|---|---|---|
| 48 小时内用现场 3D 打印做出来 | 赛事事实 | 单件 ≤80g、≤4h、无支撑或少支撑；只用一种主材料 |
| 无 OpenSCAD/无渲染条件 | 本任务环境 | `.scad` 只交付源码 + 参数注释，尺寸全部在文档里对齐 |
| 电控只有 ESP32-C3 + N20 + DRV8833 + AS5600 | 共享上下文 §4 | 机械端不能指望闭环之外的主动夹紧机构（如舵机夹爪） |
| 阳台环境：日晒、雨淋、湿手操作 | 场景 | 材料要抗 UV、盒体要排水、金属件要 304 |
| 用户不会调机 | 产品定位 | 杆径只有一个"滑动+锁"动作，不能有需要工具反复调的结构 |

### 1.3 设计取舍（写清楚为什么不是另一种）

| 方案 | 取舍 |
|---|---|
| **摩擦轮压杆自走（选定）** | 结构最简、能"套挂"；代价是牵引力受 μ 限制 → 用"载荷自增力"设计把正压力跟重量绑定（§4.3） |
| 杆上挂导轨 + 同步带 | 更稳更准，但要改造杆，违背"不换杆"卖点 |
| 丝杠/齿条 | 行程短、自重大、成本高 |
| 舵机夹爪 | 需要第三根线/额外驱动，且夹紧力不能自保持 |
| 磁吸 | 只适用铁杆，用户杆材质不可控 |

## 2. 总体形态与工作原理

### 2.1 三个件的一句话说清

- **上壳（Γ 形，55g）**：骑在杆上方的刚性主件。它同时是驱动轮座、电机座、电池/电路舱、挂钩吊板的根。**衣物重量全部由它经驱动轮压到杆上**。
- **下爪（U 形，22g）**：托着两个惰轮，从下方顶住杆；靠 2 根弹簧上顶、2 条 M4 滑槽定杆径档位。
- **挂钩吊板（14g）+ Ø6 钢销**：从上壳背舱底面往下，销心落在**杆轴线正下方 48mm**。

### 2.2 力怎么走（这是全文最重要的一张图）

```
                      衣物重力 W_g（2kg，19.62N）
                               │ 挂在钢销上
                               ▼
   ┌──────────────── 上壳 Γ ────────────────┐
   │   ▲ N_f = F_s + W            （顶轮）    │
   │   │                                     │
   │  ╔═══╗ Ø28 硅胶轮（杆正上方，Z=+26.5）   │
   │  ║   ║                                   │
   ═══╬═══╬════════ Ø25 圆杆（X 向）═══════════
   │  ╚═══╝                                   │
   │   ▼ N_i1 = F_s/2        （杆正下方）     │
   │   ●──────●  Ø20 惰轮 ×2（X=±30，Z=−22.5）│
   └───┬──────────────┬──────────────────────┘
       │ 2 根 Ø5 弹簧 │ 各 12.5N（下爪上顶）
       ▼              ▼
```

三个关键力学事实：

1. **上壳吊在驱动轮上**：N_f = F_s + W（F_s 是弹簧预载，W 是全部挂重）。所以**越重压得越紧**——这叫载荷自增力，是抗打滑的根本。
2. **两惰轮在杆下方前后 ±30mm**，它们不承重（承重的是顶轮），但提供**抗俯仰力偶**：牵引力 F_t 作用在杆顶、离杆轴 ±R，产生 2R·F_t 的俯仰力矩，由前后惰轮的法向力差承担（§4.6）。
3. **绕杆轴的滚转（roll）没有几何约束**。圆柱杆 + 径向法向力 ⇒ 三个接触力对杆轴的力矩都为零。roll 只能靠轮-杆接触面的**切向摩擦**抗，容量 = μ·R·ΣN。这决定了"挂点必须落在轴线上"这条硬约束（§4.2）。

## 4. 受力计算与校核

> 记号：W_u 单元自重，W_g 衣物重（设计工况 2kg），W = W_u + W_g，F_s 夹持预载，N_f 顶轮正压力，N_i 单惰轮正压力，F_t 牵引力，μ 轮-杆摩擦系数，R_rod 杆半径，g = 9.81 m/s²。
> 设计工况：m_u = 0.25 kg，m_g = 2.0 kg；极限工况 m_g = 5.0 kg。

### 4.1 载荷

```
W_u = 0.25 × 9.81 = 2.45 N
W_g = 2.00 × 9.81 = 19.62 N
W   = 2.45 + 19.62 = 22.07 N        ← 设计工况
W_5 = 2.45 + 5.00 × 9.81 = 51.50 N  ← 极限工况
```

### 4.2 校核一：2kg 挂点力矩 → 惰轮支反力（含"挂点偏心 8mm"反例）

**为什么必须先说清楚这件事**：杆是圆柱，三个轮与杆的接触法向力都过杆轴心线。力对轴的矩 = 力臂 × 力的垂直分量，法向力过轴心 ⇒ 力矩为零。**所以"挂在轴线正中"时，2kg 衣物对杆轴的力矩精确为 0，靠的是几何而不是摩擦。** 一旦偏心，这个力矩只能由切向摩擦承担，容量极小。

**（a）挂点在轴线上（本设计）**

```
M_hook = W_g × e,  e = 0           ⇒  M_hook = 0 N·m
```
挂点载荷 19.62N 竖直向下，经吊板全部转成顶轮正压力：

```
N_f = F_s + W = 25 + 22.07 = 47.07 N
N_i = F_s / 2 = 25 / 2 = 12.5 N    （每只惰轮）
竖直平衡校验：2N_i + W = 25 + 22.07 = 47.07 = N_f  ✓
```
**结论**：顶轮法向 47.1 N，单惰轮支反力 12.5 N，2kg 挂点产生的绕杆轴力矩为 0。

**（b）反例：挂点偏 8mm（装配误差/衣架摆动）**

```
M = W_g × e = 19.62 × 0.008 = 0.157 N·m
抗滚转摩擦容量 C = μ · R_rod · ΣN = μ × 0.0125 × (47.07 + 2×12.5) = μ × 0.0125 × 72.07 = 0.901 μ  [N·m]
  干燥硅胶/漆面钢 μ=0.6 ：C = 0.541 N·m → SF = 0.541/0.157 = 3.4   ✓
  淋湿后      μ=0.35：C = 0.316 N·m → SF = 0.316/0.157 = 2.0   ○（可接受，但不再有富余）
```
**（c）再偏大一点就会出事——这就是为什么把它写成硬约束**

```
e = 25mm（"钩子装在壳体侧面"的常规做法）：M = 19.62 × 0.025 = 0.49 N·m
  干燥：SF = 0.541/0.49 = 1.10   ✗  湿态：0.316/0.49 = 0.64  ✗
```
**结论**：e ≤ 5mm 为设计值（SF≥2.9 湿态），e = 8mm 是容差上限（SF 2.0），**e ≥ 15mm 不可接受**。这正是 lead 提醒的"模块转圈"的定量解释：不是夹不住，是摩擦容量不够。
> 若将来产品化必须做侧挂（比如钩子要避开衣物），补偿手段只有两条：把 ΣN 提到 ≥150N（预载太大，手按不动）或加配重把等效偏心拉回 0——都不如"钩子在轴线上"省事。这一点请写进专利申请的从权。

### 4.3 校核二：摩擦轮所需正压力与牵引力（要求 ≥3× 余量）

**(a) 需要多大牵引力**

| 阻力项 | 公式 | 代入 | 值 N |
|---|---|---|---|
| 滚动阻力 | F_rr = c_rr · ΣN | 0.012 × 72.07 | 0.86 |
| 杆倾角 2° | F_θ = W · sinθ | 22.07 × 0.0349 | 0.77 |
| 加速度 (a=0.3 m/s²) | F_a = (W/g)·a | 2.25 × 0.30 | 0.68 |
| 风载/衣物摆动裕量 | 取设计值 | — | 1.00 |
| **合计** | | | **3.31** |

取 **F_t = 4.0 N**（对合计值的余量 1.21，用来吸收 c_rr 和风载的不确定性）。

**(b) 正压力够不够（打滑校核）**

```
所需摩擦系数  μ_req = F_t / N_f = 4.0 / 47.07 = 0.085
可提供摩擦容量（N_f 与 μ 的乘积，符合 lead 要求的 μN 对比）：
   干燥 μ=0.60： μN = 0.60 × 47.07 = 28.2 N
   湿态 μ=0.35： μN = 0.35 × 47.07 = 16.5 N
```
| 工况 | μN（N） | F_t（N） | 余量 |
|---|---|---|---|
| 干燥 | 28.2 | 4.0 | **7.0×** ✓ |
| 淋湿 | 16.5 | 4.0 | **4.1×** ✓（≥3× 要求满足） |

**结论**：F_t = 4.0 N，硅胶轮（Shore A 50–60）对漆面钢杆在湿态下仍有 4.1× 余量；所需正压力只要 ≥ F_t/μ = 4.0/0.35 = **11.4 N**，而实际 N_f = 47.1 N 是它的 4.1 倍——**这一项不是瓶颈**，瓶颈是电机扭矩（§4.4）。

**(c) 为什么 15–25N 预载就够（lead 的建议值与本文自洽）**

顶轮正压力 N_f = F_s + W 随载荷自增；**预载 F_s 只要保证"空载时不掉"和"抗滚转有摩擦容量"**：

```
空载（W=2.45N）时 N_f = F_s + 2.45：
   F_s = 15 N → N_f = 17.5 N → μN(湿) = 6.1 N > F_t 4.0 N ✓
   F_s = 25 N → N_f = 27.5 N → μN(湿) = 9.6 N ✓（更大抗滚转容量：C = 0.23 N·m）
选 F_s = 25 N（lead 建议区间 15–25 的上沿）：兼顾抗滚转（需要大 ΣN）与手按安装力（2.5kgf）。
可调到 30 N（弹簧压缩 9.6mm），作为湿态/大风场景的加固档。
```

**(d) 预载怎么来的（可调弹簧）**

2 根压缩弹簧（外径 Ø5、线径 Ø0.6、自由长 15、有效圈 6，单根刚度 k ≈ 1.7 N/mm）：

```
F_s = n · k · δ = 2 × 1.7 × 8.0 = 27.2 N  （设计标定 25 N，取压缩 8mm 略偏安全侧）
杆径公差 ±0.3mm ⇒ δ 变化 ±0.6mm ⇒ F_s 变化 ±2.0 N（±8%）→ 弹性夹持，不压痕
```

### 4.4 校核三：速度与 20cm 移动时间

```
v = π · D_wheel · n / 60 = π × 0.028 × 30 / 60 = 0.04398 m/s = 44.0 mm/s
t_ideal = s / v = 200 / 43.98 = 4.55 s
```
加梯形速度曲线（a = 0.3 m/s²，各 0.15s 加减速，实际行程损失 ≈ 2×v²/2a = 6.6mm）与负载降速（N20 在额定扭矩附近转速下降约 15%）：

```
t_design = (200 + 6.6) / (43.98 × 0.85) + 0.3 = 5.53 + 0.3 ≈ 5.0 s（取整，设计值）
```
**结论**：单次 20cm 移动 **5.0 s**（设计值），"4 件衣服一次调整 ≤30s"的目标：4 次平均 15cm + 通信开销 ≈ 4×4.2 + 6 = 23 s ✓。

**编码器分辨率**（给软件同事）：AS5600 12 bit = 4096 计数/转，
`分辨率 = πD/4096 = 87.96/4096 = 0.0215 mm/计数`（设计值；实际受打滑影响，短距离 ±1mm，长距离靠视觉校准）。

### 4.5 校核四：电机扭矩（真正的瓶颈）

```
轮上所需扭矩 τ = F_t × R_wheel / η + τ_bearing
             = 4.0 × 0.014 / 0.95 + 0.005
             = 0.0589 + 0.005 = 0.064 N·m  ≈ 0.65 kgf·cm
```
N20 6V 30rpm 的扭矩（**设计假设值，采购前必须按实际型号 datasheet 复核，见 §12 风险 R1**）：

| 项 | 假设值 | 利用率 |
|---|---|---|
| 额定扭矩 | 0.10 N·m（1.0 kgf·cm） | 0.064/0.10 = **64%** ○ |
| 堵转扭矩 | 0.25 N·m | 26% ✓ |
| 堵转时轮上最大牵引力 | 0.25/0.014 = 17.9 N | > μN(湿) 16.5 N ⇒ **打滑先于堵转** ✓ |

**结论**：额定工况 64% 利用率偏高但可接受（占空比 <15%，单次运动 5s）；若采购到的是 0.06 N·m 版本，必须把杆倾角限制在 1° 内或改用 50rpm 型。**堵转保护不靠驱动板**：市售 DRV8833 模块把 AISEN/BISEN 直接接地、没有采样电阻，硬件上不存在限流——只能靠**固件堵转判据**：PWM 给出但 AS5600 角度在 300ms 内几乎不变 → 立即停输出（依据 `docs/05-硬件与电控设计.md` §11.1）。机械端要保证的是**"打滑优先于卡死"**：硅胶轮在 τ_stall 下先打滑（§4.5 表），弹簧可退让，所以电机不会被机械地锁死。

### 4.6 校核五：10N 侧向力 / 推挤（抗倾覆力偶）

分两个方向，结论完全不同——这是设计里最容易被想当然的地方。

**(a) 沿杆方向 10N（风推衣服沿杆 / 人手顺杆推）→ 俯仰，强力偶，能抗**

```
俯仰力矩  M_y = F_x × |z_h| = 10 × 0.048 = 0.48 N·m
力偶由前后惰轮的支反力差承担（力臂 = 惰轮轴距 60mm）：
   ΔN = M_y / a_pitch = 0.48 / 0.060 = 8.0 N
   N_i(前) = 12.5 + 4.0 = 16.5 N,  N_i(后) = 12.5 − 4.0 = 8.5 N   （两侧各担一半）
   后惰轮仍 >0 ⇒ 不抬离 ✓（抬离阈值 = 0.060×2×12.5/0.048 = 31.3 N，即 F_x ≤ 31N 不翻）
SF(倾覆) = 12.5/4.0 = 3.1 ✓
```
同时 10N 沿杆的推力必须由轮-杆摩擦承担：`μN(湿) = 16.5 N > 10 N，SF 1.65`；若电机通电保持，堵转牵引 17.9 N，**稳态可顶住 10N 推力**（占空比低，可接受）。

**(b) 垂直杆方向 10N（横推）→ 滚转，只有摩擦，扛不住 10N**

```
滚转力矩 M_x = F_y × |z_h| = 10 × 0.048 = 0.48 N·m
摩擦容量（湿）C = 0.316 N·m  ⇒  SF = 0.66 ✗
```
**结论与对策**：Y 向侧推的设计允许值是 **3 N**（SF 3.2 湿态 / 5.6 干态）。10N 横推会让模块绕杆滚转一个角度（**不会掉，也不会失效**，因为驱动轮在任意滚转角都能接触传动），松手后由重心偏心产生的恢复力矩（§3.3 配重后 e_cm≈5mm，0.11 N·m）把姿态拉回。要做"10N 横推不打滑"，只能：
1. 预载提到 30N（ΣN=82N，C(湿)=0.36 N·m，SF 0.75——仍不够）；
2. 背壁贴 TPU 95A 弧形摩擦衬（μ→0.8，C=0.72 N·m，SF 1.5）；
3. 加球铰摆杆，让衣物侧向力由摆杆摆动吸收（P1，结构复杂度 +1 档）。
**P0 不做。** 演示时的操作规范：搬动/拉扯衣服只允许沿杆方向用力。

### 4.7 校核六：夹爪弹簧力与杆面压强（避免压痕）

用户允许我们夹的是**别人的杆**，压出印子就是产品事故。三个轮与杆的接触都是"圆柱正交"，用 Hertz 点接触估算：

**(a) 开车轮（硅胶 Shore A 50，E ≈ 3 MPa）**
```
当量弹性模量 1/E* = (1−ν²)/E_silicone + 0  ⇒  E* = 3/(1−0.25) = 4.0 MPa
当量曲率半径 R_eq = 1/(1/14 + 1/12.5) = 6.60 mm
接触半径 a = (3·F·R_eq / (4·E*))^(1/3) = (3×47.07×6.60/(4×4.0))^(1/3) = (58.3)^(1/3) = 3.88 mm
接触面积 A = πa² = 47.3 mm²
平均压强 p_m = 47.07/47.3 = 1.0 MPa，峰值 p_max ≈ 1.5·p_m = 1.5 MPa
```
**结论**：硅胶轮对杆面峰值压强 **1.5 MPa（设计值）**，比钢材屈服（≥200MPa）低两个数量级，比常见喷涂层的压痕阈值（约 10–30MPa）也低一个数量级 ⇒ **不压痕**。杆若是不锈钢/铝合金/烤漆钢均安全。

**(b) 惰轮若用硬 POM（不加包胶）**
```
E_POM = 2800 MPa，ν=0.35 ⇒ E* = 2800/0.8775 = 3190 MPa
a = (3×12.5×5.56/(4×3190))^(1/3) = (0.0163)^(1/3) = 0.254 mm ⇒ A = 0.20 mm²
p_m = 12.5/0.20 = 62 MPa，p_max ≈ 93 MPa
```
**结论**：硬塑料惰轮对漆面的峰值压强 **≈93 MPa（估算）**，会压出亮痕/压塌漆面 ⇒ **必须包胶**。本设计采用 **TPU 85A 包胶 2mm**：
```
E_TPU85A ≈ 10 MPa ⇒ E* = 13.3 MPa，R_eq = 1/(1/10+1/12.5) = 5.56 mm
a = (3×12.5×5.56/(4×13.3))^(1/3) = (3.92)^(1/3) = 1.58 mm ⇒ A = 7.8 mm²
p_m = 1.6 MPa，p_max ≈ 2.4 MPa  ✓ 不压痕
```
**（c）夹持弹簧力与"压痕"的另一面：杆的局部承压**
杆若是 Ø22×0.8 薄壁铝管，轮压 47N 会不会压扁？局部承压的判据取"接触椭圆短轴 ≤ 壁厚/2"：
`b ≈ a = 3.88mm > 0.8mm 壁厚 ⇒ 薄壁铝管有局部凹陷风险`。
**对策写进用户手册**：适配杆径 Ø20–35、壁厚 ≥1.2mm 的钢管/实心杆；**薄壁（<1.0mm）铝管不在适配范围**（这条要在 App 里做成一次性提示）。

### 4.8 校核七：5kg 极限工况

| 项 | 2kg 设计工况 | 5kg 极限 | 判据 |
|---|---|---|---|
| W（N） | 22.07 | 51.50 | — |
| N_f = F_s + W（N） | 47.07 | 76.50 | 硅胶轮承压 2.5 MPa，仍安全 |
| N_i = F_s/2（N） | 12.5 | 12.5 | 不随载荷变（弹簧决定） |
| 顶轮 μN 湿态（N） | 16.5 | 26.8 | F_t≈5.0N，余量 5.4× ✓ |
| 抗滚转 C 湿（N·m） = μR(N_f+2N_i) | 0.316 | 0.444 | 偏心 5mm 时 M=0.245 ⇒ SF 1.8 ○ |
| 电机利用率 = F_t·R/0.10 | 64% | 70% | <80% ✓ |

**结论**：单模块 5kg 是"挂得住、推得动、但湿态抗滚转余量降到 1.8×"的边界工况；P0 演示只用 2kg。

### 4.9 校核八：杆的挠度与强度（不能把用户的杆压弯）

单模块净载荷 W 作用于 1.2m 跨中（最不利），杆按 Ø25×1.0 钢管：

```
I = π(D⁴−d⁴)/64 = π(25⁴−23⁴)/64 = 7675 mm⁴
δ = W L³/(48 E I) = 22.07×1200³/(48×206000×7675) = 0.50 mm（2kg）
                 = 51.50×1200³/(48×206000×7675) = 1.17 mm（5kg）
σ = W L/(4W_section), W_section = I/(D/2) = 614 mm³
  = 22.07×1200/(4×614) = 10.8 MPa（2kg） → 远低于 Q235 屈服 235 MPa ✓
```
**结论**：杆的挠度 ≤1.2mm、应力 ≤25 MPa，**用户杆不会被压弯**；但挠度 1.2mm 会让"杆径档位"的间隙变化，靠弹簧吸收（±0.6mm 压缩量变化 → 预载 ±8%）。
> 若用户是竹杆/木杆（E≈10GPa，强度 40–60MPa），δ 放大 20 倍 ≈ 10mm、σ ≈ 35MPa → **临界**，需要在 App 里提示"木质杆建议加中间支撑"。这一条写进 `docs/13-风险与PlanB.md`（Lead 维护），本文只记录结论。

### 5.1 材料选择（阳台场景倒推）

| 件 | 材料 | 为什么 | 替代 |

| 上壳 / 下爪 / 挂钩吊板 | **PETG**（P0） | 耐候优于 PLA、层间强度好、不翘边、48h 能打；HDT 70°C | **ASA**（P1，UV 与耐温更好；但收缩大、需封闭腔，现场打印风险高） |
| 惰轮包胶 / 齿形垫 | **TPU 85A** | 不压痕、增摩擦、吸收杆不直 | 采购硅胶 O 形圈套在轮上 |
| 驱动轮 | **硅胶 Shore A 50–60**（采购件） | 摩擦系数高、耐候、可注塑量产 | TPU 85A 打印（+后处理），作 PlanB |

| 钩销 / 惰轮轴 | **304 不锈钢** | 防锈、剪切强度够 | 镀镍碳钢（不推荐，阳台会锈） |

### 5.4 后处理（现场清单）

1. 蜡刀/美工刀去毛刺（重点是杆腔唇口，毛刺会刮杆漆）。
2. 热熔铜螺母：烙铁 240°C，垂直压入，冷却 30s 再松手（歪了夹持就偏）。
3. 轴承压装：台钳 + 平行垫块；Ø6/Ø8 座圈用 H7 打印后**手铰/钻头轻过一遍**（打印收缩 ±0.1mm）。
4. 杆腔背面贴 0.5mm TPU 衬（可选，增大 μ 抗滚转）。
5. 螺纹件上**中强度螺纹胶**（振动 + 户外，必须防松）。

| 三轴共面度 | ≤0.5（驱动轮轴 / 两惰轮轴） | 超差会让一个惰轮悬空（预载被吃掉一半） |
| 两惰轮轴平行度 | ≤0.2 / 60 | 超差 → 走行跑偏（靠编码器差速补偿也能救） |

**打印公差经验值**（FDM，0.4 喷嘴）：名义孔 Ø 打印出来小 0.1–0.2，因此**所有配合孔在模型里已按 +0.15 放大**（`.scad` 里的 H7 座圈是 6.15/8.15 的打印值，装配前铰到 H7）。文字写在这里，避免下一个人再踩。

## 8. 装配步骤（8 步，单人 40 分钟）

> 工具：内六角 1.5/2/2.5、烙铁 + 热熔螺母、台钳、美工刀、卡尺、螺纹胶。

1. **打印件预处理**：去毛刺，重点杆腔唇口；量三处关键尺寸（杆腔 Ø26±0.3、轴承位 Ø6.15±0.1、滑槽宽 4.4±0.1）。
2. **压热熔螺母**：上壳 6 处 / 下爪 2 处，240°C 垂直压入，冷却 30s。
3. **压轴承**：驱动轮 2×MR63ZZ、惰轮芯 4×MR84ZZ（台钳平行压，**禁止锤击**，否则压碎内圈）。
4. **电机与驱动轮**：N20 卡入电机舱（轴朝 −Y），Ø28 硅胶轮压入 Ø3 D 轴，M2 顶丝锁紧；手动转一圈确认不刮槽。
5. **下爪**：Ø4 轴穿过两惰轮与下爪支臂，两侧卡簧；下爪导柱耳插入上壳滑槽，装 2 根弹簧，M4 螺钉**先不锁死**。
6. **挂钩吊板 + 钢销**：吊板 2×M3 固定到背舱底面，Ø6 不锈钢销压入并点胶；挂一个标准衣架试挂取，确认不刮、不卡。
7. **杆径标定与配重（关键工序）**：
   - 把单元扣到实物杆上，下爪滑到贴合杆底，再锁 M4；
   - 旋转弹簧座把弹簧压缩到标线 **8mm**（壳体上刻线），手感"压得动、不松垮"；
   - 空载挂杆轻拨 —— 若模块自己转 >10°，在上唇内腔加热熔固定 15–20g 配重（§3.3），直到静止在设计姿态。
8. **电装与自检**：电池仓 + 密封圈 + 仓盖；线束走背舱侧槽（避开轮）；上电自检：编码器计数方向、轮向、LED、VL53L1X 读数；跑 10 次 20cm 往返，确认不打滑、不跑偏、不异响。

## 9. 参数化模型（`hardware/cad/`）

| 文件 | 内容 |
|---|---|
| `clip_unit.scad` | 全部机械件（上壳/下爪/钩/盖/轮），文件头是关键参数块，改 `ROD_D` 即换杆径 |
| `README.md` | 参数表、打印参数、导出命令、与本文的对应关系 |

**参数化覆盖的变量（都在 `.scad` 文件头注释里）**：`ROD_D`（杆径 20–35）、`WHEEL_D`（驱动轮 28）、`IDLER_PITCH`（惰轮轴距 60）、`FIT_CLEAR`（杆腔间隙）、`IDLER_TIRE`（包胶厚）、`HOOK_DROP`（挂点高度 48）、`SPRING_PRE`（预载压缩量）、`BODY_L` 等。

文件里带 4 条 `assert()` 自检：杆径超范围、驱动轮顶到顶盖、惰轮超出壳长、背舱放不下 18650、挂点离下爪太近（衣架会干涉）——**改参数改错会直接报错，不会静默出一个装不上的件**。

```bash
# 换 Ø32 杆，只导上壳
openscad -D 'ROD_D=32' -D 'PART="top_shell"' -o top_shell_32.stl clip_unit.scad
# 导整套打印排版
openscad -D 'PART="print_layout"' -o plate.3mf clip_unit.scad
```

**本环境没有 OpenSCAD 可执行文件**，以上命令未在本机跑过；文件按 OpenSCAD 2019.05+ 语法编写（`assert`/`echo`/Customizer 分组头），需要渲染时在一台装了 OpenSCAD 的机器上验证——这是 §12 的未验证项 V1。

| # | 失效模式 | 原因 | 后果 | 检测/预防 | 对策 |
|---|---|---|---|---|---|
| F1 | 硅胶轮打滑，走不动 | 杆面有油/水/灰，μ<0.1 | 定位失败，演示卡住 | 上电做 3s 空转测滑 | 酒精擦杆；预载调 30N；备 TPU 轮 |

## 10.5 墙体 / 伸缩杆 / 长杆的机械适配

> 场景细节见 [docs/18-安装场景与墙体适配.md](18-安装场景与墙体适配.md)；这里只写结构上必须满足的几条。

| 场景 | 结构要求 |
|---|---|
| 两端是墙（壁龛阳台） | 端部挡块用**抱箍 + 尼龙块**固定，不钻墙；归零靠堵转判据，不依赖磁铁；单元不越过挡块，收衣只向有空间一侧 |
| 伸缩杆（Ø25+Ø22，2—3mm 台阶） | 摩擦轮弹簧预压行程 ≥8mm（现设计可调）；过缝降速 20mm/s；接缝设为禁停区；演示优先用等径杆 |
| 杆中心距墙 <80mm | 结构上无法避免衣摆蹭墙 → 说明书明确"该侧不建议挂大件"；挂钩偏置 20mm 为 P1 件 |
| 杆长 >1.8m | 中间挠度会吃掉牵引余量 → 建议加"上方吊撑"（吊点在杆上方，不挡轮面）；>2.4m 必须加 |
| 方杆/细杆 | C 形夹爪换 V 形/小径夹爪（P1，SCAD 参数可改） |

**演示口径**：现场用 **1.2m 等径 Ø25 杆 + 两端挡块**，避开伸缩杆接缝与长杆挠度这两个变量；产品说明里再讲适配范围。

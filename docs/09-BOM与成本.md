> 这份文档回答一个问题：**做一套能上台演示的东西要花多少钱、钱花在哪、卖多少钱才不亏。**
>

>
> **价格口径**：所有价格标注为 **参考价（2026-11 淘宝/立创估算）**，人民币，单件小批量零售裸价。**不是询价单，不构成采购承诺**；下单前重新比价，尤其是 VL53L1X（原厂/兼容差 3 倍）和 18650（虚标重灾区）。
>
> **成本口径已锁定**（`docs/_shared-context.md` §3，2026-11-23 Lead 裁决）：单单元打样 ¥150、整机打样 ¥850（不含 RDK）、含 RDK ¥1,400、量产 1 万台 ¥125/单元、整机 ¥650。本文所有章节按这套数字写，不再有第二套口径。

### 5.4 零售与毛利推导（原"45%"结论已失效，重算）

`docs/_shared-context.md` §3 锁定的四档零售价：**Lite ¥399（2 单元 + 手机直连）/ Pro Core ¥999（4 单元 + ESP32 网关）/ Pro Vision ¥1,899（4 单元 + RDK 视觉中枢）/ 加购单元 ¥199**。

按量产成本推毛利（**不含渠道分成、物流、售后、研发摊销**——真实净利要再扣一层）：

| 档位 | 售价 | 成本构成 | 成本 | 毛利 | 毛利率 |
|---|---|---|---|---|---|
| **加购单元** | ¥199 | 单单元 ¥125 | ¥125 | ¥74 | **37.2%** |
| **Lite**（2 单元+手机） | ¥399 | 2×125 + 包装/说明 ¥20 | ¥270 | ¥129 | **32.3%** |
| **Pro Core**（4 单元+ESP32 网关） | ¥999 | 4×125 ¥500 + 网关（ESP32+电源+壳+装配）¥80 + 包装 ¥20 | ¥600 | ¥399 | **39.9%** |
| **Pro Vision**（4 单元+RDK 中枢） | ¥1,899 | 4×125 ¥500 + 中枢（含 RDK）¥650 | ¥1,150 | ¥749 | **39.4%** |
| Pro Vision + 深度相机（P1） | ¥1,899 | + 深度相机量采 ¥450 | ¥1,600 | ¥299 | 15.7% |

**检查原来那句"RDK 占了零售成本的 45%"**：

- 结论：**这条推导在新口径下不成立了，必须删掉/改写**。原因是产品分层变了——**Pro Core 不含 RDK（用 ESP32 网关）**，RDK 只出现在 Pro Vision。
- 现在正确的说法是：**在 Pro Vision 这一档，RDK X5 占 BOM 成本 56.5%（650/1,150），是单一最大项**；但该档售价 ¥1,899 足以覆盖，毛利率 39.4%，和 Pro Core 基本持平。
- 真正需要警惕的是两件事：
  1. **Pro Vision 加深度相机后毛利率掉到 15.7%** → 深度相机不能标配，只能做加购或 Pro Vision 高配版（定价需 ≥¥2,400 才能保持 30% 毛利）。
  2. **渠道分成**：硬件走电商/线下渠道通常让出 25%—35%。按 30% 算，Pro Core 净利 = 39.9% − 30% = **约 10%**，Lite 只剩 2%——**Lite 这一档本质是获客价，不靠它赚钱**，利润要靠加购单元（37%）和 Pro Vision。
- 如果 RDK 量采价谈不下来（比如 ≥¥700）：Pro Vision 成本变 ¥1,350，毛利 ¥549（28.9%），仍在可接受区；但若想把 Pro Core 换成 RDK 中枢，Pro Core 会直接变成负毛利（见下）。

**反推：Pro Core 若改用 RDK 中枢** → 成本 500 + 650 = ¥1,150 > 售价 ¥999，**毛利率 −15%**。所以「Pro Core 用 ESP32 网关、Pro Vision 才上 RDK」这个分层不是随便定的，是**成本决定的**——这条正好可以写进答辩的商业模式页。

## 6. 采购风险与下单建议

### 6.1 四个价格陷阱

| 陷阱 | 表现 | 应对 |
|---|---|---|
| **18650 虚标** | 标 2000mAh 实测 1200—1500mAh，"待机 1.9 天"变 1.2 天 | 只买带保护板正规电芯；到货用容量测试仪抽测 1 颗，实测值写回文档 |
| **VL53L1X 原厂/兼容** | ¥20 兼容件量程和一致性打折，深色衣物上更差 | 买 2 个原厂 + 2 个兼容对比；演示用原厂，兼容做备用 |
| **Type-C 线不是 5A** | 3A 线满载时 VBUS 掉到 4.6V → X5 随机重启 | 买明确标 5A/100W 的线；用功率计实测 |
| **N20 转速/扭矩不符** | 标 30rpm 实物 25 或 40rpm，堵转 0.6—1.2A 浮动 | 一次买 6 个（4 用 2 备），逐个测转速再配对 |

## 7. 一句话总结（答辩可用）

> 一套四个单元加一个中枢，**打样 ¥850（不含 RDK）**：机械占单元成本的 43%，是最大的单项；RDK 现场发，所以真要准备的是 **¥1,299**。量产 1 万台单单元 **¥125**、整机 **¥650**；零售 4 档里**加购单元 ¥199 毛利最高（37%）**，Pro Core ¥999 与 Pro Vision ¥1,899 都约 39%，**但扣掉 30% 渠道分成后 Lite 只剩 2%——它本来就是获客价**。

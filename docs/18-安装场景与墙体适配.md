# 安装场景与墙体适配

> **这份文档回答四个问题：**
> 1. 界面上的 `01 / 02 / 03 / 04` 到底是什么？
> 2. 晾衣杆长度、单元数量能不能变？
> 3. 两端是墙（壁龛式阳台）怎么装？
> 4. 伸缩杆、细杆、长杆、栏杆这些"不标准"的杆怎么办？
>
> 结论先行：**单元编号是物理模块的地址，不是衣服编号；杆长和单元数都做成可配置（0.8—2.4m / 2—8 个）；两端有墙时按"端部挡块 + 单侧收衣"设计，不假设能越过墙。**

---

## 0. 先把 `01—04` 说清楚

**`01 / 02 / 03 / 04` 是"套挂单元"的编号，也就是模块的物理地址**，不是衣服的编号。

- 每个单元里有 ESP32-C3，固件里烧一个 `UNIT_ID=01…08`；MQTT 主题是 `hangflow/unit/01/...`，中枢靠这个地址区分"谁是谁"。
- 一件衣服挂在对应的单元上，所以"单元 01 上挂的是速干 T 恤"——但**衣服本身没有 ID**（没有 RFID，也不值得加）。
- 界面上的正确读法是：**单元 01（模块）+ 速干 T 恤（挂在它上面的衣服）**。之前的原型只显示 `01`，容易让人以为是"第 1 件衣服"，这是 UI 表达问题，已经改成"单元 01"。
- 增删单元时，编号只是地址；删掉 03 之后，剩下的可以是 01/02/04/05，也可以重排成 01/02/03/04——**中枢按地址识别，不要求连续**。

> 为什么不用衣服编号？因为衣物是软的、会换、会被收走；模块是固定的、有电、有地址。**给"会动的挂点"编号，不给"衣服"编号**，这才是可维护的做法。

## 1. 参数化：杆长和单元数都应该是变量

| 参数 | 范围 | 默认（演示） | 说明 |
|---|---|---|---|
| 杆长 `L` | **0.8—2.4 m** | 1.2 m | 家用常见 1.2/1.5/1.8/2.0/2.4m；伸缩杆按"完全展开长度"算 |
| 单元数 `N` | **2—8 个** | 4 | RDK 带 8 个无压力；超过 8 个建议第二个中枢 |
| 端部余量 `m` | 50 mm（可调 30—80） | 50 mm | 两端挡块/墙支架占位；靠墙时按实际支架厚度设 |
| 最小间隙 `g_min` | 30 mm | 30 mm | 安全下限 |
| 杆径 `D` | 20—35 mm | 25 mm | 夹爪自适应；伸缩杆两节可能不同径 |
| 杆中心到墙 `d_wall` | ≥120 mm（建议 150） | — | 低于 80mm 时衣摆/衣架会蹭墙 |

**可行性判据**（中枢在界面上实时算）：

```
可用长度 = L − 2m
需要长度 = Σ t_i + (N−1) × g_min
若 需要长度 > 可用长度 → 提示"太挤了"：
   建议 A：减少单元（给出最少要拿掉几个）
   建议 B：加长杆 / 缩小 m
   建议 C：把 g_min 降到 20mm（需用户确认，不推荐长期）
```

- 该逻辑已在 `sim/spacing_planner.py` 实现（不可行返回 `drop_advice`），`planner.py` 只是加坐标偏移。
- 界面必须**显式告警**，不允许静默把间距压到 0 或让模块重叠。

### 1.1 单元数量变化时的行为

| 动作 | 中枢行为 |
|---|---|
| 加一个单元 | 上电 → 归零 → 发 `state` → 中枢自动登记（`unit/+/state`）→ 界面出现新卡片 → 重新规划 |
| 删一个单元 | 界面移除 → 中枢不再给它发指令 → 该单元原地待机（或长按关机）→ 重新规划 |
| 换编号 | 改固件 `UNIT_ID` 重烧，或界面做"重命名"映射；**不建议现场改**，贴纸写清楚 |
| 超过 8 个 | 中枢仍能收，但 Wi-Fi/MQTT 与网页会变慢；建议第二个 RDK 或分区 |

> 产品上建议**按单元卖**（加购 ¥199），杆多长、挂几件由用户决定；软件不能写死 4。

## 2. 两端是墙：壁龛式阳台怎么装

这是中国城市阳台最常见的形态：**左右都是承重墙/瓷砖墙，杆两端固定在不锈钢法兰座上**。

### 2.1 几何约束（先量再装）

```
墙 ──[法兰座]════════ 晾衣杆 ════════[法兰座]── 墙
      ↑ m=50mm                          ↑ m=50mm
      └────────── 可用长度 = L − 2m ─────┘
```

| 量什么 | 怎么量 | 影响 |
|---|---|---|
| 两墙净距 | 卷尺贴墙量 3 个高度 | 决定 `L`（不是杆标称长度） |
| 法兰座凸出墙面 | 直尺量 | 决定 `m`（端部余量） |
| 杆到墙的距离 | 杆中心到墙面 | 决定 `d_wall`，<80mm 要提醒 |
| 杆两端直径 | 卡尺/卷尺绕周长 | 伸缩杆两节可能 25/22mm |
| 杆的挠度 | 挂 10kg 看中间下垂 | >1.8m 建议加中间吊撑 |

### 2.2 两端有墙时的四条设计规则

1. **端部挡块 = 归零基准**：左端法兰座上加一个尼龙挡块/抱箍，单元撞到它即"位置 0"（堵转判据，见 docs/05 §11）。右端也加挡块，防止冲出。
2. **单元不能越过挡块**：所以**换序（P2）在两端有墙时物理上更不可能**；P0/P1 本来就不换序，这条只是再次确认。
3. **收衣只能往一侧收**：默认收向"有操作空间"的一侧（通常是靠近门/窗的一侧）；两端都顶死时，收衣 = 全部聚到中间或靠一侧，留出取衣空间。界面提供"收衣方向"选项。
4. **衣摆会蹭墙**：衣架垂直于杆，衣服宽度约 42cm；如果杆离墙只有 5—8cm，衣服会贴墙（不通风、蹭脏）。**建议 `d_wall ≥120mm`**；不够时：
   - 用薄型衣架/儿童衣架；
   - 单元挂钩向房间侧偏置 20mm（P1 结构件）；
   - 或明确告知"该侧不建议挂大件"。

### 2.3 安装顺序（两端已固定杆的情况）

1. 量 `L`、`m`、`d_wall`、两端杆径；
2. 把左端挡块/归零块装上（抱箍 + 尼龙块，不钻墙）；
3. 单元从杆下方**斜着卡入**（C 形夹爪开口朝下），逐个夹上；不需要拆杆；
4. 单元之间先留 15cm，避免上电归零时互相顶；
5. 上电 → 自动归零（向左撞挡块）→ 网页登记；
6. 在网页输入实际 `L`、`m`、`d_wall`，重新规划；
7. 先手动低速走一遍全程，确认不蹭墙、不撞法兰座。

> **不需要拆杆、不需要打孔**——这是"套挂式"的核心卖点；挡块用抱箍/扎带固定即可。

### 2.4 相机怎么放（有墙反而好办）

- 两端有墙时，相机放**房间侧**（人站的那侧），距杆 1.2—1.5m，正对杆；
- 阳台进深不足 1.2m 时：相机贴对面墙、用广角（水平 FOV ≥90°），距离 0.8—1.0m，标定后仍可用（误差会略大，见 docs/06 §2.3）；
- 不要把相机放在杆的正上方（俯视会看到衣架顶，标记被挡）；
- 相机不要被晾着的衣服挡住——放在杆的一端斜 30° 也可以，只要能看到 4 个标记。

## 3. 伸缩杆（两节/三节）：最容易翻车的"标准件"

家用伸缩晾衣杆通常是 **Ø25 + Ø22** 两节套接，接缝处有一个 **2—3mm 的台阶**。

| 问题 | 影响 | 对策 |
|---|---|---|
| 台阶处轮子瞬间悬空/撞击 | 打滑、丢步、异响 | 摩擦轮弹簧行程 ≥8mm；过台阶降速到 20mm/s；接缝位置在界面标出来 |
| 两节直径不同 | 夹爪夹持力变化 | 夹爪 20—35mm 自适应 + TPU 垫；到货实测两节夹持力 |
| 伸缩杆刚度低 | 中间下垂，模块爬坡 | >1.8m 加中间吊撑（从天花板/上沿吊，不挡杆面）；或限制单侧 4 个单元 |
| 接缝处不圆/有毛刺 | 刮伤轮面 | 装前用砂纸打磨接缝，贴一圈透明胶带过渡 |
| 杆端塑料堵头 | 挡块位置不稳 | 用抱箍挡块，不依赖堵头 |

**软件对策**：

- 标定时输入"接缝位置"（离左端多少 mm），规划器把接缝当作"禁停区"（模块不停在接缝上）；
- 过接缝时速度降到 20mm/s，并允许一次打滑（视觉校正兜底）；
- 如果接缝台阶 >3mm，建议换一根等径杆（演示用等径杆）。

## 4. 长杆（>1.8m）与中间支撑

2.4m 杆挂 8 个单元 + 8 件湿衣（约 16kg），中间挠度可能到 2—4cm。**杆一弯，模块就爬坡，摩擦轮牵引力不够**。

| 方案 | 做法 | 代价 |
|---|---|---|
| 中间吊撑（推荐） | 从阳台顶/晾衣架横梁垂一根吊杆，吊住杆中部；吊杆在杆上方，不挡模块 | 需要顶部固定点 |
| 中间抱箍支撑 | 抱箍 + 斜撑到墙 | 会挡住模块通过（只能在支撑两侧分区） |
| 降低负载 | 单侧 ≤4 个单元、湿衣分两次晾 | 体验下降 |
| 换等径加厚杆 | Ø32×1.2mm 不锈钢 | 成本 +¥80，但最稳 |

**产品口径**：**≤1.8m 不需要中间支撑；>1.8m 建议加吊撑；>2.4m 必须加。** 这句话写进说明书。

## 5. 其它场景

| 场景 | 关键问题 | 适配 |
|---|---|---|
| 顶天立地杆（两端顶墙） | 杆会轻微上下弹 | 挡块用抱箍；归零用堵转判据，不依赖磁铁 |
| 飘窗/栏杆（圆管 Ø20 以下） | 夹爪夹不紧 | 换小径夹爪（P1）；或用转接套（3D 打印） |
| 方形杆 | C 形夹爪接触面小 | 换 V 形夹爪（P1，SCAD 参数可改） |
| 杆上有挂钩/衣架 | 模块过不去 | 规划时把障碍位置设为禁停区；或先取下 |
| 阳台柜挡住一端 | 端部余量加大 | `m` 设为柜深 + 20mm，收衣方向选另一端 |
| 户外/淋雨 | 不防水 | 明确"不建议长期户外"，IPX2 只防滴水 |

## 6. 数量/长度变化后的验收清单

- [ ] 改 `L` 后，界面标尺、间距、告警都更新；杆视图与实际杆比例一致
- [ ] 改 `N` 后，新增单元能上线；删除的单元不再收到指令
- [ ] 挤不下时出现"建议减少 k 个单元"的提示，且不会重叠
- [ ] 两端墙：左端归零成功；右端不撞墙；收衣方向可选
- [ ] 杆离墙 <80mm 时出现"衣摆可能蹭墙"提示
- [ ] 伸缩杆：接缝处降速通过，不丢步（连续 10 次）
- [ ] >1.8m：有吊撑或明确提示

# 测试与验收

> **这份文档回答：怎么证明"能行"，而不是"看起来能行"。**
> 原则：**每条结论都要有能把它证伪的测量方式。** 全绿但测错了，比红着更危险。

---

## 1. 测试金字塔

```
          ┌─────────────────┐
          │ 现场验收（10 连）│  真实环境、真实观众
          ├─────────────────┤
          │ 硬件在环 HIL     │  真机 + mock 视觉
          ├─────────────────┤
          │ 集成测试（mock） │  4 虚拟单元 + 真实服务
          ├─────────────────┤
          │ 单元测试         │  规划器/重排/协议/安全
          └─────────────────┘
```

- **单元**：纯函数，无 IO，毫秒级，每次改动都跑。
- **集成（mock）**：`--mock` 模式，验证状态机、超时、急停。
- **HIL**：1—4 个真单元，网页/视觉真实，验证时序与安全。
- **现场**：最终验收，连续 10 次。

## 2. 单元测试清单（pytest）

| 测试 | 输入 | 断言 |
|---|---|---|
| `test_equalize_basic` | N=4, L=1200, t=[40]*4, q 相同 | g_i 全等；Σg + Σt + 2m = L；x 单调 |
| `test_min_gap_floor` | N=6, 空间紧张 | 所有 g_i ≥ g_min |
| `test_infeasible` | N=8, L=600 | 抛 `Infeasible(k)`，k 正确（最少取下件数） |
| `test_weighted` | q=[1,0.6,0.2] | g 按权重降序，且 Σg 守恒 |
| `test_extreme_thickness` | 一件 t=500 | 不重叠，给出提示 |
| `test_reorder_identity` | 当前=目标 | 0 步 |
| `test_reorder_reverse` | 逆序 | 步数 = N-1 或更优，最终顺序正确 |
| `test_reorder_block` | 已有最长块 | 保留块不动，只移动其余 |
| `test_protocol_seq` | 旧 seq 指令 | 被丢弃 |
| `test_protocol_bad_json` | 坏包 | 不崩溃，返回错误 |
| `test_safety_estop` | 运动中急停 | 100ms 内停 |
| `test_timeout` | 模拟不走 | 10s 后报 E08 |

**运行**：`pytest software/tests -q`，要求全绿且 <5s。

## 3. 集成测试（mock，无硬件）

| 场景 | Given | When | Then |
|---|---|---|---|
| 一键等距 | 4 单元在 0—300mm 挤着 | 调 `/api/mode equalize` | 45s 内全部到位，间距 = 目标 ±10mm |
| 智能分配 | 湿度 [0.9,0.5,0.2,0.9] | 调 smart | 湿的两侧间隙更大 |
| 收衣 | 任意布局 | 调 gather | 全部到右端，间距 60mm |
| 急停 | 运动中 | `/api/estop` | 全停，状态 ESTOP，不可自动恢复 |
| 断网 | mock 单元停止心跳 | 等 1s | 状态显示离线，规划暂停 |
| 堵转 | 注入 stall | — | E03 事件 + 全局停 |
| 低电 | 注入 batt=3.3V | — | E05 + 只允许收衣 |
| 重复指令 | 同一 seq 发两次 | — | 只执行一次 |
| 断线重连 | 单元重启 | — | 30s 内重新上线并归零 |

**验收**：`pytest software/tests/integration` 全绿；`scripts/smoke_test.py --mock` 通过。

## 4. 硬件在环（HIL）测试

| 测试 | 方法 | 通过标准 |
|---|---|---|
| 空载行走 | 单模块走 1m，卷尺量 | 编码器 vs 卷尺误差 <2% |
| 负载行走 | 挂 2kg 水袋走 1m | 误差 <5%；不打滑（无尖叫） |
| 夹持 | 挂 5kg 静置 10min；10N 侧推 | 不滑、不转、杆不歪 |
| 反复定位 | 目标 200mm，来回 20 次 | 落点标准差 <3mm |
| 堵转 | 手挡住轮子 | 200ms 内停，电流 <1.5A |
| 急停 | 运动中按网页/物理键 | 100ms 内全停 |
| 断电 | 运动中拔电 | 原地停，不掉衣 |
| 续航 | 满电待机 40h；连续动作 100 次 | 电压 >3.4V；待机 44h 后仍能动作 |
| 温升 | 连续 10 分钟行走 | 外壳 <45℃ |
| 视觉定位 | 卷尺 5 个点 | 误差 <5mm |

## 5. 可证伪验收表（关键）

> 每条都是"如果没达到，就说明这个说法是错的"。不要用"感觉还行"。

| 声明 | 测量方法 | 通过判据 | 不通过说明什么 |
|---|---|---|---|
| 间距精度 ±10mm | 卷尺量实际衣架位置，与屏幕数字比，10 次 | 10 次全部 ≤10mm | 定位链路有系统误差（标定/打滑） |
| 4 件 45 秒内排开 | 秒表，从点击到"全部到位" | ≤45s（典型 30s） | 串行策略太慢或某个单元卡 |
| 视觉定位 ±5mm | ArUco 读数 vs 卷尺 5 点 | 平均误差 ≤5mm | 内参/标记尺寸/透视误差 |
| 打滑 <5% | 走 1m 后编码器 vs 卷尺 | 偏差 ≤5% | 正压力不足/轮面材质不对 |
| 续航 3000 次（或 2 天待机） | 满电到 3.4V 计数 | ≥3000 次动作 或 ≥40h 在线待机 | 电池容量/升压效率/待机电流超标 |
| 急停 <100ms | 录像 240fps 或逻辑分析仪 | 100ms 内轮停 | 固件优先级/通信延迟有问题 |
| 连续 10 次成功 | 现场完整流程 10 遍 | 10/10 | 存在随机故障（接触/网络） |
| 断网自停 | 关热点，看单元 | 500ms 内停 | 看门狗没生效 |
| **杆长/单元数可变** | 设 L=2000mm、N=6，再设 L=900mm、N=6 | 布局不重叠；挤不下时给出"减少 k 个"告警；耗时 ≤15s/单元；界面标尺与实际一致 | 规划器写死 4 单元/1.2m |
| **两端有墙** | L=两墙净距，m=法兰厚度+10 | 左端归零成功、右端不撞墙、收衣方向可选、离墙 <80mm 有提示 | 没考虑端部占位/衣摆蹭墙 |
| **伸缩杆接缝** | Ø25+Ø22 杆，接缝处停一次再走 | 连续 10 次过缝不丢步、不异响 | 弹簧行程不够/未降速 |

**记录表**：`assets/test/2026-12-XX-test.csv`，列：`日期,测试项,方法,预期,实测,结论,测试人`。

## 7. 反"假绿"检查（写给自己）

| 陷阱 | 表现 | 避免 |
|---|---|---|
| mock 全绿 ≠ 真机能跑 | 仿真里没有打滑/延迟 | HIL 必须做 |
| 编码器自证 | 用编码器验证编码器 | 用卷尺/视觉独立验证 |
| 只测最好情况 | 新电池、空载、室内光 | 测低电、负载、展台灯 |
| 平均值掩盖抖动 | 平均 5mm 但偶尔 30mm | 记录最大值与分布 |
| 演示成功一次就放心 | 偶然 | 连续 10 次 |
| 观众不在场 | 没人挡光/碰桌 | 彩排时拉人围观 |

## 8. 回归与发布

- 每次改代码：`pytest`（<10s）→ mock 冒烟（20s）→ 真机快测（1min）。
- 现场改动：必须 `git commit` + 打 tag（`demo-YYYYmmdd-HHMM`），可回滚。
- 每天 24:00 打一个"当天可演示"的 tag；出问题回滚到上一个 tag。

## 10. 验收完成定义（Definition of Done）

一个功能"完成" = ①单元测试 ✅ ②集成测试 ✅ ③HIL 一次 ✅ ④写进文档 ✅ ⑤演示脚本里能讲 ✅。
缺一项都算"半成品"，不进演示。

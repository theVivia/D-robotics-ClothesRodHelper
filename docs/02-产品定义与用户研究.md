# 产品定义与用户研究

> **这份文档回答：这是给谁做的、凭什么他们会用、产品边界在哪。**
> 说明：本文的用户洞察基于公开常识、产品经验与团队体感，**尚未做正式访谈**；赛前第 3—5 天安排 5 个快速访谈补证（见 [docs/10](10-赛前12天准备计划.md)）。引用数字均为估算。

## 1. 一个具体的人：周六早上，上海，梅雨季

> 林，28 岁，租房，阳台一根 1.8m 的不锈钢杆。
> 周四晚上洗了 6 件衣服，挂上去的时候没空间了，只能挤在一起。周六早上摸了一下：最外面那件干了，中间两件还是潮的，凑近闻有股闷味。他把中间两件挪开一点，手一滑，杆晃了，一件 T 恤掉到地上。
> 他其实知道"应该分开挂"，但每次都要爬上去够、推、再调整，最后算了，"就这样吧"。

**这个"算了"就是产品机会。** 用户不是不知道要分开，是**手动调整的成本太高**。

## 2. 用户画像（按需求强度排序）

| 画像 | 场景 | 核心诉求 | 付费意愿 |
|---|---|---|---|
| **租房青年**（20—35） | 老小区阳台、朝北、只有一根杆 | 零改造、搬家能带走、别太贵 | ¥399（Lite） |
| **有孩家庭**（28—45） | 每天洗大量小件，杆上永远满 | 干得快、少返工、别掉 | ¥399—699 |
| **与老人同住** | 老人够不着高杆、腰不好 | 不用爬高、一键搞定、字大按钮大 | ¥399—599 |
| **学生/宿舍** | 公共晾衣区、杆少人多 | 便宜、夹上就用、不怕丢 | ¥99—199（Lite） |
| **长租公寓/酒店布草间**（B 端） | 批量晾晒、要效率 | 可管理、耐用、集中控制 | 按套采购 |

**最锋利的切入点：租房青年。** 他们不能改装（房东不让）、不愿买大件（搬家麻烦）、但受潮湿折磨最深。产品故事"夹上就用、搬家带走"对他们几乎是刚需。

## 3. 用户任务（JTBD）

> 当我洗完一批衣服要晾的时候，我想让它们**各自有风能穿过去**，这样我不用一直盯着、不用返工重洗，第二天能穿上干爽的衣服。

拆成四件事：

1. **排开**：把已有衣服之间的空隙变大；
2. **按需**：不同衣物给不同间距（被单 vs 袜子）；
3. **省事**：不用爬高、不用反复推；
4. **收拢**：要收的时候一次收完，别一件件够。

## 4. 现有方案对比

| 方案 | 价格 | 能解决什么 | 没解决什么 |
|---|---|---|---|
| 手推衣服 | ¥0 | 临时排开 | 够不着、推不齐、杆会歪、湿衣重 |
| 衣架夹/分隔夹 | ¥10—50 | 固定间距 | 只能固定几个点、不能调、不能收 |
| 双杆/伸缩晾衣杆 | ¥50—200 | 增加挂点 | 还是挤、仍需手推、要安装 |
| 电动晾衣架（升降/风干/烘干） | ¥800—3000 | 升降、吹风、烘干 | **要拆旧装新、不能调间距、贵**、占顶 |
| 烘干机 | ¥2000—6000 | 彻底解决 | 贵、占地方、费电、伤衣物 |
| 除湿机 | ¥500—2000 | 降环境湿度 | 不解决衣物间无风道的问题、费电 |
| **衣序 HangFlow** | **¥399—1,899（Lite / Pro Core / Pro Vision）** | **零改造 + 自动调间距 + 收拢** | 需要杆（20—35mm）、单模块承重 5kg |

**空白点很清楚**：所有方案都在解决"挂"和"干"，没人解决"**挂上去之后的空间关系**"。

## 5. 价值主张

**一句话**：给已有晾衣杆装上会自己走的衣架，让每件衣服都吹得到风。

**价值主张画布（简版）**

- **痛点**：挤、不干、返潮、够不着、推不齐。
- **收益**：干得快、不返工、不爬高、一键搞定、搬家带走。
- **产品**：套挂模块 + 视觉中枢 + 手机网页。
- **替代品**：手推、晾衣夹、电动晾衣架、烘干机。

## 6. 需求优先级（MoSCoW）

| 级别 | 需求 | 说明 |
|---|---|---|
| **Must** | 模块夹稳不掉；能沿杆移动；一键等距；手机可控；急停有效 | 48h 现场必须全通 |
| **Must** | 间距显示（视觉读数）；低电/离线提示 | 让评委"看见智能" |
| **Should** | 智能分配（按湿度权重）；收衣模式；视觉闭环校准 | 决定技术分 |
| **Should** | 断电即停 + 短时保持（机械自锁为 P1）、堵转保护、防撞 | 安全分 |
| **Could** | 语音控制；场景预设（内衣/被单/羽绒服）；定时收衣 | P2 |
| **Won't（这版不做）** | 自动挂衣/取衣机械臂；雨棚联动；太阳能 | 48h 做不完，明确说"不做"反而专业 |

## 8. 产品边界（明确不做什么）

- **不替代晾衣杆**：没有杆的场景（烘干机家庭、无阳台）不适用。
- **不做户外淋雨防护**：不承诺 IPX5，户外长期暴露需选配罩（P2）。
- **不做自动挂取**：挂衣/收衣仍需人手，我们只解决"挂上之后"。
- **不碰重载**：单件 >5kg（湿棉被）不适用，会提示"请手动"。
- **不做多杆联动**（这版）：一根杆 4—8 单元。

> 明确"不做什么"是产品定义的一部分，也避免评委问"那被子呢"时答不上来。

## 9. 品牌与命名

- **中文名：衣序** —— "衣"是对象，"序"是价值（秩序/排序）。两个字，好记，不土。
- **英文名：HangFlow** —— Hang（挂）+ Flow（风道/流动），双关"挂着的风"。
- **Slogan**：不换晾衣杆，让衣服自己让出风道。
- **视觉**：深色（近黑）+ 高对比 + 一点金；科技感，不卖萌（符合目标用户与评委审美）。
- **命名备选**（若商标冲突）：晾序、风隙、衣间、HangGap。

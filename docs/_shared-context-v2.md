## 1. 产品是什么

**在现有晾衣杆上，按"墙/边缘—调节器—衣物—调节器—衣物—…—调节器—墙/边缘"串起 K+1 个抱箍式伸缩圆柱；衣架挂在相邻两个调节器端头的 10mm 接缝里。圆柱伸长 → 把两边衣服推开；缩短 → 让它们靠拢。调节器不承重、不挂衣服。**

- 衣服/衣架仍然挂在**原来的晾衣杆**上。
- 一个调节器的长度 = 它两端两个接缝之间的净风道。
- 每个调节器有**一对可卡住杆的装置**（两端各一个夹持）：锁一端 → 单向伸缩；锁两端 → 定点拉伸/固定绝对位置。
- 两端调节器夹住杆后顶住墙/挡块做预紧；**不再使用恒力卷簧**。
- 每个调节器有**唯一编码**（01、02、…），装上去什么顺序就什么顺序；RDK 视觉**智能识别**编码与位置，**不换序**。

## 2. 关键尺寸与公式（锁定）

| 符号 | 含义 | 值 |
|---|---|---|
| `K` | 衣服件数 | 2—8（演示 4） |
| `K+1` | 调节器数量（两端各一个） | 演示 5（2 端 + 3 内） |
| `t_h` | 单个衣架沿杆厚度（含衣物压扁） | **10 mm（1cm 够用）** |
| `L_i` | 第 i 个调节器长度（i=0…K） | 内部动力段 100—220 mm；40—100 mm 用被动短套；端部段 30—120 mm（可被动/手动） |
| `g_i` | 第 i 与 i+1 件之间的净风道 | 内部段 `g_i = L_i` |
| 总链长 | 所有调节器 + 衣架 | `Σ_{i=0}^{K} L_i + K×10mm` |
| 杆长 | 可用长度 | 0.8—2.4 m，两端余量 50mm（靠墙按法兰厚度调） |

**位置递推**（从左墙/挡块起）：

```
x_cloth1 = L_0 + 10/2
x_cloth(i+1) = x_cloth(i) + 10 + L_i      (i=1…K−1，内部段)
末调节器 L_K 接右墙/挡块，用于预紧与端部余量
        = Σ L_0…L_K + K×10mm + 两端安装余量
```

**可行性**：`ΣL + K×10mm + 两端安装余量 ≤ 可用杆长`；端部调节器可伸出顶墙，形成 5—10mm 预紧。
**演示算例**：K=4、内部净风道 10cm → 3×100=300mm；端部 L0=L4≈60mm；总链长 300+120+40=460mm；1.2m 杆剩余由端部调节器伸出补偿/预紧。

## 3. 系统形态

```
墙/边缘 ─[调节器0]─ 衣架1 ─[调节器1]─ 衣架2 ─[调节器2]─ 衣架3 ─[调节器3]─ 衣架4 ─[调节器4]─ 墙/边缘
           接缝1            接缝2            接缝3            接缝4
```

- **抱箍式**：每个圆柱两半壳体扣在杆上，不拆杆、不打孔；内衬低摩擦导向。
- **锥面收口夹头（双端）**：每个圆柱两端各有一个锥面收口夹头（开槽夹头环 + 外套筒，套筒内滑锁紧；P0 手动；P1 可电动），夹住杆或端部挡块：
  - 只锁左端 → 伸长时右端单向伸出（定点拉伸）；
  - 只锁右端 → 左端单向伸出；
  - 两端都锁 → 长度/位置固定（绝对定位）；
  - 两端都松 → 可沿杆滑动/整段取下。
- **接缝**：相邻两个圆柱的端头 U 形托之间留 10mm，衣架钩在里面可自由转动、不承重。
- **端部**：左右端调节器夹住杆后伸出顶住墙/挡块，给整条链预紧；不再有独立卷簧。
- **驱动**：每个圆柱 N20 减速电机 + T8 梯形丝杆；AS5600 测丝杆转角→长度；ESP32-C3 闭环；1000mAh 18650；USB-C。
- **中枢**：RDK X5 + USB 相机，ArUco 识别 ID 与位置；规划每段长度；MQTT/网页。

## 4. 单元解剖

```
   左夹持件                右夹持件
      │                       │
 ┌────┴───────────────────────┴────┐
 │ 外套管（电控/电池）              │
 │   ┌─────────────────────────┐   │
 │   │ 内套管（丝杆螺母，伸缩） │   │
 │   └─────────────────────────┘   │
 └─────────────────────────────────┘
      ▲ 抱箍两半扣在杆上
      ▲ N20 + T8 丝杆 + AS5600
      ▲ ESP32-C3 + 1000mAh + USB-C
      ▲ 两端夹持件（锥面收口夹头）+ 微动开关
```

| 部件 | 作用 | 关键设计 |
|---|---|---|
| 抱箍两半 | 挂在杆上，不拆杆 | 铰链+卡扣；TPU/PTFE 内衬 |
| 双端锥面收口夹头 | 固定绝对位置/选择单向伸缩 | 锥面收口夹头：开槽夹头环 + 外套筒，套筒轴向内滑 5—8mm，锥面径向压紧杆；反向拉出松开；夹持力 ≥40N；微动开关反馈锁/松 |
| 外套管 | 固定段/电控仓 | Ø42—46mm，PETG/ASA |
| 内套管 | 伸出段 | 同轴，间隙 ≤0.15mm，防转筋 |
| 丝杆+螺母 | 旋转→直线 | T8 梯形丝杆，导程 8mm（四头）；自锁或刹车 |
| 电机 | 驱动 | N20 6V 30rpm，额定 ≥0.1N·m |
| 长度传感 | 闭环 | AS5600 装丝杆轴 |
| 端头 U 托 | 10mm 接缝，夹住衣架钩 | 圆角、防夹手 |

**为什么用锥面收口夹头**：链不再靠卷簧/端部张力"浮动"，每个调节器可以把一端锁死在杆上，另一端做单向伸缩；也能两端锁死做绝对定位。这样不会"推着整条链跑"，长度和位置都可控。

## 6. 四种模式

| 模式 | 行为 |
|---|---|
| 手动逐段 | 选第 i 段，锁一端、伸另一端；滑杆调长度 |
| 一键等距 | 内部段全设目标净风道（默认 10cm）；端部段保持预紧 |
| 按湿度加权 | 湿的两侧段更长；总长不超可用 |
| 收衣 | 内部段缩到最短，端部段回缩，衣架靠拢到一侧 |

## 7. 演示参数

- 杆：1.2m 等径 Ø25；左右墙/挡块（演示架两端）。
- 5 个调节器（01—05）+ 4 个衣架（10mm 接缝）。
- 内部净风道 10cm ×3；端部段 60mm ×2；总链长 460mm。
- 演示动作：全松→收衣→锁端部→一键等距→锁单段定点拉伸→加一件衣服（加 1 接缝 + 1 调节器，保持 K+1）→急停。
- 视觉：1.2—1.5m 正对，识别 5 个 ID，顺序校验 01—05。

## 8. 术语

- **调节器/圆柱**：抱箍式、可伸缩、双端锥面收口夹头。
- **接缝**：两个调节器端头之间的 10mm，衣架挂点。
- **内部段/端部段**：夹在衣服之间的为内部段；两端顶墙的为端部段。
- **锁端**：夹持件夹住杆；锁左/锁右/双锁决定单向伸缩或定点固定。
- **收衣**：内部段缩到最短，衣架靠拢。

算法（与 `docs/v2/10` 一致）：

```text
等距/加权：算内部目标 → Δ = Σ(新 − 旧)
          两端各吸收 −Δ/2（clamp 30–120）；一端到限位另一端补
          两端都不够 → rejected
收衣：    内部回 100（动力段最短）→ Δ 由端部内端吸收，链长仍 460
4–10 cm： 用被动短套，不进自动规划；目标 <100 mm 直接拒绝
手动拖：  单端锁、拖自由端 → 同侧端部优先吸收（外端永不动）
```

## 1. 一句话

**给已有的晾衣杆装一套"会自己走"的衣架模块，让衣服按需要让出风道——不动杆、不改装、扫码即用。**

- 中文名：衣序（让衣物有序）
- 英文名：HangFlow
- 形态：**2—8 个**套挂单元（可增删）+ 1 台 RDK X5 中枢 + 手机网页；适配 **0.8—2.4m** 杆长、20—35mm 杆径、两端墙/伸缩杆

---

## 2. 问题：不是"晾不干"，是"风进不去"

南方梅雨、回南天、冬季阴干，衣服挂在杆上互相挤着，衣物之间只剩 2–5cm。风进不去，水汽出不来，结果是：

1. **外干内湿**：外层干了，贴着的里层还是潮的，收下来一股味；
2. **返潮发霉**：一天不干，第二天湿度回升又吸回去，领口、腋下发霉点；
3. **手动推开很反人类**：湿衣服重、高杆够不着、推完杆歪了、衣架掉了；
4. **不同衣物需求不同**：被单要 20cm，袜子 5cm；但人只会"大概推一推"。

现有产品解决的是"升降"（电动晾衣架）、"烘干"（烘干机）、"除湿"（除湿机），**没有一个解决"间距"**。而间距恰恰是零成本、立刻见效的那个变量。

## 3. 方案：三个层次

| 层 | 做什么 | 关键设计 |
|---|---|---|
| **物理层** | 套挂单元夹在 20–35mm 圆杆上，自带摩擦轮沿杆走，18650 供电，不用布线 | C 形可调夹爪 + 硅胶摩擦轮 + 双惰轮防翻转 + 侧面承重挂钩 |
| **控制层** | ESP32-C3 闭环：编码器测里程、ToF 测邻距、电流测堵转，MQTT 收指令 | 速度环 + 位置环；失联 500ms 自停；低压/过流保护 |
| **智能层** | RDK X5 用相机做绝对定位（ArUco/特征），规划器算目标间距，网页给人操作 | 视觉+编码器双源融合；加权间隙分配；顺序约束与重排代价分析 |

### 四种模式（现场演示都跑一遍）

1. **手动**：手机上拖模块 / 点"宽一点、窄一点"，即时响应。
2. **一键等距**：所有衣物按当前可用杆长平均分开，3 秒排好。
3. **智能分配**：湿的、厚的、大的间隙给大；干的往边上收。按衣物"湿度权重"加权分配（算法见 [docs/06](06-视觉与算法.md)）。
4. **收衣**：全部聚拢到一端，方便一次性收走；也给"夜间防雨/防露水"留了入口。

### 安全（评委一定会问）

- **堵转即停**：PWM 在给、但 AS5600 角度 300ms 内不变 → 立即停（DRV8833 模块没有采样电阻，不靠硬件限流），防夹手、防卡死；
- **视觉防撞**：相邻模块距离 <3cm 时强制停；
- **失联保护**：MQTT 心跳丢失 500ms，单元原地停住，不"瞎跑"；
- **断电短时保持**：N20 高减速比 + H 桥短路刹车 + 静摩擦，断电后短时保持（滑移距离赛前实测）；**不承诺长期承重不掉**，机械自锁为 P1；
- **物理急停**：模块上的按键 + 网页红色按钮，双通道。

## 4. 凭什么是我们（创新点）

| # | 创新点 | 为什么值钱 |
|---|---|---|
| 1 | **套挂式零改造** | 电动晾衣架要拆旧装新（几百到几千元 + 施工）；我们夹上就用，租房党/老小区/宿舍都能用，搬家带走。 |
| 2 | **分布式模块化** | 杆多长就加几个单元，不为一根杆定制导轨；单个单元坏了不影响其余，维修成本低。 |
| 3 | **视觉闭环的外部基准** | 摩擦轮会打滑，纯编码器会累积误差；相机从外部看模块，等于给每个单元一个"绝对坐标"，这是能用便宜电机做到 ±3mm 的关键。 |
| 4 | **把晾晒变成可计算的参数** | 不是"推一下"，而是按湿度、厚度算出一组间隙；还证明了"同一根杆上不可能连续换序"，必须抬升越障——知道边界在哪，比假装无所不能更专业。 |
| 5 | **硬件成本可控** | 单模块打样 ≈¥150（电控+电池 ¥86.5 + 机械 ¥65），量产可到 ¥125；整机打样 ≈¥850（不含 RDK），量产目标 ≈¥650，具备量产可能。 |

## 6. 48 小时怎么交付（敢承诺的完成度）

- **P0（必须）**：4 个单元在 1.2m 杆上完成"手动移动 + 一键等距 + 收衣"，网页可控，急停有效，视觉给出间距读数；同一套软件支持改杆长/增删单元（2—8）。
- **P1（争取）**：智能分配（按湿度权重）、视觉闭环校准、断电/低电提示。
- **P2（锦上添花）**：BPU 上的衣物检测/湿度估计、语音控制、第二根杆联动。

> 现场决策原则：**P0 没跑通，绝不碰 P1。** 每天的里程碑门禁见 [docs/11](11-现场48小时执行计划.md)。

## 7. 商业想象（评委里有投资人）

- **用户**：中国城镇家庭约 2.9 亿户（2020 人口普查口径估算），阳台晾晒仍是主流；租房人群、老小区、学生宿舍是零改造需求最硬的群体。
- **定价**：Lite（2 单元 + 手机控制，无 RDK）¥399；Pro Core（4 单元 + ESP32 网关）¥999；Pro Vision（4 单元 + RDK 视觉中枢）¥1,899；加购单元 ¥199。
- **成本**：单单元打样 ≈¥150（量产 ¥125）；整机打样 ≈¥850 不含 RDK（含 RDK ≈¥1,400），量产目标 ≈¥650。毛利率 36%—43%（估算）。
- **渠道**：电商（晾衣架/家居类目）、家装后市场、租房平台、B 端（长租公寓、酒店布草间）。
- **延展**：同一套"视觉 + 自走模块"可迁移到衣柜内部分区、阳台植物架、摄影棚灯架——**真正的产品是"可移动的挂点"**。
- **壁垒**：结构+控制+算法的组合专利（3 个可申请点见 [docs/15](15-产品化与商业化.md)），以及"零改造"这个定位本身。

## 8. 风险一句话版

**最大的风险不是技术，是 48 小时做不完。** 所以策略是：赛前把机械、固件、算法、网页全部做到"能单独跑"，现场只做集成和调试；每个环节都有降级方案（详见 [docs/13](13-风险与PlanB.md)）。

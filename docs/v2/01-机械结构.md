# v2 · 01 机械结构（抱箍式伸缩圆柱 · 双端夹持）

> **这份文档回答什么问题**：套在既有晾衣杆上的伸缩圆柱凭什么能不拆杆装上去、能单端锁死做单向伸缩、能两端锁死把长度钉死、两端调节器能顶墙预紧，并且在 48 小时内用一台普通打印机做出来。

## 0. 一页结论

| 项 | 设计值 | 结论 |
|---|---|---|
| 调节器数量 | **N = K+1**（演示 K=4 → **5 个**: 01–05） | 两端各 1 个端部段，中间 3 个中间段 |
| 适配杆径 | Ø20–Ø35 圆杆（演示 Ø25 不锈钢） | 夹持环按杆径一版一打，改 `ROD_D` 重生成 |
| 单件质量 | 中间段 200 g / 端部段 165 g（含电机电池，估算） | 打印件 90 g/单元 |
| 长度规格 | **N 窄距 100–130**（行程 30）· **M 中距 130–190**（60）· **W 宽距 190–220**（30）· **E 端部段 90–110**（20，带顶墙撑脚）· **S 被动短套 40/60/80**（无电机） | 净风道 g = L（衣架占 10 mm，中心距 = L + 10）；**40–100 mm 是动力盲区，用 S 短套** |
| 夹持方式 | 每端 1 套**锥面收口夹头**：12° 锥面套筒（行程 6 mm）压 6 段弹性夹头环，`F_hold = 82 N`（设计，要求 ≥40 N） | 无外露爪子；外径只比管体大 2 mm（Ø68 vs Ø66） |
| 夹持检测 | 每端 1 个微动开关，套筒行程 ≥4.5 mm 闭合 | 状态可上报，"锁没锁"可判定 |
| 工况 A 推力 | 单端锁死推衣架 **F_push = 8 N**（额定 15 N） | 丝杆扭矩 0.0155 N·m，N20 30rpm 额定 0.078 → **5.0×** |
| 工况 B 预紧 | 两端锁死，顶墙预紧 **F_pre = 15 N** | 夹持安全系数 70/15 = **4.7×** |
| 伸缩速度 | 4.0 mm/s @30rpm（T8×8） | 行程 30 mm 用时 7.5 s |
| 接缝 | **10 mm**（用户锁定），两半销对接成销桥 | 衣架钩环跨 10 mm 销桥，下陷 0.64 mm |
| 位置保持 | 夹持锁死 = 绝对定位，不靠链张力、不靠丝杆自锁 | 断电保持 ✓ |
| 机械件成本 | 中间段 **≈¥51**、端部段 **≈¥54**（**不含** N20、电磁推杆、驱动、电池、主控） | 电控口径见 `docs/09`；一整套 5 个 ≈**¥263** |
| 打印预算 | 单件 ≤4.2 h / ≤95 g，5 件合计 ≤18 h | 满足 48 h 单机 |

**三条硬约束（设计冻结）**

1. **夹持是"径向锥面锁"，不是"爪子夹"也不是"抱箍夹死"**：锁死时锥面把弹性夹头环径向压在杆上，`F_hold = 82 N`（设计，要求 ≥40 N）；松开时套筒回退，夹头环弹开，导向套与杆单边留 0.3 mm 间隙，链条才能滑。这个"可锁 / 可滑"的双态是整套机构的物理基础。
2. **接缝永远不许闭到 0**：两个端头的**挡台在缝宽 4.0 mm 时相碰**（物理硬限位），另有 3 mm TPU 缓冲垫只做缓冲；缝宽由控制保证 6–14 mm（目标 10 mm）。见 §6.3 防夹手。
3. **端部段顶墙，不是端部段顶杆**：预紧力走"撑脚 → 墙"，杆只承受自身与衣物的竖直载荷。这根杆是既有家居设施，不能当拉杆用。

## 1. 形态与零件分解

### 1.1 链的排列（本版锁定）

```
墙/挡块 ─[调节器01]─ 衣物1 ─[调节器02]─ 衣物2 ─[调节器03]─ 衣物3 ─[调节器04]─ 衣物4 ─[调节器05]─ 墙/挡块
            ↑端部段            ↑中间段            ↑中间段            ↑中间段            ↑端部段
                    接缝1            接缝2            接缝3            接缝4
```

- 衣物 i 挂在**调节器 i 的右端头**与**调节器 i+1 的左端头**之间的 10 mm 接缝里。
- 每件衣服两侧都有调节器 → 任意一段单独伸缩，都不会牵动整条链（这是"推力只要 8 N"的根因）。
- 端部段（01、05）比中间段短，额外带**顶墙撑脚**；两端顶墙后整条链被"夹"在两面墙之间，无松动感。

### 1.2 单个调节器的零件分解

| 编号 | 零件 | 材料/工艺 | 功能 |
|---|---|---|---|
| A | 端头/夹持座 ×2（左右各一） | PETG 打印（两半 + 铰链 + 卡扣），轴向宽 16 | 扣在杆上；装夹头环、锥面套筒、微动开关 |
| B | 锥面套筒（外套） | PETG 打印两半或 POM，Ø68×12，内锥 12° | 轴向内滑 6 mm，把夹头环径向压紧；外径只比管大 2 mm |
| C | 弹性夹头环（6 段） | TPU 95A（主选，可掰开扣杆）/ POM·钢（两半对开，备选） | 5 条半槽 + 1 条全开缝；内孔 = 杆 + 0.3，6 片抱紧面 |
| D | 导向衬套（低摩擦） | PTFE 片 0.5 + TPU 防摆筋 2 道 | 松开时"松配导向"，单边 0.3 mm |
| E | 外管（两半） | PETG 打印，Ø66×壁 2.5 | 承力外壳、藏丝杆与电机 |
| F | 内管（滑管） | PETG 打印骨架 + 3 筋 | 伸缩段；带 POM 螺母座 |
| G | T8×8 梯形丝杆 + POM 螺母 | 采购 / 打印螺母 | 旋转变直线，4.0 mm/s，η=66.1% |
| H | N20 30rpm 减速电机 | 采购（计电控口径） | 每单元 1 个 |
| I | 端头 U 形托 + 半销 | PETG 打印 + Ø5×12 不锈钢销 | 接缝处托住衣架钩；半销对接成销桥 |
| J | 微动开关（每端 1 个） | 采购（计电控口径） | 夹持锁死检测 |
| K | 顶墙撑脚（仅端部段） | M8×40 尼龙螺钉 + Ø28 TPU 垫 | 顶墙预紧 10–20 N，行程 25 mm |
| L | 编码牌 | 打印凸字 / 贴纸 | 01–05，视觉识别用 |

**每调节器 = 2 套夹持（A+B+C+D+J）+ 1 套伸缩（E+F+G+H）+ 2 个端头（I）。** 端部段多 1 个 K。

## 2. 双端夹持：整套方案的机械基石

### 2.1 三种操作状态

| 状态 | 左夹持 | 右夹持 | 机械效果 | 用在哪 |
|---|---|---|---|---|
| **T 态（单向伸缩）** | 锁死 | 松开 | 只有右端伸缩，左端是支点 | 推/拉单侧衣架、微调间距 |
| **T′ 态** | 松开 | 锁死 | 只有左端伸缩 | 反向微调 |
| **F 态（定点锁定）** | 锁死 | 锁死 | 长度锁死；管子两端都被钉在杆上 | 演示中的"定格"、断电保持 |
| **W 态（端部预紧）** | 锁死 | 顶墙撑脚顶住墙 | 整条链被夹在两面墙之间 | 收工/演示前的预紧 |

- **T 态是"尺蠖步"**：锁一端 → 伸另一端 → 锁新端 → 松旧端，重复 3 次就把一段移动 50 mm。控制层（`docs/v2/03`）负责编排，机械层保证每一步都成立。
- **F 态的最大价值：断电不用电机保持。** 位置由锥面夹头锁定，N20 掉电也不会被衣服推走（对比"靠丝杆自锁"的方案，这里不再依赖 λ<μ′）。

### 2.2 锥面收口：推力 → 径向夹紧 → 摩擦保持（校核）

锥面套筒沿轴向被推入，锥面（半锥角 θ）把轴向力放大成径向力，夹头环抱住杆：

```
轴向推力（手扳/电磁推）  F_a = 40 N（规格 30–50 N）
锥半角                  θ = 12°（设计区间 10–15°，角度越小放大越大但越易自锁）
锥面摩擦                μ_cone = 0.12 → 摩擦角 φ = arctan(0.12) = 6.84°
径向夹紧力              N_r = F_a × cot(θ + φ) = 40 × cot(18.84°) = 40 × 2.932 = 117 N
  · 推力下限 30 N → 88 N；上限 50 N → 147 N
  · 锥角敏感情形：θ=10° → 132 N；θ=15° → 100 N（同一 40 N 推力）
夹头-杆摩擦             μ_pad = 0.7（TPU 95A 对不锈钢干摩擦，手册 0.6–0.8）
保持力                  F_hold = μ_pad × N_r = 0.7 × 117 = 82 N
```

- **对照要求**：要求 `F_hold ≥ 40 N` → **2.05×**；若杆面有油污、μ_pad 跌到 0.45 → 53 N，仍 1.3×。
- **轴向止退**：锥面不自锁（`tanθ = 0.213 > μ_cone = 0.12`），夹头回弹会把套筒往外顶，回弹力
  `F_out = N_r·tanθ = 117 × 0.213 = 24.9 N`，由套筒上的**止退缺口/弹片**承担，设计 60 N → **2.4×**。
- **行程与收口量**：套筒行程 `s = 6.0 mm` → 径向收口 `δ_r = s·tanθ = 6.0 × 0.213 = 1.28 mm`。其中 0.6 mm 用于吃掉 0.3 间隙 + 0.3 挤压，剩 0.68 mm 吸收杆椭圆/公差。**行程 5–8 mm 都落在可用区**。
- **回差**：止退缺口轴向旷量 0.3 mm → 径向夹紧力波动 `0.3×tan12° = 0.064 mm`（夹紧力 ±2%）。**不产生轴向定位误差**——锥面只给径向力，轴向分力由止退缺口吃住。
- **杆面压强**：6 片抱紧面，每片 6×14 mm → A = 504 mm²，`p = 117/504 = 0.23 MPa`（不锈钢/喷漆杆许用 ≥5 MPa → 21×）。
- **夹头瓣强度**：每瓣径向力 19.5 N，悬臂 7 mm，截面 6×3.5 mm →
  `M = 136.5 N·mm，W = 12.25 mm³，σ = 11.1 MPa`（POM 许用 ~60 MPa → 5.4×；TPU 不按应力算，按变形设计）。
- **驱动**：手动 3:1 拨钮（手力 15 N → 45 N）；P1 自动版用 **12 V 电磁推杆（推力 50 N / 行程 8 mm）**，或 MG996R 舵机 + 8 mm 曲柄（≈122 N 富余）。**SG90（22 N）不够，别用。**

### 2.3 松开状态：为什么是"松配导向"而不是夹死

| | 夹死（过盈抱箍） | **松配导向（本设计）** |
|---|---|---|
| 间隙 | 0 或负 | 单边 0.3 mm（`GUIDE_CLEAR`） |
| 松开时能否滑 | 不能，得靠弹性变形硬顶 | 能，PTFE 片 μ≈0.10–0.15 |
| 锁死时靠谁 | 抱箍本体变形 | 独立的锥面套筒 + 弹性夹头环 |
| 杆径公差 Ø20–35 ±0.3 | 一种尺寸夹不住全部 | 0.6 mm 有效间隙吸收 |
| 杆不直（1.2 m 中间下垂 0.5 mm） | 会卡 | 0.3 mm 单边 + PTFE 自润滑可过 |

结论：**夹持与导向必须解耦**。导向永远松（PTFE 片 + 两道 TPU 防摆筋只负责不晃），锁死由锥面套筒 + 夹头环单独完成。这也让"衣架能随手推着滑"成立。

### 2.4 两半套筒不拆杆安装（铰链 + 卡扣 + C 形夹头）

- 结构：端头/夹持座与锥面套筒**都是两半**，一侧**印刷铰链**（PETG 活铰 1.2 mm ×12 mm，寿命估 ≥500 次）或 Ø2×14 不锈钢销铰（打样推荐销铰）；另一侧**悬臂卡扣**（钩深 3 mm、宽 8 mm，卡入形变 1.2 mm = PETG 2%，脱出力估 25–35 N，设计值待实测）。
- 夹头环是**C 形**（5 条半槽 + 1 条全开缝，共 6 段），松态内孔 Ø25.9（杆 +0.9），可掰开直接扣上杆；TPU 95A 的掰开应变 ~27%，远低于其断裂伸长（>300%）。POM/钢版本改为**两个半环燕尾对开**。
- 安装：① 掰开夹头环扣上杆 → ② 两半端头扣合、卡扣合拢 → ③ 套筒套上 → ④ 推套筒到止退缺口（咔哒）。**全程不拆杆、不打孔、不需要第二个人。**
- 二次保险：卡扣旁留 M3 螺纹孔，打样期可加一颗 M3×8 螺钉防意外弹开（演示后去掉）。

## 3. 尺寸链

### 3.1 径向（改 `ROD_D` 自动跟随）

从杆轴心向外，各层半径（mm）：

```
R_rod    = ROD_D/2                        Ø25 → 12.5
R_bore   = R_rod + GUIDE_CLEAR            = 12.5 + 0.3   = 12.8   （夹持环内孔半径）
R_sleeve = R_bore + WALL_S  (2.0)         = 14.8                 （内管外半径，骨架）
R_nut    = R_sleeve + NUT_SLOT (0.6) + NUT_HALF(7.5) = 22.9      （螺母中心所在半径 = 丝杆偏心 e）
R_out    = R_nut + NUT_HALF(7.5) + WALL(2.5) = 32.9              （外管外半径）
BARREL_OD = 2 × R_out ≈ 65.8 → 设计取 Ø66
```

推导式：`BARREL_OD = ROD_D + 2 × (GUIDE_CLEAR + WALL_S + NUT_SLOT + 2×NUT_HALF + WALL)`
= ROD_D + 2×(0.3+2.0+0.6+15+2.5) = **ROD_D + 40.8**
→ Ø20: 60.8；Ø25: 65.8；Ø35: 75.8。

- 概念图里圆柱/杆的视觉比例 ≈ 3.8:1（Ø25 杆 → Ø95），本设计 Ø66 比概念图更瘦，**外观不会比图更笨**。
- 丝杆偏心 e = 22.9 mm 是"让开杆 + 让开内管"的硬下限：`e ≥ R_sleeve + NUT_SLOT + NUT_HALF`，不能压。
- **接缝处不许有外径突变**：两个端头同为 Ø66，衣架钩环（外径 ≤ 48，见 §3.3）在缝里自由转动，不会碰到管壁。

### 3.2 轴向：L_MIN 的下限从哪来（关键）

一根带丝杆的伸缩管，**最短长度由内部零件排布决定**（三个零件在轴向不能重叠）：

```
L_MIN = 2×L_clamp(16) + L_nut(12) + L_bearing(8) + L_motor_axial(14) + 余量(4)
      = 32 + 12 + 8 + 14 + 4 = 70 + STROKE
```

- `L_clamp = 16` 是夹持端头轴向宽（锥面套筒 6 mm 行程 + 铰链 + 卡扣塞得下的下限，改小就装不下套筒行程）；
- `L_motor_axial = 14` 是**电机横置**后的轴向厚度（N20 沿径向偏置、锥齿轮/同步带转向丝杆）；同轴布置会涨到 40，L_MIN 直接多 26；
- `L_nut / L_bearing` 是螺母半长与轴承座宽度。

于是 **`STROKE ≤ L_MIN − 70`**（`C_L = 70`，即除行程外的一切）。反推规格：

| 规格 | L_MIN | L_MAX | STROKE | 用途 |
|---|---|---|---|---|
| **N 窄距** | 100 | 130 | 30 | 净风道 10–13 cm |
| **M 中距** | 130 | 190 | 60 | 净风道 13–19 cm |
| **W 宽距** | 190 | 220 | 30 | 净风道 19–22 cm |
| **E 端部段** | 90 | 110 | 20 | 墙到第一件衣服的距离；带顶墙撑脚 |
| **S 被动短套**（无电机） | 40 / 60 / 80 | 同左 | 0（定长） | 窄风道、临时加位、成本敏感段 |

- **40–100 mm 是这套结构的动力盲区**：`L_MIN ≥ STROKE + 70` 的硬结果，任何"带丝杆的动力段"都做不进 10 cm 以内。这段用 S 短套解决（结构一样、只是不伸缩）。
- **演示配置（K=4，风道 8/10/12 cm）**：`E(90) + S(80) + N(100) + N(120) + E(90)`。
- 总链长：`ΣL + K×SEAM + 2×撑脚 = 480 + 40 + 30 = 550 mm`；杆 1.2 m，余 **650 mm** ✓
- 净风道 g = L（衣架占 10 mm，中心距 = L + 10）——与旧口径 `g_i = L_i` 一致，只是数量从 K−1 变成 K+1、两端多两段。

**⚠️ 与锁定口径的出入（要 Lead 同步）**：`_shared-context-v2.md` 写 L 40–220。本设计里 **40–100 mm 只能是被动短套**（动力段硬下限 100 mm）；100–220 由 N/M/W 三档覆盖。演示 8/10/12 cm 仍然做得到——8 cm 那段用 S(80)，其余用 N。若坚持"每个调节器都能动"，演示风道建议改 **10/13/16 cm**（全动力段）。

### 3.3 接缝：10 mm 与衣架接口包络

| 项 | 值 | 依据 |
|---|---|---|
| 缝宽 SEAM | **10 mm** | 用户锁定（1 cm 够用） |
| 衣架钩线直径 | Ø3.2–4.0 | 标准塑料衣架 |
| 衣架钩环内半径 | R 18–22 | 标准衣架 |
| 钩环平面 | 垂直于杆轴 | 正常挂姿 |
| 半销 | Ø5 × 12，伸出端面 5.0 mm + 卡入 7 mm | 两端半销对接成 10 mm 销桥 |
| 半销端面间隙 | 0.5 mm（常态间隙；硬限位是端头挡台，最小缝 4.0 mm，见 §6.3） | 防夹手硬限位 |

## 4. 伸缩机构与丝杆校核

### 4.1 丝杆选型（T8×8 梯形，4 头）

```
d = 8, P = 2, lead l = 8 (4 头), d2 = d − 0.5P = 7
λ = arctan(l / (π d2)) = arctan(8/21.99) = 19.99°
```

效率（梯形牙，牙型半角 15°，润滑钢/POM，μ = 0.15）：

```
μ′ = μ / cos15° = 0.15 / 0.966 = 0.1553
η = tanλ (1 − μ′ tanλ) / (tanλ + μ′)
  = 0.3638 (1 − 0.1553×0.3638) / (0.3638 + 0.1553)
  = 0.3638 × 0.9435 / 0.5191 = 0.3431 / 0.5191 = 66.1%
```

速度 `v = 30 rpm / 60 × 8 = 4.0 mm/s`（落在 3–8 mm/s ✓；行程 30 mm → 7.5 s）

**自锁判定**：`λ = 20.0° > arctan(μ′) = 8.83°` → **不自锁**。本设计**不需要自锁**：位置由双端夹持锁定（§2.1 F 态），这是取消卷簧后最大的收益。

### 4.2 工况 A：单端锁死，推/拉衣架

前提（控制层保证）：被推侧的相邻调节器**先松开对应端夹持**，只余导向摩擦。

```
衣架钩在销桥上的拖滞：F_hd = μ_pin × m_h × g = 0.15 × 2.0 × 9.81 = 2.94 N   （μ_pin 钢/钢 0.15 估算）
相邻调节器滑动端导向摩擦：F_guide = μ_g × N_side
   N_side = (m_u/2 + m_h/2) × g = (0.10 + 1.0) × 9.81 = 10.8 N
   μ_g = 0.25（PTFE 片 + 杆面偏差，保守取任务口径 0.2–0.3 的中值）
   F_guide = 0.25 × 10.8 = 2.7 N
制造/歪斜附加：F_mis = 1.0 N（设计取值）
─────────────────────────────────────────
F_push = 2.94 + 2.7 + 1.0 = 6.6 N      → 设计值取整 8 N，额定 15 N（1.9× 裕量）
```

丝杆扭矩：

```
T_push = F × l / (2π η) = 8 × 0.008 / (2π × 0.661) = 0.0154 N·m
T_rated = 15 × 0.008 / (2π × 0.661) = 0.0289 N·m
```

### 4.3 工况 B：两端锁死，顶墙预紧

- 顶墙撑脚手拧，设定 `F_pre = 15 N`（10–20 N 范围）。
- 预紧力在**调节器内部**成对抵消（左端夹持 ←→ 右端夹持），再由撑脚传给墙：夹持摩擦承担 15 N，安全系数 4.7×。
- 杆的轴向载荷 = 0（预紧力不进杆），只有 §7 的竖直载荷。

### 4.4 电机扭矩裕量

N20 12V 30 rpm 参数（**目录典型值估算，打样必须实测**）：额定扭矩 0.078 N·m，堵转 0.25 N·m，额定转速 30 rpm，堵转电流 ~1.2 A。

| 工况 | 丝杆扭矩需求 | 额定裕量 | 堵转裕量 |
|---|---|---|---|
| A 设计 8 N | 0.0154 N·m | **5.1×** | 16.2× |
| A 额定 15 N | 0.0289 N·m | **2.7×** | 8.6× |
| B 预紧 15 N | 0.0289 N·m | **2.7×** | 8.6× |

- 结论：**N20 30rpm 够用，且不再像"推整链"方案那样吃紧（旧方案 1.35×）**。
- 保持：F 态靠锥面夹头（82 N），电机可断电；T 态瞬间断电也不掉位置（丝杆背驱扭矩 `T_bd = F l η/(2π) = 15×0.008×0.661/(2π) = 0.0126 N·m`，低于 N20 减速箱静摩擦阈值估 0.03 N·m，估算）。
- 电流限流：驱动板设 **0.5 A** 软限（≈0.10 N·m），对应丝杆推力 52 N，高于机械额定 15 N → 任何卡死都先触发限流而不是烧电机。

### 4.5 限位

- 电气：丝杆行程两端各一个霍尔/光电（计电控），软件限位 ±2 mm。
- 机械：内管尾部凸台顶住外管端面（硬限位），避免螺母撞轴承；过冲力由 PETG 凸台承担（30 N 下压强 <1 MPa）。

## 5. 端头与接缝：衣架怎么挂住、怎么防脱

### 5.1 U 形托 + 半销（销桥）

- 每个端头（左右各一）在**端面正中、低于杆轴 21.5 mm**处开一个 **U 形开口托**（开口朝上、宽 5.4 mm、深 9 mm）；U 槽里横放一根 **Ø5×12 不锈钢半销**，销伸出端面 5.0 mm，卡在 U 槽底部。
- 两个相邻端头的半销伸出端相对，中间留 0.5 mm → 形成约 10 mm 的**"销桥"**。
- 衣架钩环（内 R 18–22）挂在销桥上：两个半销就是两条支撑线，钩环跨 10 mm、下陷 0.64 mm，自定心 ✓。
- 为什么半销而不是一根整销：**两端是独立调节器，各自运动，整销会被别断**；半销对接后视觉上仍是一根"短轴"，衣架钩跨过去感觉不到接缝。

### 5.2 受力校核

```
单端承受衣架载荷（两半销对分）：F_h = m_h g / 2 = 2.0×9.81/2 = 9.81 N
半销悬臂长 a = 5.0 mm（伸出端面部分）
M = F_h × a = 49.1 N·mm
W = π d³/32 = π×5³/32 = 12.27 mm³          （Ø5 实心圆截面）
σ = M/W = 4.0 MPa  vs  304 不锈钢许用 ~150 MPa → 安全系数 37×   ✔ 可减到 Ø4（σ=7.8 MPa 仍 19×）
```

- 半销根部挤压（PETG U 槽）：`p = 9.81/(5×7) = 0.28 MPa` ✓
- 钩环拖滞（工况 A 推衣架）：F_hd = 2.94 N，远小于半销能力 ✓

### 5.3 防脱

| 脱出方式 | 对策 | 校核 |
|---|---|---|
| 钩环沿销桥轴向滑出 | 两个端头的**端面**（Ø66 圆盘）本身就挡住钩环两侧；钩环宽度 3.6 mm，缝 10 mm → 最多横移 6.4 mm 就被端面挡住 | 不会掉 |
| 钩环横向（Y）窜动 | 端头 U 形托两侧壁（高 8 mm）包住半销；钩环只能绕销摆动 | 不会掉 |
| 衣架被向上抽出 | 允许（这是挂取动作），但**正常摆动不会自己跳出**：钩环要跳出必须抬升 ≥ 8 mm（U 槽侧壁高） | 误脱需 ≥8 mm 抬升 |
| 半销从 U 槽跳出 | U 槽口有一道 0.4 mm 的收口（弹性卡入），拔出力估 15–25 N | 正常拉扯不掉 |
| 断电/被衣服拉扯 | 夹持锁死；销桥两端独立，不传拉力 | — |

### 5.4 两个端头如何"挤压彼此"

本版没有卷簧，两端头**不靠持续挤压贴合**，而是靠**控制定位**：每个调节器的位置由它自己的双端夹持钉在杆上，接缝宽度 = 两个已锁定调节器端面之间的距离。因此：

1. **锁定后**：两个端头各自静止，10 mm 缝是"绝对尺寸"；两端半销端面留 0.5 mm，**永不接触**（不产生挤压力），衣架钩在中间自由转动。
2. **移动时**：只有"正在伸缩的那一端"在动，另一端被夹持钉住；被推的衣架 / 相邻调节器按 §4.2 的 8 N 推力走。
3. **需要"贴合感"时**：用顶墙撑脚做 W 态预紧，把整条链压紧在两面墙之间——力走墙，不走接缝。

> 与旧版（"靠两端挡块/卷簧保持贴合"）的差别：本版把"贴合"从**机械自挤压**改成**位置锁定 + 端部顶墙**。好处是断电不掉位、不依赖弹簧一致性、不会因为一件衣服重就把整链挤歪。

## 7. 竖直载荷与杆的校核

- 每件湿衣按 2.0 kg 估（演示 4 件 → 8 kg，加衣架 4×0.1 kg）。
- 衣架钩环搭在销桥上 → 载荷**对分**到相邻两个调节器的夹持环 → 传入杆（径向）。
- 单调节器最大径向载荷：`N_r = (m_u/2 + m_h) g = (0.10 + 2.0)×9.81 = 20.6 N`
- **杆的弯曲**：4 件集中载荷约 8.4 kg 均布在 0.46 m 上，按简支 1.2 m、E=200 GPa、Ø25 实心：
  ```
  I = π d⁴/64 = π×25⁴/64 = 1.917e4 mm⁴
  δ_max ≈ 5 w L⁴/(384 E I)，w = 84 N / 1.2 m = 70 N/m
        = 5×70×1.2⁴ / (384×200e9×1.917e-8) = 0.30 mm
  ```
  → 下垂 0.3 mm，对 0.3 mm 导向间隙和 0.5 mm 半销端隙都是**同一量级**，可接受；杆不是本产品承力件。
- 夹头环对杆的**局部压强** 0.23 MPa（§2.2），不会压出凹坑。

## 11. 待验证清单（交给 Lead）

**必须先打样实测的三项（本文无法自证）**：

1. **锥面夹头的保持力**：按 θ=12°、μ_cone=0.12、μ_pad=0.7 算出 82 N，但 TPU 95A 在 Ø25 不锈钢上、有尘/有水时 μ_pad 可能跌到 0.4–0.45 → 保持力 47–53 N，仍过 40 N 但只剩 1.2–1.3×；且**若杆有油漆，μ 和压痕都会变**。需实测 3 种杆面（裸不锈钢 / 喷漆 / 铝合金磨砂）。
2. **横置电机 + 锥齿轮/同步带的效率与噪声**：本文按"直接驱动丝杆"算扭矩，横置转向会损失 5–15%，若实际损失 >15%，A 工况额定裕量从 2.7× 掉到 2.3×，仍可用但需确认。
3. **衣架钩环与销桥的匹配**：本文假设标准衣架（内 R18–22、线径 3.2–4.0、喉口 ≥9 mm）。现场衣架五花八门，若钩环内 R 太小（<15）会跨不住 10 mm 销桥、若线径太细（<2.5）会从半销端隙里卡进 0.5 mm 缝。**建议演示统一采购同一款衣架，或加一个 5 g 的打印钩套。**

**另需 Lead 拍板的一项（影响 `_shared-context-v2.md` 和演示脚本）**：
- 动力段硬下限 = 100 mm（§3.2），因此 **40–100 mm 只能被动短套**。演示 8/10/12 cm 可行（8 cm 用 S(80)），但"每段都能动"这个说法要么改成"宽段动力、窄段定长"，要么把演示风道改成 10/13/16 cm。这一条同时影响 `docs/v2/03` 的规划器和 `docs/v2/06` 的演示脚本。

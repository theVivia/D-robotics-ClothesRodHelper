# 用 taste-skill 审界面（tasteskill 2.5.1）

> 用户要求"试试 taste-skill"。已安装并加载 `design-taste-frontend`（tasteskill 2.5.1，`~/.dsh/skills/design-taste-frontend`）。
> **它不是给控制台 App 的**，是给公司官网/产品落地页的（house rules：一屏一节、真实产品照片、hero、one section per screen）。所以这里只取它能迁移的"系统规则"，审 app-v2。

## 1. 取用的规则

| 规则 | 在 app-v2 的落法 |
|---|---|
| 界面 90—95% 中性，最多一个强调色 | 白/浅灰底，唯一强调蓝 #2F6FED；绿/橙只做状态点 |
| 一个系统：一种圆角、一种卡片、一种按钮、一种分隔线 | 圆角统一 12px；去掉渐变/发光/装饰阴影 |
| 字号：正文 ≥16px，标签 13px，没有更小的正文 | 清掉 8—11px 技术小字；尺子刻度除外 |
| 真实产品 UI，不用通用模板 | 杆视图是真实结构（圆柱/接缝/夹头），不是抽象插画 |
| 文案像人话，不用术语堆砌 | `V2 Chain`→`晾衣杆`、`ΣL+K×10`→`总长`、`MQTT 在线 18ms`→`已连接` |
| 对比度 4.5:1；可点元素 ≥44px | 灰字加深，按钮加高 |
| 图片下不放说明文字（house rule 1） | App 里不挂"图注"；说明放面板里 |

## 2. 审计发现（改前）

- 8—11px 的 mono 标签大量存在（eyebrow、stat label、panel note、log）；
- 文案有 `V2 CHAIN`、`ΣL+K×10`、`MQTT 在线 18ms`、`视觉识别` 等工程黑话；
- 残留 golden 变量（`--gold` 等）虽已不用，但 CSS 里还在；
- 状态色（绿/橙）被用来染文字，应该只做点；
- 卡片/按钮圆角不统一，有渐变背景。

## 3. 改后

- 浅色家电风：`#F4F5F7` 底、白卡片、`#1E2329` 字、`#6B7280` 次要、`#2F6FED` 唯一强调；
- 正文 16px、标签 13px，主界面不再有 <13px 的句子；
- 固定端 01/05：锁死 + "固定端"标签，不可拖；内部 02—04 可拖；
- 端部/接缝/夹头用真实结构表达，金色圆环删除；
- 截图：`app-v2/.verify/390x844-default.png`、`rod2400.png`。

## 4. 没照搬的部分

- **一屏一节 / hero / 真实照片**：这是控制台，不是落地页；硬套会让操作变远。
- **产品照片**：目前只有 SVG 概念图，没有实拍；等打样后补真实照片，再按 taste-skill 做产品落地页。
- **taste-skill 的 gate 脚本**：需要 Node 22+ 和浏览器自动化，本机 Node 18，未运行；只人工执行了它的系统规则。

> 结论：taste-skill 对"落地页"有用，对"控制台"只能取其系统规则。真正该用它的是之后的产品官网/众筹页，不是这个操作页。

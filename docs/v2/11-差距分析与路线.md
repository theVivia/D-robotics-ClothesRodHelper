## 2. 必须解决的矛盾（按严重度）

### A. 端部"固定"的语义（已定，正在落）

- 错误：端部两端都锁死 → 等距/收衣没有行程，物理不成立。
- 正确：**外端锚定、内端自由伸缩 30—120mm**；外端坐标 0/D 不动，内端吸收总长变化。
- 影响：app 拖动/自动模式、sim 规划、机械端部设计、电控 5 单元全电动。
- 状态：`docs/v2/10` 已写；app/ sim / mech / elec 已发修改。

### B. 动力段最短 100mm vs 4cm 风道

- 机械：零件叠出来 L_MIN=100；40—100 只能被动短套。
- 现状：app/sim 仍允许 40mm。
- 决定：**P0 动力段 10—22cm；4—10cm 用被动短套（手动装）**；App 里 8cm 段标"被动短套"或直接默认 10cm。**不承诺"全自动 4cm"**。
- 演示：默认 10cm；要展示"更窄"用被动套，不放进自动模式。

### C. 5 个电动 vs 端部被动

- P0：**5 个都电动**（端部要吸收总长），对应 02 的 ¥890.5 工程 BOM。
- Lite：端部被动，自动模式只能做"总长不变的重分配"，成本 −约 ¥100。
- 答辩口径：P0 全电动；量产 Lite 端部被动、手动预设。

### D. 速度

- 4mm/s → 日常 48.9s，超 30s；7mm/s → 29.6s。
- 决定：**默认 7mm/s**（T8 8mm 导程 + ≥50rpm 电机），BOM 电机换 50—60rpm 或 PWM 提转速；文档统一写 7mm/s（范围 3—8）。

### E. 演示杆长

- 1.2m 挂 4 件 → 链 460、空杆 640，画面空。
- 决定：**演示可用 0.6m 杆**（可用 500，链 460，空杆 40，紧凑）或 1.2m（空杆 640）；产品参数 0.8—2.4m。App 先保 1.2m，现场按展台空间切。

### F. 成本口径

- 工程打样 ¥890.5 / 材料精简 ¥575 / 量产 ¥601 / 含 RDK ¥1,440。
- 对外主口径：**工程打样 ¥890.5（不含 RDK）、含 RDK ¥1,440；量产约 ¥601**。¥575 只说"纯物料"。
- 定价：Pro Core ¥899、Vision ¥1,599；毛利按 1 万台物料、偏乐观，答辩要标注。

## 4. 现在最危险的 5 件事

1. **夹头实际摩擦力**：82N 是算的；喷漆/有尘杆可能掉到 50N，仍够但没验证。
2. **CAD 没渲染**：SCAD 只做了括号配平，可能过切/薄壁。
3. **自动模式与手动约束不一致**：app 的等距/收衣如果绕过端点吸收，就会重现"锁死端被带着跑"。
4. **没有真机**：所有演示是 App + 仿真，评委一问"能动吗"只能放视频/讲计划。
5. **v2 deck 还没做**：现在只有文档，路演没有一页能看的东西。

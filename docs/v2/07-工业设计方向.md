# v2 工业设计方向：按"正常家居产品"来做

> **这份文档回答：这东西应该长什么样、用什么材料、交互怎么表达，才像能卖的产品，而不是黑客松展台上的科技玩具。**
> 背景：用户明确要求"不要按我的审美（深色+金色科技感），学习正常产品设计"。

---

## 1. 先看同类产品长什么样

| 品类 | 代表形态 | 设计语言 |
|---|---|---|
| 伸缩窗帘杆/浴帘杆 | 白色/银色圆管 + 两端橡胶垫，旋转锁紧 | 极简、无按钮、无灯、靠摩擦和纹理提示 |
| 隐形晾衣绳 | 白色 ABS 圆盒 + 不锈钢线 + 锁扣 | 家电白、圆润、墙面安装、无多余装饰 |
| 落地/折叠晾衣架 | 阳极氧化铝管 + 白色/灰色塑料接头 | 轻、可折叠、接头是视觉重点、颜色克制 |
| 米家电动晾衣架 | **月光白**、超薄、隐藏式灯 | 大面积白、少缝、无金属高光、品牌字很小 |
| 相机三脚架/吸尘器延长管 | 黑色/银色铝管 + 旋钮/扳扣 | 功能可见、锁紧件是唯一"机械感"来源 |

**结论**：这个品类的"正常长相"是 **白/灰 + 哑光塑料 + 银色铝管 + 橡胶垫**，不是深色 + 金色 + 发光环。用户家里已经有晾衣杆，产品应该"像杆的一部分"，而不是"另一个电子设备"。

## 2. 设计原则（按优先级）

1. **像家居五金，不像数码产品**：无屏幕、无 RGB、无外露螺丝；最多一个小状态灯。
2. **低存在感**：外径尽量接近杆（Ø40—44mm），长度方向不突兀；白色/浅灰为主，铝管只露一小段。
3. **锁紧件就是视觉焦点**：一个拇指扳手/旋钮，红色小点=未锁，绿色小点=锁死；不用发光圆环。
4. **免工具安装**：抱箍两半扣上、扳手锁紧；端部橡胶垫顶墙，不伤墙面。
5. **可清洁**：无凹槽藏灰、无织物；湿布一擦。
6. **安全可读**：接缝处 10mm 防夹圆角；锁/松有触觉"咔哒"和颜色双提示。
7. **系列化**：白/浅灰两色，长度 0.8/1.2/1.5/1.8m 套装；加购段同色。

## 3. CMF（颜色/材料/表面）

| 部件 | 材料 | 颜色/表面 | 说明 |
|---|---|---|---|
| 外套管 | PC/ABS 或 ASA | **哑光白 #F2F2F0** / 浅灰 #D8DADD | 抗 UV、阻燃 V0；哑光避免指纹 |
| 内套管（可见段） | 6063 铝 | **阳极氧化银** / 细磨砂 | 与白壳形成"一白一银"的干净对比 |
| 接缝/端头 | TPU 85A | 浅灰 #BFC3C7 | 防夹、减震、遮缝 |
| 夹头环/套筒 | POM/PA66 + TPU 内衬 | 白/浅灰 | 不电镀、不发光 |
| 端部墙垫 | TPE/硅胶 | 透明或浅灰 | 不伤墙、增加摩擦 |
| 锁紧扳手 | PA66 + 不锈钢销 | 浅灰，红色/绿色小点 | 单手可扳，行程 6mm |
| 状态灯 | 单颗 0603 LED 导光柱 | 白/蓝/红 | 只在配网/故障时亮，平时灭 |
| 品牌 | 激光蚀刻 | 浅灰 | 5mm 字，放在底部 |

> 金色、镜面、RGB 灯环、大面积黑色全部去掉。深色只保留在说明书和包装上。

## 4. 形态与结构（外观层）

```
墙 ─[橡胶墙垫+抱箍端头]─ 白色外套管 ─ 银色内管 ─[接缝 10mm]─ 下一段 …
```

- **端部单元（01/05）**：外端是**固定端**——抱箍锁在杆上 + 橡胶垫顶墙（够不到墙就锁杆）；外壳比中间段短，造型像"墙座"，让用户一眼看出"这是固定端，不要拖"。
- **中间单元（02—04）**：两端各一个锁紧扳手；内管从一端伸出；接缝处有浅灰 TPU 护圈，衣架钩挂在护圈中间的 10mm 缝里。
- **锁紧扳手**：拇指大小，扳下=锁（绿点露出），扳上=松（红点露出）；旁边有凸起盲文点/图标，老人也能摸出来。
- **接缝**：不做金色圆环；用一圈浅灰 TPU，宽度 10mm，圆角 R2，防夹手。
- **状态**：只有一颗小 LED 在端部单元底部，配网/低电/故障时亮；正常灭。

## 5. 交互与 App（浅色中性）

- App 背景 **#F4F5F7**、卡片白、文字 **#1E2329**、次要 **#6B7280**、强调色 **#2F6FED**（蓝）；成功绿 **#12A150**、警告橙 **#D97706**。
- 首页：一张"杆的俯视图"，白色圆柱、灰色接缝、蓝色当前段；**固定端 01/05 带锁图标和"固定"标签，不能拖**；中间段可拖。
- 控件：大圆角、44px 以上触控区、系统字体；不发光、不渐变金。
- 状态：锁/松用图标+文字（🔒 锁定 / 🔓 松开），不用装饰环。
- 文案：像家电说明书——"端部固定，先解锁再调"、"已锁紧"、"还剩 640mm 空杆"。

## 6. 当前设计要改的地方

| 旧（深色+金色） | 新（家居产品） |
|---|---|
| 金色圆环/椭圆装饰 | 删除；只留浅灰 TPU 接缝护圈 |
| 金色夹头/发光点 | 浅灰扳手 + 红/绿锁状态点 |
| 深色 HUD 背景 | 浅色 App、白色卡片 |
| 端部没有"固定"表达 | 端部墙座造型 + "固定端"标签 + 锁图标，不可拖 |
| 科技感渐变 | 哑光白/浅灰/阳极氧化银 |

---

## 7. 验证方式（产品感）

- 把渲染图给 5 个非参赛者看，问"这是什么东西、装在哪、贵不贵"；答不出"晾衣杆配件"就重画。
- 放在真实阳台照片里做合成图，检查是否像"本来就该在那"。
- 和米家/宜家同类产品并排，看颜色/比例是否同一语言。

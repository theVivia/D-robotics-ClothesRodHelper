# 夹持约束下的长度调整（拖动规则）

> 这份文档定义"锁住端点后，长度到底该怎么变"。app-v2 之前的拖动是"整条链重排"，会把锁住的端点带着跑——物理上不成立。以下是修正后的模型。

---

## 1. 自由度

一排 K+1 个圆柱、K 个 10mm 接缝，每个圆柱两端各一个夹头。每个夹头只有 **锁 / 松** 两态。

- 圆柱长度 `L_i` 是两端之间的距离：`L_i = x_right(i) − x_left(i)`。
- 接缝固定 10mm：`x_left(i+1) = x_right(i) + 10`（衣架挂在这里，缝宽不变）。
- 一个端点锁死 = 它的绝对坐标固定；松 = 它跟着管端走。
- **两端都锁**：`L_i` 和两端坐标全固定（不能再伸缩）。
- **锁一端**：只有自由端能沿杆移动，`L_i` 随之变。
- **两端都松**：圆柱可整体滑动，也可伸缩——一个拖动无法同时决定"滑"和"伸"，所以交互上要求先锁一端。

---

## 2. 拖动传播

拖某个自由端移动 `δ`：

```
移动该端 → 接缝跟着移动 δ → 相邻圆柱的自由端跟着移动 δ
        → 若相邻端锁死，则停止；由相邻圆柱的"另一自由端"吸收 δ（它的长度变 −δ）
        → 继续传播，直到遇到下一个锁死端点或链端
```

- 传播路径上所有端点都必须让路；**任何锁死端点的坐标不能变**。
- 如果路径上没有任何可动的自由端来吸收 `δ`（全锁死 / 已到行程极限），**拒绝这次拖动**，提示是哪一段的固定端挡住了。
- 端部 01/05 是"两端锁死"的边界，`L=60mm` 固定，只作为链的起点/终点。

---

## 3. 可行性判据

设拖动后所有段的长度为 `L_i'`，锁死端点为固定坐标。必须同时满足：

1. `L_min ≤ L_i' ≤ L_max`（动力段 100—220mm；被动段 40—100mm）；
2. 所有锁死端点的坐标不变；
3. 接缝宽度恒为 10mm；
4. 总链长 `ΣL_i' + K×10 ≤ 可用杆长`；
5. 传播路径上至少有一个自由端吸收位移。

任一不满足 → 拖动无效，UI 显示"被 XX 固定端挡住 / 超行程"，而不是强行重排。

---

## 4. 交互规则

| 操作 | 结果 |
|---|---|
| 拖左把手（右端锁死） | 左端移动，`L` 变；左端锁死时把手禁用 |
| 拖右把手（左端锁死） | 右端移动，`L` 变；右端锁死时把手禁用 |
| 两端都锁 | 两个把手都禁用；点了提示"两端锁定，先松一端" |
| 两端都松 | 不允许直接改长度，提示"先锁一端再调" |
| 端部 01/05 | 两端锁死，长度固定 60mm，不可拖 |
| 锁按钮 | 44×44px 点击区，整块可点；与拖把手分开，避免抢事件 |

---

## 5. 验收场景

1. `01/05` 固定；拖 02 右端 +20mm：`02: 100→120`，`03` 左端 +20；若 03 右端锁死，`03: 120→100`；若 03 两端锁死，拒绝并提示。
2. `03` 两端锁死：拖 03 任何位置，03 两端坐标和长度都不变。
3. 拖 04 想把 05 顶出去：05 固定，拒绝，05 坐标不动。
4. 默认 1.2m/4 件：端部 60+60、内部 100×3、接缝 40 → 总长 460mm；端部长度保持 60。
5. 所有锁死端点在一次拖动前后的坐标差 = 0。

---

## 6. 代码落点（app-v2）

- `state.clamps[i] = {l, r}` 是约束，不是装饰；所有长度变更必须先过约束检查。
- 位置不能每次从"左墙累计"重算；要以**锁死端点的绝对坐标**为锚，向两边铺。
- 拖动函数只改一个自由端，然后调用 `propagate()` 求解；求解失败则回滚。
- 端部 `i=0`、`i=K` 固定：初始化时 `L=60`，两端锁死，不进入拖动。

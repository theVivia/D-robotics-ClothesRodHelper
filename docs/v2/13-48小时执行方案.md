## 5. 关键路径与砍功能顺序

**关键路径**：夹头能锁 → 5 单元能伸缩 → 端部锚定/吸收 → 网页→MQTT → 视觉 ID → 演示。

**砍功能顺序**（从先砍到最后）：
1. BPU/衣物识别（本来不做）
2. 按湿度加权
3. 加一件（6 圆柱）
4. 视觉闭环（降级为长度反馈）
5. 0.6m 短杆（用 1.2m）
6. **绝不砍**：收/等距/单段拖、急停、5 个 ID、3 分钟演示

## 7. 失败预案

| 现象 | 现场动作 | 话术 |
|---|---|---|
| 单元不动 | 复位/换备用；不行放视频 | "它触发了卡死保护，这是安全设计。" |
| 网页连不上 | 打开本地 `app-v2/index.html` | "现场 Wi-Fi 挤，我们用本地备份。" |
| 视觉丢 ID | 等 1s；遮挡移开；长度推算 | "衣服挡住了编码，它用长度反馈推算。" |
| 夹头松/链散 | 单人扶住；重新锁；换端部 | "这是我们要在打样里解决的边界。" |
| 时间不够 | 只演收→等距→单段 | "核心动作就这三个。" |

---

## 8. 答辩要点（背下来）

1. 衣服挂原杆，调节器不承重；一个圆柱=一段风道。
2. K 件=K+1 段；接缝 10mm；不用卷簧。
3. 端部只锁外端，内端吸收总长；锁死端绝对不动。
4. 锥面收口夹头，82N 保持，不是爪子。
5. 5 单元全电动；Lite 端部被动降本。
6. 工程打样 ¥890.5，量产 ¥601；Pro Core ¥899。
7. 没做的：真机打样/寿命/认证；不编数据。

# v2 成本与商业：按"段"卖

> **这份文档回答：v2（抱箍式伸缩调节器链）到底多少钱、卖多少钱、毛利多少、市场多大、壁垒在哪。**
> 概念依据：[docs/_shared-context-v2](../_shared-context-v2.md) + 2026-11-23 用户第二次结构澄清（**K 件衣服 = K+1 个调节器，两端各一个；每端开槽弹性夹头环 + 外套筒，套筒内缩 5—8mm 径向压紧杆、不夹衣架；端部调节器顶墙预紧；取消恒力卷簧**）。
> 一句话区别：v1 按"个模块"卖、每个模块承重；**v2 按"段"卖，一段 = 一个伸缩调节器 = 一段净风道，调节器不承重。**
> 更新：2026-11-23 ｜ 状态：v2 商业 v0.2（估算，未量产、未销售验证）

## 0. 结论先行

1. **拓扑变了**：墙/边缘 — 调节器 — 衣物 — 调节器 — … — 调节器 — 墙/边缘。**K 件衣服 = K+1 个调节器**（4 件 = 5 个：2 个端部 + 3 个内部）。两端也有调节器，靠顶墙预紧把整条链压住，**不再需要恒力卷簧**。夹持是**锥面收口夹头**（每端开槽弹性夹头环 + 外套筒，套筒向内滑 5—8mm 把夹头径向压紧在**杆（或端部挡块/墙端）**上，拉出即松开），**没有外露爪子，也不夹衣架钩**：锁左端 / 锁右端 / 双端锁止 → 单向伸缩、定点拉伸、固定绝对位置；两端都松开 → 可沿杆滑动或整段取下。衣架钩只挂在两个调节器端头之间的 **10mm 接缝**里，不参与夹持、不承重。
2. **成本仍比 v1 低，但降幅收窄**：v1 挂 4 件要 4 个模块（4×¥150 = ¥600 打样）；v2 要 5 个调节器（3 内部 ×¥100 + 2 端部 ×¥75 = **¥450 打样**）→ **降 25%**。量产：v1 ¥500 vs v2 **¥373**。
3. **售价降 10%、毛利升 6 个点**：主力 Pro Core（5 调节器，4 件衣服）从 v1 的 ¥999 降到 **¥899**，毛利从 42% 升到 **48%**——省的是 ToF、摩擦轮、承重结构、大电池；**多出来的是第 5 个调节器**，但单件便宜 34%，总数还是更省。
4. **商业模式仍是"按段卖"**：内部段 ¥149/段、端部件 ¥259/对；4 件衣服 = 2 端 + 3 内，散买 **¥706**、套装 ¥899（含网关）。加一件衣服 = 加一段。
5. **市场量级不变**（客单价接近）：TAM 约 ¥1,300 亿量级、SAM 约 ¥150 亿、三年 SOM **¥3,000 万—¥1.8 亿**。

> ⚠️ 口径说明（三条，答辩前必读）
> ① **单件成本**：内部调节器 **打样 ¥100 / 量产 ¥83**（原 v2 的 ¥90 / ¥74 + 双端锥面收口夹头 ¥10 / ¥9）；端部调节器按**简化版 ¥75 / ¥62** 计（可用同硬件，见 §1.3 敏感性）。毛利按"简化端部"算，属**偏乐观侧**；若端部用同硬件，组合毛利降约 6 个点（主力 SKU 降 4pp）。
> ② **整机口径**：本文 §1.5 的 **¥575** 是**精简打样口径**——只算 5 个调节器 + 相机 + 演示杆 + 包装，不含备件/中枢配件/装配测试；同口径 1 万台物料是 **¥463**。工程 BOM（[docs/v2/02](02-电控与BOM.md)，5×¥124.5 单元 + 中枢配件 190 + 杆/墙 78）= **¥890.5（不含 RDK）**；02 给的 1,000 台量产整机 ≈ **¥601（不含 RDK）**。**答辩时分开讲：工程打样 ¥890.5、量产 ¥601、精简物料 ¥575/¥463，别混用。** 含 RDK：精简 ¥1,120 / 工程 ¥1,440 / 量产 ¥1,051。
> ③ **毛利口径**：本文所有毛利按 **1 万台量产单价（¥83 / ¥62）** 算，且**不含研发、模具、认证、备件与装配测试**——所以是**偏乐观**的。真实净利三年为负（见 §2.2）。

## 1. 成本：按"段"算

### 1.1 公式与件数

```
一套（K 件衣服）的成本 = (K−1) × 内部调节器 + 2 × 端部调节器
调节器总数 = K + 1        （4 件衣服 = 5 个：2 端 + 3 内）
不再需要：恒力卷簧、左右挡块、大电池、摩擦轮、ToF
```

| K（衣服件数） | K+1（调节器数） | 打样物料（不含中枢/杆） | 量产物料（1 万台） |
|---|---|---|---|
| 1 | 2（全端部） | 2×75 = **¥150** | 2×62 = **¥124** |
| 2 | 3（2 端 + 1 内） | 150 + 100 = **¥250** | 124 + 83 = **¥207** |
| 4（演示） | 5（2 端 + 3 内） | 150 + 300 = **¥450** | 124 + 249 = **¥373** |
| 6 | 7（2 端 + 5 内） | 150 + 500 = **¥650** | 124 + 415 = **¥539** |
| 8 | 9（2 端 + 7 内） | 150 + 700 = **¥850** | 124 + 581 = **¥705** |

| | v1 | v2 | 变化 |
|---|---|---|---|
| 件数 | 4 个自走模块 | **5 个调节器** | +1 件 |

> **为什么多一个件还更便宜**：v2 单个调节器没有 ToF（省 ¥20）、没有摩擦轮/惰轮/防翻转、电池从 2000mAh 降到 1000mAh、不承受 5kg 承重。**是"不需要"，不是"采购谈判"。**

| 数量关系 | 衣服件数 = 模块数 | **调节器数 = 衣服件数 + 1** |
| 最小配置 | 2 模块（2 件） | 2 端部（1 件，¥259） |
| 加一件衣服 | 加一个模块 ¥199 | 加一个内部段 ¥149 |
| 端部件 | 无此概念 | **单列，可替换（¥259/对）**；坏了不用换整链 |
| 主力配置 | 4 模块 | **5 调节器（2 端 + 3 内）¥899** |
| B 端报价 | 按套 | **按杆长/工位**：¥1,899/2m 杆（约 10 件，含网关，不含 RDK）；含 RDK 视觉 ¥2,899/杆 |
| 复购 | 加模块 | **加段、换端部件、第二根杆（衣柜/阳台）** |

**按段卖的三个好处**（答辩可直接说）：
1. **用户算得清**：一段 = 一段风道 = ¥149，"我要 10cm 风道"就是"加一段"。
2. **没有过度购买**：2 件衣服的租房党只买 2 端 + 1 内（¥399），不用为"4 件套装"多付钱。
3. **修得起**：端部件是受力件（顶墙/夹持），单列后**坏了只换一对 ¥259**，不用整链返修——这是 v1"模块坏了换整个"的改进。

**B 端算例（估算）**：酒店布草间 2m 杆、挂 10 件 → 11 个调节器（2 端 + 9 内）+ 网关：
成本 `2×62 + 9×83 + 80 = ¥951`，报价 **¥1,899/杆**（毛利 50%）；100 间酒店 × 50 杆 = 5,000 杆 → 收入 **¥950 万**。
这是 v2 比 v1 更适合 B 端的根本原因：**不承重、能按杆长铺、坏了只换一段或一对端部件。**

## 5. 专利点更新（3 个可申请点，写思路不写法律文书）

> 说明：赛后 2 周内做 FTO 检索（国知局 + Google Patents），3 个月内提交；不是权利要求书，最终范围由代理师撰写。**赛前不要公开发布核心结构细节**（公开即丧失新颖性）。

### 专利点 1（结构，实用新型 + 发明双报）：一种双端锥面收口夹头的抱箍式伸缩杆件调节装置

**要保护的结构**：抱箍两半壳体 + 内外伸缩套管 + 两端各一组锥面收口夹头（开槽弹性夹头环 + 外套筒 + 微动开关）+ 端部顶墙垫。

**权利要求思路**：
1. 一种杆件调节装置，包括沿杆件周向对合的第一壳体与第二壳体（**两半抱箍**），对合后卡扣锁紧并允许沿杆滑动；
2. 壳体内设同轴内外套管，内套管由丝杆螺母驱动伸出，**伸出量即装置长度**；
3. 装置的**两端各设一组锥面收口夹头**，由开槽弹性夹头环与外套筒配合：套筒沿轴向向内滑移 5—8mm，使夹头环**径向收口**、压紧杆件；拉出套筒即松开。两个方向的夹头可独立锁止（锁左端 / 锁右端 / 双端锁止），双端锁止时固定绝对位置，两组均松开时可沿杆滑动或取下；夹持对象为**杆件本体/端部挡块/墙端，不夹持衣物/衣架**（P0 手动套筒、P1 电动套筒）；
4. 锥面收口夹头内设**微动开关**，检测"已夹紧/已顶墙"状态并回传；
5. 端部调节器的外端设**顶墙垫**，与墙面/法兰接触形成轴向预紧，**替代恒力卷簧**；
6. 两相邻装置的端头对合处留 **10mm 接缝**，容衣架钩自由转动（衣架钩不参与夹持、不承重）。

**可检索关键词**：晾衣杆 抱箍 伸缩 夹持 / 双端 夹持 杆 / telescopic clamp hanger rod。
**为什么不是显而易见**：现有晾衣杆附件是"固定夹/挂钩"，伸缩杆是"整杆伸缩"；把"抱箍可滑动 + 双端锥面收口夹头 + 顶墙预紧 + 接缝挂点"压进一个 220mm 内的单元，是新的组合。

### 专利点 2（传动/控制，发明）：一种顶墙预紧的分段锁止与长度控制方法

**要保护的方法**：每段独立长度闭环（丝杆 + 磁编码器）+ 双端锥面收口夹头的"拉出松开—调长—推入夹紧"时序 + 端部顶墙预紧检测；断电后夹头保持（不靠弹簧）。

**权利要求思路**：
1. 沿杆件串联 N 个可伸缩段，**两端段外端顶墙预紧**（微动开关检测顶紧到位），中间段两端夹持杆件/端部挡块（不夹衣架）；
2. 调节时序：外套筒拉出松开 → 丝杆调长至目标 → 外套筒推入（内缩 5—8mm）夹紧 → 重新顶墙预紧 → 回读长度与微动状态；
3. 每段以**段长为目标闭环**（非行走位置控制），相邻段无机械同步轴，链式耦合；
4. 断电/断网时夹持保持当前位置，**不依赖弹性件维持张力**；任一段卡死仅该段停并回退，其余段保持；
5. 顶墙预紧的行程/力纳入总长约束校核。

**可检索关键词**：顶墙 预紧 伸缩段 锁止 / clamp lock telescopic segment preload wall。
**为什么值钱**：这是"取消卷簧、不用摩擦轮、断电不掉"的结构性原因；也是 v2 精度（±1—2mm/段）和售后（只换夹持件/端部件）的基础。

### 专利点 3（算法/系统，发明）：一种基于唯一编码识别的 K+1 调节器间距规划方法

**要保护的方法**：拓扑识别（K 件衣服 ↔ K+1 个调节器）+ 以"衣架厚度 10mm + 目标净风道 g_i"直接输出段长 L_i + 不换序。

**权利要求思路**：
1. 每个调节器设唯一视觉编码（ArUco 01—09），相机识别编码 → ID 与沿杆位置，建立"调节器—接缝—衣架"的物理映射；
2. 以 `L_i = g_i`（段长 = 净风道）、`中心距 = L_i + 10mm` 计算目标长度，并校核 `ΣL_i + K×10mm + 端部预紧行程 ≤ 可用杆长`；
3. 识别出 K+1 个调节器即推断 K 件衣服（含"两端无衣架"的端部），**不换序**；
4. 约束不满足时给可执行建议（减少件数/缩短风道/换更长杆），而不是只报错；
5. 视觉位置与长度反馈不一致（累计误差/夹持滑动）时，以视觉校正段长，误差 >3mm 重标定。

**可检索关键词**：间距 规划 伸缩段 编码 识别 顶墙 / segmented gap planning marker id end units。
**为什么值钱**：结构能抄，**"视觉 ID ↔ 接缝 ↔ 顶墙端部 ↔ 目标长度"的映射和标定流程**抄不走；v1 的"避让重排"算法在 v2 物理上不需要了，护城河转移到这一层。

**专利时间线（估算成本）**

| 时间 | 动作 | 成本（估算） |
|---|---|---|
| 2026.12 赛后 2 周 | FTO 检索（自己查 + 代理检索） | ¥0—2,000 |
| 2027.01—03 | 实用新型 ×2（结构 + 夹持） | ¥3,000—6,000/件 |

## 9. 追问预案（评委最可能问的 8 个问题）

| 问题 | 一句话答案 | 展开 |
|---|---|---|
| "为什么是 K+1 个，不是 K−1？" | 墙到第一件衣服之间也要一段，最后一件到墙之间也要一段；两端各一个，所以比衣服多一个。 | 4 件 = 2 端 + 3 内 = 5；最小配置 2 端 = 1 件。 |

### 1.3 四个设计原则

1. **通电不会自己动**：nSLEEP 外部 10k 下拉，上电即 DRV8833 休眠（输出高阻）；固件自检通过后才允许拉高。
2. **夹持是运动的前提**：P0 手动夹持，但状态由 2 个微动开关反馈；**未锁一端（或两端都锁死）时电机禁止动作**（§6.3）。
3. **断电位置不丢**：丝杆导程 8mm 不自锁，但 N20 1:298 减速箱的反驱阻力 + 停机 300ms 动态刹车足以保持；断电后位置由 AS5600 多圈计数（存 NVS）恢复，不做每次上电归零。**取消卷簧后，链的定位完全靠各调节器夹持+丝杆长度**。
4. **单元自治**：中枢只发目标长度，闭环、限位、夹持联锁、堵转、急停全在单元本地；断网就地站住。

## 2. 关键器件选型

### 2.1 驱动：为什么 DRV8833（而不是 TB6612）

| | **DRV8833（选）** | TB6612FNG（备选） |
|---|---|---|
| VM 范围 | 2.7—10.8V | VM 2.5—13.5V，逻辑 VCC 2.7—5.5V |
| 连续电流 | 1.5A RMS/通道（2A 峰值） | 1.2A 连续（3.2A 峰值） |
| 逻辑电平 | 3.3V 直接兼容 | 需 3.3V 供 VCC（单电源 3.3V 也行） |
| 模块价 | ¥4.5 | ¥6.5—8 |
| 关键缺点 | 市售模块**无采样电阻**，堵转只能靠固件 | 封装大、要多接 VCC/GND/STBY 三根线 |
| 结论 | **P0 选它**：N20 堵转 0.7—1.2A 在 1.5A 内 | 若实测某批 N20 堵转 >1.5A，原脚位替换（AIN1/AIN2/PWM 同义） |

- 单电机只用一个通道：AIN1/AIN2 驱动，BIN1/BIN2 接 GND，nSLEEP 由 GPIO10 控制。
- PWM 20kHz（高于人耳），占空比上限 **80%**（限制最大推力，防夹手的第一道软件限幅）。
- 停机时序：PWM=0 → AIN1=AIN2=1（动态刹车）**300ms** → nSLEEP 低（高阻，靠减速箱保持）。
- 市售 DRV8833 模块引脚顺序不统一（红板/蓝板/GY 板），**按功能名对位，不按位置对位**。

### 2.2 长度反馈：AS5600 vs 线性电位器（二选一）

**结论：选 AS5600（装在丝杆尾端，径向磁铁 Ø6×2.5，气隙 0.5—3mm）。**

| 维度 | **AS5600（选）** | 线性电位器（滑轨式） |
|---|---|---|
| 量程 | 单圈 12 位绝对角，**多圈靠固件累计**（180mm=22.5 转） | 需 ≥200mm 行程直滑电位器，市面少见、≥¥30 |
| 精度 | 1.95µm/count，实际 ±0.3mm（背隙主导） | 12 位 ADC 理论 44µm，实际 ±0.5%FS≈±0.9mm，且有接触噪声 |
| 磨损 | 非接触，无磨损 | 电刷滑轨，数千次后有噪声/跳变 |
| 接线 | I2C 两根线（GPIO6/7），与 v1 相同 | 需 3 线 + **一路 ADC**；本设计 ADC 脚已被电池检测占用（GPIO0），GPIO2 是 strapping 不能接可变电压 |
| 电源扰动 | 数字接口，抗 PWM 干扰 | 电刷在电机 PWM 附近易拾噪，需 RC + 多次采样 |
| 掉电绝对性 | 单圈内绝对；**整段长度靠 NVS 里的圈数**，丝杆/减速箱保持位置 → 上电即知 | 全程绝对，无需归零（唯一优势） |
| 成本 | 模块 ¥9（含磁铁） | ¥30—60 + 结构件 |

**怎么处理"多圈不绝对"这个唯一缺点**（这是本方案必须写清楚的地方）：

1. **采样**：200Hz 定时器读 RAW_ANGLE（0x0E/0x0F），相邻差 >2048 判为跨圈 ±1，累计成 int32 `counts`。
2. **换算**：`L_mm = L_MIN + counts / 512`（512 counts/mm = 4096 ÷ 8mm 导程），其中 `L_MIN` 端部=30、内部=40；满行程 counts：端部 46,080、内部 92,160。
3. **落盘**：静止 500ms 后写 NVS（限 5s 一次，减少擦写），带 CRC。
4. **上电**：读 NVS → 校验范围与 CRC → 读两个限位开关状态交叉验证；三者一致才允许运动。不一致（CRC 坏/越界/限位矛盾）→ **自动归零**：慢速收缩到 LIM_MIN（4mm/s，最长 50s），归零成功后 count=0。
5. **为什么掉电不会跑位**：丝杆导程 8mm 不自锁，但 1:298 减速箱反驱阻力大 + 停机动态刹车；验收要求"断电后 60s 内轴向位移 <0.5mm"（§10 H-07）。

**AS5600 关键参数**：I2C 7 位地址 **0x36**，3.3V，12 位，DIR 接 GND（顺时针角度增大）；寄存器 ANGLE=0x0E/0x0F。磁铁必须跟**丝杆**转，不是跟电机壳。

### 2.3 电机与丝杆的匹配计算（必须先对齐机械）

```
要求：全行程 180mm，伸缩速度 3—8mm/s（00 文档锁定）
N20 6V 30rpm = 0.5 r/s
速度 = 0.5 r/s × 导程 P
  P = 2mm → 1.0mm/s（太慢，全行程 180s）
  P = 4mm → 2.0mm/s（偏低）
  P = 8mm → 4.0mm/s ✓（全行程 45s，20mm 调整 5s）
  P = 16mm → 8.0mm/s（上限）
→ 选 T8 梯形丝杆，导程 8mm（四头，2mm 螺距）
```

推力校核（需要的推力按 20—30N：衣架链摩擦 + 端部顶墙预紧，**无卷簧**）：

```
丝杆效率 η≈0.35—0.45（梯形丝杆+黄铜螺母）
T = F × P / (2π × η)
F=30N：T = 30 × 0.008 / (2π × 0.4) = 0.0955 N·m ≈ 0.97 kg·cm
F=20N：T = 0.064 N·m ≈ 0.65 kg·cm
N20 30rpm（1:298）额定扭矩约 1.2—1.5 kg·cm，堵转 2 kg·cm 级
→ 额定扭矩余量只有 1.2—1.5 倍，属于"够但薄"，见 §11 风险 R1
```

> **与机械文档的冲突点**：`docs/v2/00-总览与架构.md` §4 写"导程 0.8—1mm"，按 30rpm 算只有 0.4—0.5mm/s，与同文档 §9"伸缩速度 3—8mm/s"矛盾。本文按 8mm 导程设计电控参数，**机械确认后以机械 BOM 为准**；若机械坚持 1mm 导程，则全行程需要 180s、AS5600 圈数 180 圈，电控需改归零策略与续航数字（见 §11 R1）。

| **0x36** | AS5600 | P0 唯一设备 |
| 0x20 | PCF8574（P1 电动夹持 I/O 扩展） | P1 预留，P0 不装 |
| 0x40 | INA219（电流/电压） | P1 备用，不冲突 |
| 0x29 | VL53L1X（v1 的邻距 ToF） | **v2 不用**（已删邻距） |
| 0x70 | TCA9548A | 仅当未来同总线挂 2 颗 AS5600 时用 |

> **AS5600 没有地址选择脚**：一颗 MCU 只挂一颗时没有冲突问题；如果未来要在一个单元里挂第二颗（比如双丝杆），只能用 TCA9548A 分路，不能改地址。

## 3. 引脚表（照这个插线）

> 板子：ESP32-C3 SuperMini（22.5×18mm，USB-C 直连 GPIO18/19，无 CH340）。
> **插线前先看丝印**：不同批次两排引脚顺序不同，本表按功能名，不按"左起第几个"。

### 3.1 引脚分配总表

| GPIO | 网络名 | 方向 | 功能 | 外围 / 备注 |
|---|---|---|---|---|
| **GPIO0** | `BAT_SENSE` | 模拟入 | 电池电压（ADC1_CH0） | 100k/100k 分压 + 100nF；ATTEN3（0—2.5V） |
| **GPIO1** | `LOCK_A` | 数字入 | A 端（端部=外端）夹持状态 | 内部上拉；夹持微动 NO 到 GND，**锁=低**；线断=高=未锁（保守） |
| **GPIO2** | `LED_DIN` | 数字出 | WS2812 数据 | 串 330Ω；**外部 10k 上拉到 3V3**（strapping 脚，复位时须为高；WS2812 DIN 高阻，靠上拉保证） |
| **GPIO3** | `LIM_MIN` | 数字入 | 下限位微动开关（L=40mm） | 内部上拉，开关另一端 GND，100nF；低=触发 |

| **GPIO20** | `LIM_MAX` | 数字入 | 上限位微动开关（L=220mm） | 内部上拉；UART0 RX 复位后为输入，安全 |
| **GPIO21** | `LOCK_B` | 数字入 | B 端（端部=内端）夹持状态 | 内部上拉；开关到 GND **串 1kΩ**；⚠ 与 UART0 TX 复用：开机 ROM 打印会与该脚短暂冲突（≤3.3mA），固件启动后立即改输入；P0 不用串口日志 |

| **GND** | `GND` | 电源 | 共地 | 电机地与逻辑地单点汇在 TP4056 GND |

> **引脚预算说明**：12 个功能脚正好用满 11 个非 strapping 脚 + GPIO9（按键）+ 借用 GPIO21（UART0 TX）做 LOCK_B。GPIO21 的抗冲突靠"1k 串联 + 固件启动第一件事把它配成输入 + 不用串口日志"三件事保证。若现场必须保留串口日志，用 P1 的 PCF8574（0x20）接夹持开关，GPIO21 恢复为 TX。

### 3.2 strapping 避坑（ESP32-C3）

| 脚 | 复位时 | 我们的处理 | 为什么 |
|---|---|---|---|
| **GPIO2** | 需为高（SPI boot；数据手册建议上拉防毛刺） | 用作 LED_DIN，**外接 10k 上拉**；WS2812 DIN 高阻，上拉保证复位时高 | 不能用可变电平的东西（如限位开关）占这个脚 |
| **GPIO8** | 下载模式/ROM 打印参与 | 完全悬空 | 接外设可能进不了程序 |
| **GPIO9** | 内部弱上拉；拉低=下载模式 | **用作 KEY_IN**：外部按键与板载 BOOT 并联，正常操作不会按住；⚠ 开机瞬间按住会进下载模式（唯一代价） | 其余引脚已用满，按键只能借这个脚 |
| **GPIO21** | 复位时是 UART0 TX，会输出启动日志 | **用作 LOCK_B**：开关到 GND 串 **1kΩ**，开机冲突电流 ≤3.3mA；固件启动第一件事改输入 | 不用串口日志时安全；要日志就换 PCF8574 |

一句话：**GPIO2 只接"上电自然是高"的东西（串 330Ω 的 WS2812 数据线 + 10k 上拉）；GPIO8 悬空；GPIO9 只接按键（别按住开机）；GPIO21 只接带 1k 串阻的开关。**

### 3.3 绝对不能用的脚

| 脚 | 原因 |
|---|---|
| GPIO11 | VDD_SPI / Flash 供电，改板后才能当 GPIO |
| GPIO12—17 | 板载 SPI Flash，占用即无法启动 |
| GPIO18/19 | USB D-/D+，唯一烧录+调试通道 |

### 3.4 复用与电气注意

- GPIO4/5/6/7 同时是 JTAG 的 MTDI/MTCK/MTMS/MTDO。做 PWM/I2C 允许（优先级 3），代价是放弃 JTAG 硬件调试——本来就用 USB-Serial-JTAG。
- GPIO20 是 UART0 RX：复位阶段 ROM 只把它当输入（有内部上拉），接微动开关（到 GND）安全。
- **GPIO21 是 UART0 TX**：复位时会输出启动日志，所以外部只允许接"串 1kΩ 到 GND 的开关"（LOCK_B），不接受任何强驱动器件；要串口日志就把 LOCK_B 移到 P1 的 PCF8574。
- 所有 IO 是 3.3V 电平；WS2812 数据高电平 3.3V 满足 0.7×VDD 门限。
- MT3608 6V 输出给 DRV8833 VM；**不要**把 6V 引到 SuperMini 的 5V 脚（会烧 LDO）。

| 器件 | 状态 | 3.3V 侧电流 | 来源 |
|---|---|---|---|

| **电池侧待机** | | **≈29mA** | **设计值** |

### 5.2 伸缩（匀速，带载）

```
6V 轨：N20 带载 180mA + DRV8833 静态 2.5mA = 182.5mA
P_6V = 6.0V × 0.1825A = 1.095W
P_电池(电机) = 1.095 / 0.85 = 1.288W
I_电池(电机) = 1.288 / 3.7 = 348mA
I_逻辑 = 29mA（运动时 LED 蓝，按 31mA 上限）
I_总 = 348 + 31 ≈ 380mA（电池侧）
```

### 5.3 堵转（瞬时，300—600ms 可配后固件切断）

```
6V 轨：N20 堵转 700mA + DRV8833 2.5mA = 702.5mA
P_6V = 6.0 × 0.7025 = 4.215W
P_电池 = 4.215 / 0.85 = 4.959W
I_电池(电机) = 4.959 / 3.7 = 1340mA
I_总 = 1340 + 31 ≈ 1371mA（≈1.37A）
```

校核：
- 电池保护板 2—3A 不动作（1.37A = 1.37C @1000mAh，瞬时可接受）；
- MT3608 输入电流 = 1.34A < 2A 开关限流，**但持续不能超过 0.5s 量级**，否则模块发热/掉压 → 固件堵转判据必须 ≤0.3—0.6s 切断（§6.1）；
- 若实测某批 N20 堵转 1.2A：电池侧 1.37→2.2A，逼近保护板 2—3A，必须换 DRV8833 限流/加 PTC 1.5A（可选件，见 BOM）。

### 5.4 续航（1000mAh，可用 85%）

```
可用容量 = 1000mAh × 0.85（保护板截止 + 老化 + 低温）= 850mAh
```

**待机天数**

| 档位 | 策略 | 电池侧电流 | 续航 |
|---|---|---|---|
| 在线待机（P0 演示） | Wi-Fi 保活、状态 1Hz、LED 呼吸 | 29mA | **29.3h ≈ 1.2 天** |
| 演示静置（收到命令才亮灯） | LED 灭 | 26mA | 32.7h ≈ 1.4 天 |
| 深休眠（P1，不发货用） | 断开 Wi-Fi，仅 RTC 唤醒 | 约 0.15mA（含保护板） | 理论 236 天，实际按自放电 8—12 个月 |

> 深休眠**不能收 MQTT**，只用于运输/长期存放；演示请用"在线待机"。

**动作次数**（一次动作定义为 20mm 调整：8cm→10cm 净风道，最常用的演示操作）

```
移动时间 = 20mm ÷ 4mm/s = 5.0s
加梯形加减速 0.5s + 到位 settle 0.5s → 6.0s
单次电量 = 0.380A × 6.0s / 3600 = 0.633mAh
纯动作次数 = 850mAh ÷ 0.633 ≈ 1343 次
```

- 全行程 180mm：45s → 4.75mAh → **179 次**；
- **24h 在线待机后**：剩余 850 − 29×24 = 154mAh → 还能动 **243 次**（这就是真实使用口径）；
- 一次完整演示（5 单元 × 30 次调整）：5×30×0.633 = **95mAh ≈ 单块电池的 9.5%**；
- 充电：500mA 从空到满 ≈ 2.1h（0.5C）。

**结论**：动作本身几乎不耗电，**吃电的是待机**。实测待机若超过 40mA，先查 AS5600 供电与 WS2812 亮度，再查 ESP32 是否进了 modem-sleep。

## 6. 安全与失效保护

### 6.1 丝杆卡死判据（v2 核心）

```
采样：AS5600 200Hz；每 300ms 一个窗口
条件 A：PWM 占空比 ≥ 35%（不是"给了命令"，是真的在给电）
条件 B：窗口内 |Δcounts| < 3（3 counts ≈ 6µm，正常 4mm/s 时约 614 counts/300ms）
条件 C：避开启动前 150ms（加速段）
A 且 B 成立（300ms 窗口；固件 `STALL_CONFIRM` 可配 1=300ms / 2=600ms）→ 判卡死

动作（按顺序，全部在本地完成）：
1) PWM=0
2) AIN1=AIN2=1 动态刹车 200ms
3) nSLEEP=0（高阻）→ 丝杆+减速箱保持
4) 红灯闪 5 次，MQTT evt：{"code":"E03","state":"fault"}
5) 反向回退 1.5mm（释放夹紧），再停；**不自动重试第二次**
6) 需中枢发 resume 或本地长按按键解除
```

为什么不用电流：DRV8833 模块没有采样电阻，硬件上不存在电流限流。而"给了 PWM 但编码器不动"这个现象**直接就是卡死/顶死**，对"丝杆卡死"和"限位顶死"一视同仁。P1 加 INA219 后可再加"电流 >0.6A 且不转"的双判据。

### 6.2 上下限位（硬件 + 软件双保险，按角色）

| 层 | 端部 01/05（END） | 内部段（MIDDLE） | 动作 |
|---|---|---|---|
| 硬件限位 | 机械硬限位 28 / 122mm | 38 / 222mm | 顶住后由 §6.1 卡死判据兜底 |
| 开关限位 | 微动 **30 / 120mm** | 微动 **40 / 220mm** | 触发即 PWM=0、更新状态、evt `E04 LIMIT`；下限触发同时把 count 归零（归零基准） |
| 软件限位 | 软限位 30—120mm | 软限位 40—220mm | 目标越界直接拒绝（evt `E07`），不做"慢慢靠过去" |

- 上限位触发后**只允许收缩**；下限位触发后**只允许伸出**（防止命令打架把丝杆顶死）。
- 上电时若 LIM_MIN 已闭合：直接认为在最小长度，count 清零；若 LIM_MAX 闭合：允许收缩。
- **同一套硬件**：端部/内部共用 PCB、电机、丝杆；差异只在固件参数（`UNIT_ROLE_END`）、限位凸台位置和出厂装配。BOM 不区分。

### 6.3 夹持状态联锁（未锁禁止伸缩，按角色）

P0 是**手动**双端夹持：每端一个**锥面收口夹头（collet）**——开槽夹头环 + 外套筒，**套筒向内滑 5—8mm 就把夹头径向压紧在杆上，拉出松开**。夹持状态由 2 个微动开关反馈（LOCK_A=外端/数字端，LOCK_B=内端/另一端，锁=低）。**锁一端的含义**：该端成为锚点，另一端沿杆滑移，电机可伸可缩；**锁两端**：两端都被夹住，长度固定。

**内部段（MIDDLE）状态表**

| LOCK_A | LOCK_B | 状态 | 允许动作 | 灯 |
|---|---|---|---|---|
| 锁 | 松 | `referenced_a`（A 端锚定） | 允许伸缩（B 端沿杆滑移） | 绿/蓝 |
| 松 | 锁 | `referenced_b`（B 端锚定） | 允许伸缩（A 端沿杆滑移） | 绿/蓝 |
| 锁 | 锁 | `fixed`（定点固定/绝对位置） | **禁止电机动作**，只测量与上报 | 绿常亮 |
| 松 | 松 | `free`（无基准） | **禁止电机动作**，提示"请先锁一端" | 黄闪 |

**端部 01/05（END）特殊规则**

| LOCK_A（外端） | LOCK_B（内端） | 状态 | 允许动作 | 灯 |
|---|---|---|---|---|
| 锁（正常） | 松（默认） | `referenced_a` | **允许伸缩**：外端坐标固定，内端在 30—120mm 内移动吸收总长变化 | 绿/蓝 |
| 锁 | 锁 | `fixed` | 禁止电机动作（内端被锁 = 长度固定） | 绿常亮 |
| 松 | 任意 | `free`/`fault` | **禁止电机动作**，evt `E13`；提示"外端夹头未锚定" | 黄闪/红闪 |

> 端部**外端微动只测"锚定套筒是否到锁位"**，不参与伸缩；内端微动照常检测。端部外端在 P0 由装配保证常锁，固件把它当安全前提：外端未锁 = 不准动。

联锁规则（全部在单元本地，不依赖中枢）：

1. **运动前**：MIDDLE 只有 `referenced_a/b` 允许 `set_length`；END 只有"外端锁 + 内端松"允许。其余返回 evt `E13 CLAMP_UNLOCKED`，保持 nSLEEP 低。
2. **运动中变状态**：200Hz 采样 + 50ms 去抖；一旦离开允许态 → **立即停**（≤50ms），刹车 200ms → 高阻，evt `E14 CLAMP_CHANGED`。
3. **fail-safe 默认**：开关断线/接触不良 = 读到高 = 未锁 → 禁止运动（宁可不动）。
4. **端部不是"整段锁死"**：外端锁死、内端自由，端部长度可变（30—120mm）；这正是自动等距/收衣能吸收总长变化的原因（`docs/v2/10`）。
5. **手动操作顺序（内部段）**：推入套筒锁"锚定端" → 拉出"滑移端"套筒 → 调长度 → 推入"滑移端"套筒 → 需要定点固定时再推入"锚定端"套筒（确保两端都到锁位）。端部：外端保持常锁，内端默认松；需要固定长度时再推入内端套筒。
6. **P1 电动夹持**：J4（I2C）/J5（+6V0）预留，PCF8574（0x20）驱动**微型舵机/电磁推套筒**；电动夹持必须先"拉出套筒（松）"再让电机动作，"推入套筒（紧）"必须在电机停稳后，顺序由固件状态机保证。
7. **微动的局限**：它只测"套筒是否到锁位"，不测径向夹紧力。夹头环磨损/杆径偏小可能"显示锁但未夹紧"→ 必须做 30N 轴向推力测试（§10 H-21）；夹头环建议用 POM/尼龙或 3D 打印 TPU 内衬，磨损后更换。

### 6.4 接缝夹手

接缝是两个 U 托之间的 10mm 缝，衣架钩挂在这里。运动方向上的风险是"手指/衣物被两段圆柱的端头夹住"。

| 措施 | 说明 |
|---|---|
| 结构 | U 托圆角 ≥R3、缝口倒角；这是机械负责，电控要求"不留锐边" |
| 软件限速限力 | 占空比上限 80%；起步前 150ms 先闪蓝灯（运动预告）；不允许 >5mm/s |
| 卡死判据 | 手指/衣物挡住 → 电机顶住 → 300ms 内 E03 停机（§6.1） |
| 停止即松 | 停机和急停都走"刹车 200ms → 高阻"，不持续顶住 |
| 验收 | 8mm 木棒塞进缝里做 50 次伸缩，必须在 0.8s 内停、木棒无压痕（§10 H-05） |

> 诚实说明：v2 没有独立防夹传感器（v1 的 ToF 已删）。防夹靠"低推力 + 300ms 卡死判据 + 圆角结构"，属于**被动安全**，不是"绝对夹不疼"。演示时手不要放在接缝里，这条写进演示脚本。

### 6.5 断网/断中枢保持（fail-safe）

| 事件 | 判据 | 动作 |
|---|---|---|
| 心跳丢失 | 500ms 无 `hangflow/hub/status` 或自己的 cmd | **立即停**，保持当前位置（刹车 300ms → 高阻，减速箱保持），状态置 `holding` |
| 断网 5s | MQTT/Wi-Fi 断开 | nSLEEP 低（高阻），LED 红慢闪，本地闭环继续可响应按键 |
| 重连 | MQTT 重连成功 | 上报当前 `length_mm`，**不自动续跑最后一条命令**，等中枢重新下发 |
| 中枢重启 | — | 同上；中枢用视觉 + `state` 重建链路，重新规划 |

设计原则：**最后一条命令不会变成"一直往前走"**。任何通信中断都收敛到"停住 + 保持"。

### 6.6 低压保护（四档，电机停转时采样）

| 电池电压 | 动作 |
|---|---|
| ≥3.60V | 正常 |
| 3.60—3.50V | 黄灯；拒绝 >100mm 的大行程，只允许小幅调整 |
| 3.50—3.40V | 黄灯闪；**只允许收缩/收衣**，禁止继续伸开 |
| <3.40V | nSLEEP 低 + 红灯闪 + evt `E05 LOW_BAT`；进入低功耗待机 |
| <3.30V 或 10 分钟无命令 | 深休眠（P1 才实现；P0 保持在线待机并红灯） |

阈值取 3.5V 而不是保护板的 2.5V：3.5V 以下内阻陡增，电机一启动就把逻辑轨拉到 3.2V 以下，容易复位。

### 6.7 急停（三条独立路径）

| 路径 | 实现 | 响应 |
|---|---|---|
| **网页/MQTT** | `hangflow/sys/estop`（QoS1，广播）→ 单元回调第一行 PWM=0、nSLEEP=0 | 100—500ms（受 Wi-Fi） |
| **本地按键** | 长按 3s → 锁存急停；再长按 3s 解除 | <50ms（GPIO 中断） |
| **物理断电** | 外壳侧面拨动开关 | 瞬间（电机惯性 <1 转） |

- 急停是**锁存**的：必须显式解除（网页"复位"或长按），不因收到新命令自动恢复。
- 急停时 LED 红快闪；状态 `estop:true`。
- 开关必须装在**手够得到**的位置（外壳侧面偏下），不要藏在抱箍内侧。

### 6.8 其它

| 威胁 | 措施 |
|---|---|
| 固件跑飞 | `esp_task_wdt` 2s；复位默认 nSLEEP 低（10k 下拉），电机不动 |
| 丝杆反驱（导程 8mm 不自锁） | 300ms 动态刹车 + 减速箱阻力；验收 §10 H-07（断电 60s 位移 <0.5mm）；不达标 → 加常闭电磁刹车或改小导程 |
| 夹持微动失效/线断 | 读高=未锁 → 禁止运动（fail-safe）；evt E13 |
| 手动夹持没锁到位 | 运动中状态跳变 → 50ms 内停（E14）；上电 200ms 后才开始读 |
| 电池反接 | 18650 座防呆 + 丝印；TP4056 模块自带保护 |
| 电机反电动势 | DRV8833 内部续流二极管 |
| MT3608 过流 | 堵转 ≤0.3—0.6s（可配）；可选 PTC 1.5A 自恢复保险丝 |
| 静电 | 外壳内走线不裸露；I2C/电机线双绞 |

## 7. 通信：RDK 热点 + MQTT

### 7.1 拓扑

```
手机 ─┐
      ├─ 2.4GHz（RDK 开热点 SSID:HangFlow，10.42.0.1）
单元 ─┤        RDK X5：mosquitto:1883 + FastAPI:8000 + USB 相机
      └─ 单元 01—07 静态 IP 10.42.0.11—.17
```

- ESP32-C3 **只支持 2.4GHz**，热点必须开 2.4G，信道选 1/6/11 中最空的；
- 单元 ID 01—07 与顶部 ArUco 标签一致；**K 件衣服 = K+1 个单元**（演示 K=4 → 01—05）；RDK 视觉读 ID，MQTT 用 ID 对号；
- 单元 static IP 按 ID 固定，避免 DHCP 重连抖动。ID 01—07 最多支持 7 个单元（K≤6），演示 5 个。

### 7.2 主题表（ID = 01—07）

| 主题 | 方向 | QoS | retain | 说明 |
|---|---|---|---|---|
| `hangflow/unit/{id}/cmd` | 中枢→单元 | 1 | 否 | 目标长度、速度、急停/复位 |
| `hangflow/unit/{id}/state` | 单元→中枢 | 0 | **是** | 10Hz 运动 / 1Hz 空闲 |
| `hangflow/unit/{id}/evt` | 单元→中枢 | 1 | 否 | 事件（卡死/限位/低电/到位） |
| `hangflow/unit/{id}/cfg` | 中枢→单元 | 1 | 否 | 参数（软限位、速度上限、标定） |
| `hangflow/sys/estop` | 中枢→全部 | 1 | 否 | 广播急停（锁存） |
| `hangflow/sys/resume` | 中枢→全部 | 1 | 否 | 解除急停 |
| `hangflow/hub/status` | 中枢→全部 | 1 | 否 | 中枢心跳 1Hz |

单元遗嘱（LWT）：断线时 broker 自动往 `state` 发
`{"v":1,"id":"01","state":"offline","ts":...}`（retain）。

### 7.3 报文（JSON，UTF-8，单条 ≤512B）

**中枢 → 单元（cmd，`op` 区分动作）**

```json
{"v":1,"seq":42,"op":"set_length","set_length_mm":100.0,"speed_mm_s":4.0,"timeout_ms":60000}
{"v":1,"seq":43,"op":"clamp","clamp":"a","action":"release"}
{"v":1,"seq":44,"op":"stop"}
{"v":1,"seq":45,"op":"resume"}
{"v":1,"seq":46,"op":"home"}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `v` | int | ✓ | 协议版本 1 |
| `seq` | int | ✓ | 单调递增；单元丢弃 `seq ≤ last_seq`（防乱序） |
| `op` | enum | ✓ | `set_length` / `clamp` / `stop` / `resume` / `home` |
| `set_length_mm` | float | set_length 必填 | 目标长度；端部 30—120、内部 40—220，越界回 E07 |
| `speed_mm_s` | float | ✗ | 1—5mm/s，默认 4.0；超过上限按上限 |
| `timeout_ms` | int | ✗ | 默认 60000；超时 evt E08，停 |
| `clamp` | string | clamp 必填 | `"a"`=外端/数字端，`"b"`=内端/另一端 |
| `action` | enum | clamp 必填 | `lock` / `release` / `status`（P0 手动夹头只支持 `status`；`lock/release` 回 E15） |

> `stop` = 立即停（可再运动）；`resume` = 解除急停锁存；`home` = 慢速归零（端部 30mm / 内部 40mm）。急停仍走广播 `hangflow/sys/estop`，优先级最高。

**单元 → 中枢（state，10Hz 运动 / 1Hz 空闲）**

```json
{
  "v": 1,
  "id": "01",
  "role": "END",
  "seq": 42,
  "length_mm": 59.6,
  "length_min_mm": 30,
  "length_max_mm": 120,
  "state": "moving",
  "clamp_a": true,
  "clamp_b": false,
  "clamp_state": "referenced_a",
  "batt_mv": 3820,
  "current_ma": 180,
  "limit_min": false,
  "limit_max": false,
  "estop": false,
  "fault": 0,
  "uptime_s": 813,
  "ts": 1730000000123
}
```

| 字段 | 说明 |
|---|---|
| `role` | `END`（端部 01/05：外端锚定、内端 30—120）/ `MIDDLE`（内部段 40—220） |
| `length_mm` | 实测长度（AS5600 换算），±0.3mm |
| `length_min_mm/max_mm` | 当前角色的软限位范围，中枢不用再猜 |
| `state` | `boot` / `online` / `idle` / `moving` / `holding` / `fault` / `estop` / `offline`(LWT) |
| `clamp_a` / `clamp_b` | A（外端/数字端）/B（内端/另一端）夹持是否锁定（`true`=锁）；**这两个字段决定能不能动** |
| `clamp_state` | `referenced_a` / `referenced_b` / `fixed` / `free`；中枢据此决定是否下发运动命令 |
| `batt_mv` | 电池毫伏（停转时采样） |
| `current_ma` | P0 无电流传感器时填 `null`（P1 加 INA219 后为实测） |
| `limit_min/max` | 限位开关实时状态 |
| `fault` | 0=正常；非 0 见 7.4 |

**单元 → 中枢（evt，QoS1）**

```json
{"v":1,"id":"01","code":"E03","state":"fault","msg":"stall: 2cnt/300ms @duty0.62","length_mm":146.2,"ts":1730000000456}
```

### 7.4 错误码（v2）

| 码 | 含义 | 现场处置 |
|---|---|---|
| E01 | Wi-Fi 断开 | 查热点/信道；重启单元 |
| E02 | MQTT 断开 | `systemctl restart mosquitto` |
| E03 | 丝杆卡死/顶死 | 拿走障碍物；长按按键或网页复位 |
| E04 | 触发硬限位 | 检查是否顶到端部/限位装反 |
| E05 | 低电（<3.4V） | 换电池/充电 |
| E06 | 归零超时 | 检查下限位/丝杆是否卡 |
| E07 | 非法指令 | 检查 `set_length_mm` 范围/`seq` |
| E08 | 到位超时 | 降低速度/查负载 |
| E09 | AS5600 无响应 | 查 I2C 线/磁铁气隙/地址 0x36 |
| E10 | 急停锁存 | 网页或长按解除 |
| E11 | 过温（>60℃，P1） | 停机散热 |
| E12 | ID 不匹配（中枢侧） | 视觉 ArUco ID 与 MQTT ID 不符，检查标签 |
| **E13** | **夹持未锁/无基准**：MIDDLE 的 free/fixed 或 END 的外端未锁时收到运动命令 | 按提示锁一端/松一端；END 检查外端锚定；见 §6.3 |
| **E14** | **运动中夹持状态变化** | 立即停；检查套筒是否没推到锁位/微动松动 |
| **E15** | **P0 无夹持执行器**（收到 `clamp` 的 lock/release） | P0 手动夹头只能 `status`；lock/release 留给 P1 电动套筒 |

### 7.5 时序

```
中枢                                broker                         单元
 │ cmd{seq=42,set_length_mm=100} ──► │ ───────────────────────────► │ 校验 seq/范围
 │                                   │                             │ 本地闭环（AS5600）
 │ ◄──────── state 10Hz(lenght_mm) ──┤ ◄────────────────────────── │
 │ ◄──────── evt{code=OK} ───────────┤ ◄────────────────────────── │ 到位（±1mm 内）
 │ 60s 未到位 → 发 stop + 记 E08      │                             │
```

- 到位判据：`|length_mm − set_length_mm| ≤ 1.0mm` 连续 300ms → evt `{"code":"OK"}`，state=idle。
- 中枢 10Hz 下发是"设定值保持"，不是 P 控制；单元本地用 **位置 PI + 速度梯形**（算法同学出参数，电控给接口）。

## 12. 与 v1 的差异（电控口径）

| 项 | v1 | v2 |
|---|---|---|
| 单元数量 | 4 个自走模块 | **K+1 个**（K 件衣服，两端也有；演示 K=4 → 5 个） |

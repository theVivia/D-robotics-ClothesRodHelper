## 这是什么

从预览看：圆柱壳 + 内部三角活塞/三角凸轮 + 三片排骨状推块 + 侧拨杆。推测是**转动三角活塞，三块同步径向伸出/收回**的夹紧结构；没有参数表，尺寸/力/行程要同事补。

## 怎么打开

Fusion 360 → 文件 → 打开 → 选 `piston-v2.f3d`。不要直接改这个文件，先另存副本。

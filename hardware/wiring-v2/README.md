## 接线顺序（别跳步）

1. 电源链路（`wiring-unit-v2.md` §1）：电池 → TP4056 → 开关 → VBAT_SW → MT3608（预调 6.0V）→ DRV8833 VM
2. 量电压：6V 轨 5.9—6.1V、3V3 轨 3.25—3.40V、GPIO10 上电为 0V
3. 电机驱动（§2）：AIN1/AIN2/nSLEEP
4. AS5600（§3）：I2C + 磁铁
5. 上下限位（§4）、夹持状态（§5.1）、灯/键（§5.2）
6. 按 §9 自检清单逐项打勾

## 三条硬警告

1. **电池 3.0—4.2V 只能进 SuperMini 的 5V 脚**（板载 LDO 转 3.3V），进 3V3 脚会烧。
2. **6V 只能进 DRV8833 VM**，进 SuperMini 任意电源脚会烧。
3. **GPIO8 悬空**；**GPIO9 只接按键**（与板载 BOOT 并联，别按住开机）；**GPIO21 只接 LOCK_B + 1kΩ**；GPIO2（WS2812 数据）必须外接 10k 上拉。

## 2026-11-23 结构修正（先看这条）

- **K 件衣服 = K+1 个调节器**（两端也有），端部调节器顶墙预紧，**取消恒力卷簧**。
- 每个调节器**两端各一个锥面收口夹头（开槽夹头环 + 外套筒，套筒内滑 5—8mm 锁紧/拉出松开）**，每个夹持端 1 个微动开关反馈套筒"锁/松"（共 2 个/单元）。
- **电机只在"恰好一端锁、另一端松"时允许伸缩**；两端都锁或都松 → 禁止运动（E13）。
- 端部单元与中间单元硬件完全相同。

## 与 v1 接线的差异

| v1 | v2 |
|---|---|
| AS5600 测摩擦轮转角 | **AS5600 测丝杆转角**（多圈计数） |
| VL53L1X ToF ×1（0x29） | **没有 ToF** |
| 无独立限位 | **2× 微动限位**（GPIO3 / GPIO20） |
| GPIO2 = ToF XSHUT | **GPIO2 = WS2812 数据（10k 上拉）** |
| 2000mAh 电池 | **1000mAh** |
| 4 个自走单元 | **K+1 个伸缩圆柱（演示 5 个，两端也有）** |

# 伸缩圆柱（Unit）v2 逐网络接线表

> 照这张表接一台圆柱约 40—60 分钟。**接完先做 §8 上电顺序、再按 §9 自检，然后上电。**
>
> 主控：ESP32-C3 SuperMini（USB-C 直连 GPIO18/19，无 CH340）
> 引脚分配理由与 strapping 避坑：`docs/v2/02-电控与BOM.md` §3
> 接线图：`diagram-unit-v2.svg`（A4 打印）；机读表：`netlist-unit-v2.csv`
>
> 版本 v2.2 · 2026-11-23 · 对应 v2 电控口径（丝杆伸缩、双端手动夹持 + 状态反馈、无卷簧、无 ToF、无摩擦轮）
>
> **2026-11-23 结构修正**：K 件衣服 = **K+1 个调节器**（两端也有）；每个调节器**两端各一个手动锥面收口夹头夹持**，每个夹持点 1 个微动开关反馈"锁/松"。电机只负责伸缩，**未锁禁止伸缩**。

## 0. 物料与方向（先认清器件）

| 器件 | 丝印/端口 | 本表用法 |
|---|---|---|
| ESP32-C3 SuperMini | 3V3 / 5V / GND / GPIO0—GPIO10、GPIO20/21 | 5V 脚接**电池**（3.0—4.2V，不是 5V！） |
| DRV8833 模块 | VM / GND / AIN1 / AIN2 / BIN1 / BIN2 / nSLEEP / AOUT1 / AOUT2 | 只用 A 通道；模块引脚顺序各批次不同，**按功能名对位** |
| TP4056 Type-C 模块 | B+ / B− / OUT+ / OUT− | 充电 + 保护 |
| MT3608 模块 | VIN+ / VIN− / VOUT+ / VOUT− | 预调到 6.0V 再接入 |
| AS5600 模块 | VCC / GND / SDA / SCL / DIR / GPO | I2C 0x36；DIR 接 GND |
| N20 6V 30rpm | M+ / M− | 丝杆联轴 |
| 微动开关 ×4 | COM / NO | 上下限位 2 个 + 夹持状态 2 个；NO 对 GND，触发=低 |
| WS2812B-2020 | VDD / DIN / GND | 单像素 |
| 18650 | + / − | 带保护板 |

**⚠️ 三条最容易烧板的事**

1. 电池正极**只能**进 TP4056 的 B+ 和 SuperMini 的 **5V** 脚（经 LDO），**绝不能**接 3V3 脚。
2. 6V（MT3608 VOUT）**只能**进 DRV8833 VM，**绝不能**进 SuperMini 5V/3V3。
3. 拧电池前先量电池座正负极是否短路（二极管档，应无读数）。

| `GND` | M5 | DRV8833 **BIN2** | `GND` | 黑 | — |

## 3. 长度反馈：AS5600（I2C 0x36）

| 网络 | # | 起点 | 终点 | 线色 | 备注 |
|---|---|---|---|---|---|
| `+3V3` | E1 | SuperMini **3V3** | AS5600 **VCC** | 橙 | — |
| `GND` | E2 | `GND` | AS5600 **GND** | 黑 | — |
| `I2C_SDA` | E3 | SuperMini **GPIO6** | AS5600 **SDA** | 绿 | 4.7kΩ 上拉到 3V3（总线首端） |
| `I2C_SCL` | E4 | SuperMini **GPIO7** | AS5600 **SCL** | 白 | 4.7kΩ 上拉到 3V3 |
| `GND` | E5 | AS5600 **DIR** | `GND` | 黑 | 顺时针角度增大 |
| — | E6 | AS5600 **GPO** | 悬空 | — | P0 不用 |

**磁铁安装（接对了线没用，这一步错了等于没装）**：
- 径向磁铁 Ø6×2.5mm（或 Ø8×3mm），粘在**丝杆尾端**的沉孔里；
- 磁铁中心与 AS5600 芯片中心同心，**气隙 0.5—3mm**（>3mm 精度下降，>5mm 读不到）；
- 装完扫 I2C：`0x36` 必须在；手动转丝杆一圈，角度应 0—4095 连续覆盖、无跳变。

**换算**（写进固件注释）：`L_mm = 40 + counts / 512`，其中 512 counts/mm = 4096 ÷ 8mm 导程；满行程 92,160 counts。
上电恢复：NVS 存圈数 + 限位交叉校验，不一致自动归零（详见 `docs/v2/02-电控与BOM.md` §2.2）。

## 4. 上下限位（2× 微动开关）

| 网络 | # | 起点 | 终点 | 线色 | 备注 |
|---|---|---|---|---|---|
| `LIM_MIN` | L1 | SuperMini **GPIO3** | 下限位微动 **NO** | 绿 | 内部上拉；COM 接 GND；触发=低 |
| `GND` | L2 | 下限位微动 **COM** | `GND` | 黑 | — |
| `LIM_MAX` | L3 | SuperMini **GPIO20** | 上限位微动 **NO** | 绿 | 内部上拉；COM 接 GND；触发=低 |
| `GND` | L4 | 上限位微动 **COM** | `GND` | 黑 | — |
| 去抖 | L5 | 每个开关两端并 100nF | — | — | 就近焊在开关引脚 |

**安装位置（关键）**：
- 下限位：内管完全缩回（L=40mm）时，内管尾部凸台刚好压到开关滚轮；
- 上限位：内管伸出 220mm 时，内管前端凸台压到上限位；
- 开关固定在**外套管**内壁，线不随内管移动 → 不会疲劳断线；
- 机械硬限位 38/222mm，留 2mm 缓冲，开关先触发。

## 5. 夹持状态、状态灯、按键

### 5.1 夹持状态开关（2× 微动，每个夹持端 1 个，装在套筒锁位旁）

每端结构：**开槽夹头环（锥面）+ 外套筒 + 复位弹簧**。套筒向内滑 **5—8mm** → 锥面把夹头径向压紧在杆上 = 锁；拉出 = 松开。微动只检测"套筒在锁位/松位"，不测夹紧力。

| 网络 | # | 起点 | 终点 | 线色 | 备注 |
|---|---|---|---|---|---|
| `LOCK_A` | C1 | SuperMini **GPIO1** | A 端套筒锁位微动 **NO** | 紫 | 内部上拉；COM 接 GND；**锁=低**；断线=高=未锁 |
| `GND` | C2 | A 端套筒锁位微动 **COM** | `GND` | 黑 | — |
| `LOCK_B` | C3 | SuperMini **GPIO21** | B 端套筒锁位微动 **NO** | 紫 | **串 1kΩ**（GPIO21 与 UART0 TX 复用，防开机冲突）；COM 接 GND |
| `GND` | C4 | B 端套筒锁位微动 **COM** | `GND` | 黑 | — |
| 去抖 | C5 | 每个开关两端并 100nF | — | — | 就近焊在开关引脚 |

**安装**：微动固定在外套管内壁、套筒锁位旁；套筒内滑 5—8mm 到位时压下杠杆 = 锁 = 开关闭合到 GND = 读到低。**套筒拉出（松）时开关必须可靠断开**（否则显示"锁"而实际能滑，安全方向反了）。

**固件联锁（`docs/v2/02-电控与BOM.md` §6.3）**：
- 两端都松（`free`）/ 两端都锁（`fixed`）→ **禁止电机动作**，只上报；
- 只有一端锁（`referenced_a/b`）→ 允许伸缩；
- 运动中状态跳变 → 50ms 内停。

### 5.2 状态灯、按键

| 网络 | # | 起点 | 终点 | 线色 | 备注 |
|---|---|---|---|---|---|
| `+3V3` | D1 | SuperMini **3V3** | WS2812B **VDD** | 橙 | 就近 100nF 到 GND |
| `GND` | D2 | `GND` | WS2812B **GND** | 黑 | — |
| `LED_DIN` | D3 | SuperMini **GPIO2** | WS2812B **DIN** | 蓝 | **串 330Ω**；GPIO2 外接 **10kΩ 上拉到 3V3**（strapping 脚） |
| `KEY_IN` | K1 | SuperMini **GPIO9** | 按键 **一脚**（与板载 BOOT 并联） | 蓝 | 内部上拉；并 100nF 到 GND；⚠ 开机时按住会进下载模式 |
| `GND` | K2 | 按键 **另一脚** | `GND` | 黑 | — |

**灯语义**：绿呼吸=就绪；蓝=运动中；黄=低电/未锁；红闪=故障/急停；白闪=归零；灭=深休眠。
**按键**：短按=暂停/自检；长按 3s=急停锁存；急停状态下再长按 3s=解除。

## 6. 不接的线（写下来防"顺手接上"）

| 引脚 / 线 | 为什么不能接 |
|---|---|
| SuperMini **GPIO8** | strapping + 板载蓝灯 + ROM 打印控制，接了下不进程序 |
| SuperMini **GPIO9** | 只接**按键**（与板载 BOOT 并联，正常常开）；**开机时不要按住**，否则进下载模式 |
| SuperMini **GPIO21** | 只接 **LOCK_B 的微动 + 1kΩ 串阻**；其它任何强驱动外设都不行（UART0 TX 开机输出日志） |
| SuperMini **GPIO11—GPIO17** | Flash 供电/SPI Flash，占用即无法启动 |
| SuperMini **GPIO18/19** | USB D−/D+，唯一烧录+调试通道 |
| N20 编码器线 C1/C2/VCC/GND（若发的是编码器版） | P0 不用增量编码器（AS5600 绝对角）；**剪断单独包好，别碰 3V3/GND** |
| TP4056 **OUT+ 直连电机** | 必须经 MT3608 升 6V；3.7V 直驱扭矩/转速不够 |
| 6V 进 SuperMini 任意电源脚 | 烧 LDO |
| AS5600 **GPO** | P0 不用，悬空 |
| P1 电动夹持（J4/J5） | P0 不装；只在 P1 接 PCF8574/舵机/电磁铁，**不要现在飞线** |

## 7. 走线与工艺

| 项 | 规定 | 原因 |
|---|---|---|
| 电机线 | AWG26 硅胶线，双绞 | 减少 PWM 对 I2C 干扰 |
| I2C 线 | AWG28 双绞，长度 ≤100mm | 400kHz 短线才稳 |
| 电源线 | AWG24，电池到板 ≤80mm | 1.4A 峰值压降可控 |
| 接地 | 电机地/逻辑地单点汇在 TP4056 GND | 避免电机电流流过 I2C 参考地 |
| 连接器 | 电池 XH2.54 带扣；电机 PH2.0；传感器 GH1.25 或直焊 | 防振脱落 |
| 去耦 | 每颗 IC 100nF；6V 轨 100µF/16V；电池入口 100µF/16V | — |
| 固定 | 线扎/热熔胶固定在壳内，运动件周围留 5mm 净空 | 防磨破皮 |
| 极性 | 电池座丝印 +/−；所有插头防呆 | 反接烧 TP4056 |

## 8. 上电顺序

1. 电源开关 OFF，电池不接；
2. 量电池座正负极：不短路；
3. 接电池、开关 ON、**不接电机**：量 6V 轨 5.9—6.1V、3V3 轨 3.25—3.40V；
4. 量 GPIO10 对地：0V（上电默认休眠 ✓）；
5. 扫 I2C：0x36 在；
6. 接电机，发 20% 占空比：内管应缓慢伸出，电流 250—350mA；
7. 手顶住内管：0.8s 内停 + 红灯闪（E03）；
8. 手动触发上下限位：停 + E04 状态；
9. 推入/拉出两端套筒：`clamp_a`/`clamp_b` 应在网页/日志里翻转；两端都松或都锁时发运动命令应被拒绝（E13）。

**烧录注意**：接 USB 烧录时把**电源开关关掉**（避免 USB 5V 与 6V 轨同时工作、电机突然动）；烧完再开。

## 9. 接完自检（5 分钟，打勾）

- [ ] 不接电池：电池座不短路
- [ ] 6V 轨 5.9—6.1V；3.3V 轨 3.25—3.40V
- [ ] GPIO10 上电默认 0V
- [ ] I2C 扫到 0x36；转一圈角度连续
- [ ] 待机电流 25—35mA
- [ ] 伸缩电流 330—430mA
- [ ] 卡死 0.8s 内停 + 红灯闪
- [ ] 上下限位触发即停
- [ ] 夹持开关：锁=A 端读到低；松=A 端读到高；B 端同样
- [ ] 两端都松 / 两端都锁：运动命令被拒绝（E13）
- [ ] 运动中扳松一端：≤50ms 停（E14）
- [ ] 长按 3s 急停锁存；再长按 3s 解除
- [ ] 断热点 5s 内停住，位置不动
- [ ] 断电 60s 再上电，长度误差 ≤1mm（不归零）

## 10. 常见故障速查

| 现象 | 先查 |
|---|---|
| 上电不启动、反复重启 | 5V 脚是否接了 6V/电池反接；电池电压 <3.0V |
| 电机不转但灯正常 | nSLEEP 是否被拉高；DRV8833 VM 是否有 6V；AIN1/AIN2 是否对调错 |
| 电机只往一个方向转 | 该方向 LEDC 通道没初始化；AIN 脚虚焊 |
| I2C 扫不到 0x36 | SDA/SCL 接反、上拉缺失、磁铁没装（部分模块无磁铁也通信，但角度不变）、3.3V 未供 |
| 长度数值跳变 | 磁铁气隙 >3mm、电机 PWM 干扰（双绞/加 100nF）、多圈跨圈逻辑 bug |
| 归零超时 | 下限位没接/装反；丝杆卡；限位触发点晚于硬限位 |
| 电机不动、状态 `free`/`fixed` | 夹持联锁生效：先锁一端、松一端（E13）；看 LOCK_A/B 是否真的翻转 |
| 运动中突然停 | 夹持开关抖动/套筒没推到锁位（E14）；检查开关杠杆行程与 100nF |
| 开机进下载模式 | 按键/GPIO9 在开机时被按住；松开重新上电 |
| 充电不亮灯 | TP4056 电池接反/电芯电压过低（<2.5V 保护锁死） |

# hardware/cad · 套挂单元参数化模型

主件参数化文件，**不需要渲染就能读**：所有关键尺寸都在文件头注释里，和 `docs/04-机械结构设计.md` 的尺寸链一一对应。

| 文件 | 内容 |
|---|---|
| `clip_unit.scad` | 全部打印件 + 装配视图（上壳、下爪、挂钩吊板、电池仓盖、驱动轮、惰轮） |

## 怎么用

```bash
# 整套装配视图（含参考杆）
openscad -o clip_unit.stl clip_unit.scad

# 只导出某个零件
openscad -D 'PART="top_shell"'     -o top_shell.stl     clip_unit.scad
openscad -D 'PART="lower_jaw"'     -o lower_jaw.stl     clip_unit.scad
openscad -D 'PART="hook"'          -o hook.stl          clip_unit.scad
openscad -D 'PART="battery_cover"' -o battery_cover.stl clip_unit.scad

# 换杆径（Ø20–35 全范围，其余尺寸自动跟随）
openscad -D 'ROD_D=32' -D 'PART="top_shell"' -o top_shell_32.stl clip_unit.scad

# 打印排版（四件一板）
openscad -D 'PART="print_layout"' -o plate.3mf clip_unit.scad
```

在 OpenSCAD 的 Customizer 里同样能改（参数已按 `/* [组名] */` 分组）。

## 关键参数（文件头同名变量）

| 参数 | 默认 | 范围 | 含义 |
|---|---|---|---|
| `ROD_D` | 25 | 20–35 | 目标杆径。**唯一需要现场改的参数** |
| `FIT_CLEAR` | 0.5 | 0.4–0.8 | 杆腔单边间隙；杆有漆/不直取 0.8 |
| `WHEEL_D / WHEEL_W` | 28 / 12 | — | 硅胶驱动轮，正压力 47N 时接触压强 1.5MPa |
| `IDLER_D / IDLER_W` | 20 / 8 | — | 惰轮 |
| `IDLER_PITCH` | 60 | 50–70 | 两惰轮轴距 = 抗俯仰力臂，越大抗倾覆越好但壳更长 |
| `IDLER_TIRE` | 2.0 | 0–3 | 惰轮包胶厚，0 = 硬 POM 直接接触（会压痕，不要） |
| `BODY_L` | 96 | — | 沿杆总长 |
| `BOT_Z` | −36 | — | 背舱底面，抬高是为了给衣架钩环留净空 |
| `HOOK_DROP` | 48 | 44–50 | **杆轴心到钩销中心的距离**。这是硬约束：销心必须在杆轴正下方 |
| `SPRING_PRE` | 8.0 | 5–10 | 弹簧装配压缩量，决定夹持预载（Fs ≈ 2×1.7×压缩量） |

文件里带 5 条 `assert()`：杆径越界、驱动轮顶到顶盖、惰轮超出壳长、背舱放不下 18650、挂点离下爪太近（衣架干涉）。**参数改错会直接报错，不会静默出一个装不上的件。**

## 打印（0.4 喷嘴 / 0.2 层高 / PETG）

| 件 | 耗材 g | 时长 h | 填充 | 摆放 |
|---|---|---|---|---|
| 上壳 | 55 | 2.9 | 25% gyroid / 3 壁 | 背舱贴平台 |
| 下爪 | 22 | 1.3 | 40% / 3 壁 | 横梁贴平台 |
| 挂钩吊板 | 14 | 0.9 | 40% / 3 壁 | 侧躺（层线 ⊥ 拉力） |
| 电池仓盖 | 9 | 0.6 | 25% / 3 壁 | 平面贴平台 |
| 惰轮包胶 ×2（换 TPU 85A） | 4 | 0.4 | 60% / 3 壁 | 平面贴平台 |

合计 104g / 6.1h，单件均 ≤80g / ≤4h，**无需支撑**。

## 坐标系

原点 = 杆轴心线与单元 X 向中点。**X 沿杆，Z 向上，Y 垂直于杆**；C 形开口朝 −Y（杆从 −Y 侧滑入）。
`echo()` 会打印出杆腔直径、两轮轴心高度、外形尺寸和预载估算值，`-D 'ROD_D=20'` 与 `-D 'ROD_D=35'` 各跑一次就能看到尺寸随杆径的变化。

## 未验证

本机没有 OpenSCAD 可执行文件，**这些文件未经渲染验证**（只保证语法结构与括号配平）。第一次渲染请重点看：
1. 上壳的杆腔与驱动轮槽是否穿透到外表面（会开天窗）；
2. 下爪导柱耳与上壳滑槽的 15mm 行程是否够 Ø20→Ø35；
3. 挂钩侧吊板与下爪横梁底面（z=−32.5）是否有 ≥5mm 净空。

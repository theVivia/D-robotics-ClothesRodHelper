## 通用约定

**线色**（全项目统一，看见颜色就知道是什么）：

| 颜色 | 用途 |
|---|---|
| 红 | 电池正极 / 6V 轨 |
| 黑 | GND |
| 橙 | 3.3V |
| 黄 | 电机相线（AOUT1/2） |
| 绿 | I2C SDA |
| 白 | I2C SCL |
| 蓝 | 控制信号（nSLEEP / XSHUT / LED_DIN / KEY） |

**线径**

| 回路 | 线径 | 理由 |
|---|---|---|
| 电池 → 板（峰值 1.4A） | AWG24 | 压降 <0.1V |
| 6V → DRV8833（峰值 0.7A） | AWG26 | — |
| 电机相线（峰值 0.7A） | AWG26，双绞 | 抑制 PWM 干扰 |
| I2C / 信号 | AWG28，SDA/SCL 双绞，≤100mm | 400kHz 稳定 |
| 按键 / LED | AWG28 | — |

**连接器**

| 位置 | 型号 | 备注 |
|---|---|---|
| 电池 ↔ 板 | XH2.54-2P 带扣 | 有防呆，反接插不进 |
| 电机 ↔ DRV8833 | PH2.0-2P | — |
| AS5600 / VL53L1X | GH1.25-4P（或直接焊接） | 4P：VCC/GND/SDA/SCL，注意丝印顺序各家不同 |
| 按键 | 直接焊 2 pin | — |

## 上电前的三件事（每次装机都做）

1. **不接电池**，万用表二极管档量电池座两端：无限大（不短路）。
2. 接电池、**不接电机**：量 6V 轨 5.9—6.1V、3.3V 轨 3.25—3.4V。
3. 串电流表量待机：35—45mA。>100mA 立刻断电（查短路/焊锡搭桥）。

## 三条最容易接错的地方

1. **SuperMini 的"5V"脚接的是电池 3.0—4.2V，不是 5V**。别把 6V 轨接上去（会超板载 LDO 输入范围，冒烟）。
2. **GPIO8 / GPIO9 不许接任何外设**（strapping + 板载 LED/BOOT 键），接了下不进程序。
3. **DRV8833 的 BIN1/BIN2 接 GND**，不是接 MCU（我们只用 A 通道）。悬空也行（内部有下拉），但接 GND 更干净。

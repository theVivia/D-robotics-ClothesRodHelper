# 中枢（RDK X5）接线表

> 中枢的接线比单元少，但每一根都烧钱：接错电源会烧板，接错网络会当场演示失败。
> 硬件依据见 `docs/05-硬件与电控设计.md` §2、§9、§10。

---

## 1. 供电

| # | 起点 | 终点 | 线材要求 | 备注 |
|---|---|---|---|---|
| H1 | 5V/5A 适配器（官方） | RDK X5 **Type-C 供电口**（板上丝印 PWR，位于一侧第一个 Type-C） | **必须 5A 线**（一般 3A 线满载压降 0.3—0.5V） | ⚠️ 不要用电脑 USB 口供电（官方警告：会反复重启） |
| H2 | 220V 排插 | 适配器 | 国标三孔 | 演示区备 1 个带开关排插，别跟吹风机/热水壶共线 |

**两个 Type-C 别插错**：

| 接口 | 板上位置 | 用途 |
|---|---|---|
| 供电口 | 靠近板边、有绿色 PWR 指示灯 | 接 5V/5A 适配器 |
| 烧录口 | 另一个 Type-C | 接电脑（烧系统/ADB），**不是供电口** |

板上有 4 个指示灯：PWR（绿，供电正常）、ACT（绿，系统运行闪烁）、以及网口旁边的状态灯。**上台前确认 PWR 常亮、ACT 在闪**；ACT 不闪 = 系统没起来。

## 2. 摄像头

| # | 起点 | 终点 | 备注 |
|---|---|---|---|
| H3 | USB 摄像头（UVC，1080p30，广角 100°—120°） | RDK X5 **USB 3.0 Type-A**（4 个里选**离网口最远**的那个） | 每个 USB3 口可给 1A@5V，UVC 相机 0.2—0.4A，余量充足 |
| H4 | （P1 备用）奥比中光深度相机 | USB3 或 MIPI CSI | P1，不进 P0：驱动/标定风险高 |

相机安装：架在晾衣杆斜上方 30°—45°，**距杆 0.8—1.5m**，视野覆盖整根 1.2m 杆；画面里必须能同时看到 2 个以上的 ArUco 基准标记（贴在杆两端）。

## 3. 网络（两条路，选一条）

### 3.1 主路：板载 Wi-Fi 开 2.4GHz 热点

```bash
sudo iw dev wlan0 scan | grep -E "freq|SSID|signal" | head -60   # 挑信道
sudo nmcli device wifi hotspot ifname wlan0 ssid HangFlow band bg channel 6 password hangflow2026
sudo iw dev wlan0 set power_save off
```

| 项 | 值 |
|---|---|
| SSID / 密码 | `HangFlow` / `hangflow2026` |
| 频段 / 信道 | 2.4GHz，ch 1 / 6 / 11 三选一（现场扫完再定） |
| 带宽 | 强制 HT20（40MHz 在拥挤场馆是自杀） |
| 网关 IP | 10.42.0.1（NetworkManager shared 模式默认） |
| 单元静态 IP | 10.42.0.11 — 10.42.0.14（按编号） |

### 3.2 备路：有线 + 随身 2.4G 路由器

现场 2.4G 太脏（几十个 AP）时切这条：RDK 插网线到随身路由器 LAN 口，路由器开 2.4G AP 给单元和手机。比板载 Wi-Fi 稳，代价是多带一个设备。

### 3.3 服务

| 服务 | 端口 | 启动 |
|---|---|---|
| mosquitto（MQTT broker） | 1883 | `sudo systemctl enable --now mosquitto` |
| FastAPI（手机网页） | 8000 | 见 `software/rdk/` |

`/etc/mosquitto/conf.d/local.conf`：

```
listener 1883 0.0.0.0
allow_anonymous true
```

自测：`mosquitto_sub -h 10.42.0.1 -t '#' -v`（另开一个终端发一条，能收到即通）。

## 4. 40PIN（P0 不接，留档）

| 用途 | 接法 | 限制 |
|---|---|---|
| 5V 风扇（可选） | 40PIN 的 **5V（pin 2 或 4）** 与 **GND（pin 6）** | 40PIN 5V 总预算 **≤500mA（保守口径）**；风扇选 ≤300mA 的 |
| 备用 UART 接第二块 MCU | 40PIN 的 UART 脚 | P1 |

默认 3.3V 电平（板上 IO 电平选择头可切 1.8V，**别动它**）。40PIN 负载能力**按保守口径 3.3V ≤800mA / 5V ≤500mA** 设计（官方两处文档分别是 1A/1A 与 800mA/500mA，取小的；详见 `docs/17-RDK平台与开发环境.md` §4）。多个外设同时用要重新算。

## 5. 线束与摆放（演示现场）

```
            [220V 排插]
                 │
        [5V/5A 适配器]
                 │ 5A Type-C 线（≤1m）
                 ▼
   ┌─────────────────────────────┐
   │        RDK X5  竖放          │◀── USB3 相机（线长 1m，扎带固定）
   │  底部垫高 10mm（散热）        │
   └──────────────┬──────────────┘
                  │ 2.4G 热点
        ┌─────────┴──────────┐
        │  手机（扫码开网页）  │
        └────────────────────┘
```

- 电源线**贴着桌面走 + 胶带固定**，别横跨演示区（评委一踢就完）。
- 相机线与 Wi-Fi 天线**分开走**（平行走线会耦合，表现为画面卡顿 + MQTT 丢包）。
- X5 竖放、底部垫高 10mm；不要平放在桌布上（满载 10W 级别，闷着会降频）。
- 备 2 张已烧好系统的 SD 卡（同镜像），一张当场换。

---

## 6. 上电顺序

1. 插好相机 → 2. 接 5V/5A 电源 → 3. 等 PWR 常亮 + ACT 闪烁（约 30s）→ 4. 确认热点出现 → 5. 手机连热点、打开网页 → 6. 单元逐个上电（先 1 个，再 2/3/4）。

**别反着来**：先开单元再开中枢的话，单元会一直重连，看日志会误判成"模块坏了"。
